# ChooChooTracker v1.0.26-alpha

Changes since **v1.0.25-alpha**.

## Audio and workflow

- Add spatial insert effects with track sidechain ducking, plus an experimental
  SNDStation package for TrimUI Smart Pro with local volume and rotation controls.
- Audition WAV files in the browser while holding PLAY. Support multiple game
  controllers at once.
- Improve audio capture, sidebar visuals and tap tempo.

## Editing, platforms and fixes

- Align Simplified Song creation with Classic defaults and apply the configured
  default length when patterns are created.
- Improve Classic slot allocation and picker behavior, controller navigation,
  NTH loop hints and NextUI H700 support.
- Preserve console audio output during experimental USB audio capture; clarify
  NextUI sampling setup and PortMaster installation.
- Fix DNB example sample-end metadata. Publish only the validated universal
  macOS ZIP; keep provenance and its build checksum in the Actions artifact.

## Downloads

Windows, Android (store and direct APKs plus store AAB), Linux x86_64 AppImage,
Raspberry Pi OS 64-bit, PortMaster, NextUI, MiyooPorts, Web, universal macOS,
and an **experimental SNDStation** Debian package. Android is **1.0.26-alpha**,
version code **26**.

Alpha release: back up important projects. SNDStation remains experimental while
rendering performance is investigated.
