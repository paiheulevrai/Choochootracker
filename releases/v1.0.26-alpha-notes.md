# ChooChooTracker v1.0.26-alpha

Small update, it feels so weird to have release notes that look like human-made software projects.

Changes since **v1.0.25-alpha**.

## Audio and workflow

- Add Reverbs and Delays as insert effects, with optional sidechain duckin
- Audition WAV files in the browser while holding PLAY
- Added tap tempo
- Added support for USB audio gadget microphone input (activate it using the ChooChooHacker app)

## Editing, platforms and fixes

- Align Simplified Song creation with Classic defaults and apply the configured
  default length when patterns are created
- added H700 support for PAK store
- Experimental SndStation build
- Mini piano is now a bit bigger

## Bug fixes
- the app now supports several controllers connected at the same time
- small navigation bugs

Alpha release: back up important projects. SNDStation remains experimental.
I may move to Beta stage next week if the changelog looks like this again.
