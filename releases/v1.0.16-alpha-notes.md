# ChooChooTracker v1.0.16-alpha

This alpha brings together every change merged since v1.0.15-alpha.

## Sample editing and performance

- The Sample Edit Slice row now offers **EQUAL**, **AUTO**, and **LAZY** modes. AUTO detects transients, while LAZY starts with one whole-sample slice and lets you place slice boundaries during playback.
- Slice points can be browsed, split, deleted, and nudged directly. They can be kept in the project or written to WAV cue chunks, and WAV cue chunks seed AUTO slicing when loaded.
- Sliced samples gain `SLI`/`SPL` FX, chromatic LAZY playback, a clearer count/slice control, improved preview pitch, and better slice-related hints.
- Stretch and slicing are mutually exclusive. Stretch processors are released correctly when voices are destroyed.
- A new **PAN** control and mixer monitoring improve stereo work; pan modulation is faster on PortMaster too.

## Sound design and instruments

- Master insert effects, parametric EQ, configurable audio-buffer settings, and lower idle CPU usage expand the mixing workflow.
- Insert-effect editing, Rotary speed, Shift navigation, and modulation categories have been refined; effect tails now finish naturally after playback stops.
- The FM operator editor, SID preset editor, portable user preset packs, and native gain compensation make chip sound design more practical.
- Import and export support for Dirtywave M8 `.m8s` instruments is available for Braids and Sample instruments.
- LSDj `.lsdsng` songs can be imported; `.sav` files present a song picker, and desktop/Android can export through an `.lsdsng` template. Grooves and common LSDj phrase commands are translated on import.

## Workflow, files, and reliability

- Android now ships two storage flavours: private **store** storage and **direct** storage backed by the system folder picker. **Settings > Working folder** can change, copy, or clear the selected workspace.
- File navigation is more resilient in empty and unreadable folders, respects Android storage boundaries, and accepts longer extension lists.
- Failed saves preserve the existing project. Settings can export a bounded support report for bug reports.
- Opt reliably backs out of Settings, Project, folder creation, and name entry. Scale/Slice hints, FM catalog loading, and PortMaster key mapping received fixes.

## Platforms and interface

- The Web build supports browser Web MIDI input and output, preserves settings across browser-session recovery, and maps HiDPI touch coordinates correctly.
- An optional procedural **Night** boot screen and a portable spoken left/right stereo test have been added.
- The user manual is now available in Brazilian Portuguese, Chinese, Dutch, French, German, Italian, Japanese, Polish, Russian, and Spanish.
- Windows, Android, Linux AppImage, Raspberry Pi OS 64-bit, PortMaster, MiyooPorts, and Web packages are built and validated by GitHub Actions.

> Alpha release: keep backups of important projects and report unexpected behavior, especially in the new sample, Android storage, Web MIDI, and import/export workflows.
