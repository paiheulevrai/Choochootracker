# ChooChooTracker v1.0.19-alpha

Changes since [v1.0.16-alpha](https://github.com/paiheulevrai/Choochootracker/releases/tag/v1.0.16-alpha).

## New features

- SoundFont instruments with collection browsing and Lane FX support, plus **MonkSynth**, a vocal synthesiser with ten-voice unison, vowel and voice controls, and stereo delay.
- Beads granular insert and reverb send, synchronized tape echo send, and Trance Gate as both an insert effect and a Sequence modulation source.
- Vocal and formant controls, longer LFO cycles, expanded chorus and phaser ranges, and improved insert FX menus.
- Ableton Link synchronization for tempo and transport, plus improved external MIDI clock synchronization. Sampler editing now displays tempo in BPM.
- Record microphones and USB audio inputs directly into the Sample editor, or bounce a tracker track to a sample. The audio handler recovers when an input device disconnects.
- Android support for more gamepads, optional virtual pad hiding, and updated launcher icons. Raspberry Pi OS 64-bit joins the release packages.

## Fixes

- Corrected CRD chord inversion pitches and made drop voicings available in the editor.
- Fixed Android sensor input, project/workspace loading, audio input lookup, MIDI backend, and USER preset loading.
- Fixed audio recorder buffer handling, Windows WAV export directory detection, and unstable instrument waveforms during playback.
- Improved insert FX navigation and test stability.

## Packages

Windows, Android (store and direct APKs plus store AAB), Linux x86_64 AppImage, Raspberry Pi OS 64-bit, PortMaster, MiyooPorts, and Web. Android is **1.0.19-alpha**, version code **19**.

Alpha release: back up important projects. PortMaster, MiyooPorts, and Raspberry Pi packages still need checks on their target hardware.
