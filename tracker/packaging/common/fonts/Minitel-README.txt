The local font generator was adapted for this conversion to rasterize the
source on its 8x10 pixel grid, keep a shared baseline, and enlarge using
integer scaling with padding. The source has no ASCII grave accent (`):
the missing character is a horizontally mirrored apostrophe. The resulting
font contains all 95 printable ASCII characters at five screen sizes.
