ChipNomad - Chiptune Tracker for Windows

SYSTEM REQUIREMENTS:
- Windows 10 or later
- DirectX compatible sound card

INSTALLATION:
1. Extract all files to a folder of your choice
2. Run choochootracker.exe

IMPORTANT:
- Keep SDL2.dll and libwinpthread-1.dll in the same folder as choochootracker.exe

For more information, visit: https://chipnomad.org/
