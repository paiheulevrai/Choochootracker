ChooChooTracker for Raspberry Pi
================================

This package contains a native Linux build of ChooChooTracker, including all
runtime assets, instruments, the user manual, and licenses.

This AArch64 package requires Raspberry Pi OS 64-bit and a Raspberry Pi 3B+,
Pi 4, Pi 5, Zero 2 W, or compatible 64-bit Compute Module.

REQUIREMENTS:
- Raspberry Pi OS or another compatible ARM Linux distribution
- SDL2 library (install with: sudo apt install libsdl2-2.0-0)

INSTALLATION:
1. Extract the archive to any directory.
2. Make sure SDL2 is installed.
3. Run ./chipnomad.sh from a terminal, or run ./choochootracker directly.

CONTROLS:
- Keyboard mappings can be changed in Settings > Key mapping.
- Gamepad: D-pad, A button (Edit), B button (Opt), Start (Play), Menu (Shift)

For more information, visit: https://github.com/paiheulevrai/Choochootracker

Compatibility depends on the installed SDL2 and C/C++ runtime versions.
