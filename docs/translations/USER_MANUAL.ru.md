# Руководство пользователя ChooChooTracker
> Это автоматически сгенерированный перевод `docs/USER_MANUAL.md` из текущего английского руководства. Если есть расхождения, приоритет за английским текстом.
>
> **Условности.** Интерфейс приложения на английском. Сохраняйте названия экранов, меню, полей и кнопок, FX-коды, имена модулей и движков, а также расширения файлов на английском.

ChooChooTracker — это 8-дорожечный трекер для музыкального воспроизведения на портативных консолях.

Он наследует классический рабочий процесс LSDj и систему навигации, с несколькими возможностями звукового дизайна:

- Эмуляция винтажных чипов и консолей
- Soundfonts
- Осцилляторы Mutable Instruments Braids, Plaits и Plaits-Alt с мультимодовым фильтром
- PCM-сэмплы, одноцикловые волны и вейвтейблы с мультимодовым фильтром
- aChChid — универсальный acid-синт на базе Open303
- Bogie — 12-модельный встроенный драм-синт с мультимодовым фильтром
- MonkSynth - вокальный синтезатор с десятиголосным унисоном и стерео-задержкой
- MME — двухосцилляторный мультимодуляционный синт с мультимодовым фильтром
- Sintered — встроенный экспериментальный цифровой драм-синт с 6 моделями

## 1. Установка и файлы

### ArkOS / PortMaster

Установите `choochootracker.zip` через PortMaster или скопируйте распакованный пакет в каталог `ports` консоли. Запустите **ChooChooTracker** из меню Ports.

### Miyoo Mini / Mini Plus (Onion OS)

Распакуйте архив MiyooPorts в корень SD-карты так, чтобы папки `Roms/PORTS/` слились с существующими папками Onion. Запустите **ChooChooTracker** из меню Ports после обновления списка. Перед заменой существующей установки сделайте резервную копию папки `projects/`.

Время загрузки проекта может зависеть от типов инструментов, использованных в песне. Если запуск или загрузка проекта кажутся аномально медленными, сообщите, сколько занимает каждый из них, вместе с моделью консоли и версией Onion OS.

### Raspberry Pi OS 64-bit

Распакуйте архив Raspberry Pi AArch64, установите рантайм SDL2 (`sudo apt install libsdl2-2.0-0`) и запустите `./chipnomad.sh` из распакованной папки. Держите встроенные инструменты и остальные ресурсы рядом с исполняемым файлом.

### Windows

Запустите `choochootracker.exe` с `SDL2.dll` и `libwinpthread-1.dll` в той же папке.

Поддерживается ввод с клавиатуры (подробнее см. раздел Jazz mode) или геймпада.

### Веб

Вы можете использовать Choochootracker онлайн по адресу https://choochootracker.vercel.app/ .

Управление возможно с клавиатуры, экранных контролов на мобильных устройствах или через геймпад.

Сохранённые настройки, сэмплы, темы, проекты и т.д. хранятся в памяти браузера.

Используйте **Download .cct** для экспорта проектов.

Примечание: из-за ограничений iOS использование midi с веб-версией на iPhone может быть невозможным.

## 2. Управление

ChooChooTracker лучше всего работает с геймпадом, имеющим крестовину (D-pad), 2 аналоговых стика и 7 кнопок.

| Логический контроль | По умолчанию на портативке | По умолчанию в Windows |
|---|---|---|
| **[LEFT/RIGHT/UP/DOWN]** | D-pad | Стрелки |
| **EDIT** | A | X |
| **OPT** | B | Z |
| **PLAY** | Start | Пробел |
| **SELECT** | Select | Shift |
| Модуляционные оси | Левый и правый стики | Стики геймпада |
| **STICK LIVE** | L1 | Q |
| **MOTION RECORD** | L2 | W |
| **MOTION ERASE** | R2 | E |

Назначения кнопок можно изменить в **Settings > Controls > Key mapping**, в том числе на Android с внешним геймпадом. На PortMaster сохраните переназначение кнопки через **Done**, затем отпустите кнопку, чтобы продолжить настройки.

### Навигация

- Используйте **[UP/DOWN/LEFT/RIGHT]** для перемещения курсора.
- Удерживайте **SELECT + [DIRECTION]** для переключения между экранами.
- Удерживайте **OPT + [DIRECTION]** для навигации внутри экрана.
- На значении используйте **EDIT + [LEFT/RIGHT]** для мелкой настройки или **EDIT + [UP/DOWN]** для крупной.
- Нажмите **EDIT** для ввода значения или активации команды.

### Выделение и буфер обмена

- **SELECT + OPT** включают режим выделения и переключают полезные диапазоны выделения.
- Используйте **[DIRECTION]** для расширения диапазона.
- Нажмите и отпустите **OPT** для копирования и выхода из режима выделения.
- **OPT + EDIT** вырезает выделение.
- За пределами режима выделения удерживайте **SELECT** и нажмите **EDIT** для вставки.
- **EDIT + [DIRECTION]** редактирует выделенные ячейки одновременно.

### Воспроизведение

- **PLAY** запускает воспроизведение с курсора. Повторное нажатие останавливает.
- Вы можете редактировать ноты, инструменты и цепочки во время воспроизведения; изменения слышны с следующего тика секвенсора.
- **SELECT + PLAY** запускает все дорожки вне экрана Song.
- **EDIT + PLAY** проигрывает предпрослушивание инструмента из Instrument Pool.

### Глобальный Bounce

Выделите диапазон строк и колонок Song, Chain или Phrase, затем дважды нажмите **EDIT** для открытия экрана BOUNCE TO SAMPLE. Bounce учитывает все выделенные дорожки: дорожки, у которых первая цепочка начинается позже в выделении, молчат и присоединяются в момент своей первой цепочки, так что файл содержит все цепочки выделенных дорожек.

Экран предлагает:

- **File name**: редактируйте с помощью клавиатуры символов. При открытии предлагается следующий свободный номер последовательности (`001`, `002`, ...) — первое число, для которого `.wav` ещё не существует в папке экспорта. Можете редактировать имя свободно — имя используется как есть. Если файл с таким именем уже есть, добавляется суффикс `_001`, `_002` и т.д., чтобы не затирать существующие файлы. Счётчик сбрасывается при загрузке или создании проекта.
- **Sample rate** и **Bit depth**: те же параметры, что и на экране экспорта.
- **Include in a sample name**: три галочки, которые добавляют теги в начало имени файла при нажатии **Start** (по умолчанию выключены):
  - **[BPM]** — текущий темп проекта, например `[120]`
  - **[Key]** — основная нота и лад, например `[Cmaj]`, `[F#min Pent]`
  - **[Bars:Beats:16ths]** — длина рендера в тактах, долях и шестнадцатых. Одна фраза равна одному такту (16 шестнадцатых), доля — 4 шестнадцатых. Полные фразы показывают только такты, например `[2]`; частичные — `[0:2]` (две доли) или `[0:1:3]` (одна доля и три шестнадцатых). Для мультидорожечного bounce решает самая длинная дорожка. Выделение, заканчивающееся посредине доли, считает на одну шестнадцатую меньше: последняя выделенная строка — точка отсечки, её note-off приходится на конец предыдущей шестнадцатой.
  - Теги применяются в порядке `[BPM][Key][Length]` перед именем файла.
- **Start**: отрисовать выборку в WAV-файл в папку экспорта (см. *Export location* в Project screen)
- **Cancel**: выйти без bounce

Во время рендеринга **OPT** отменяет процесс. После завершения или отмены экран возвратится туда, откуда был вызван bounce.

## 3. Структура песни и карта экранов

Удерживайте **SELECT + [DIRECTION]** для переключения между экранами.

Основной навигационный ряд:

<pre>
        I
R P   G M
<strong>M S C P I T</strong>
D S     P W
</pre>

Центральный ряд:

- **M**: Mixer (ветвления Reverb, Delay)
- **S**: Song (ветвления Project, Settings)
- **C**: Chain
- **P**: Phrase (ветвления Groove)
- **I**: Instrument (ветвления Modulation и Instrument Pool)
- **T**: Table (ветвления AY Wavetable editor)

Верхний ряд:

- **R**: Reverb
- **P**: Project
- **G**: Groove
- **M**: Modulation
- **I**: Insert FX

Нижний ряд:

- **D**: Delay
- **S**: Settings
- **P**: Instrument Pool
- **W**: AY Wavetable editor

Песня в ChooChooTracker используется с такой иерархией:

```text
Song -> Chain -> Phrase row -> Note + Instrument + FX
```

В песне 8 дорожек. Каждая содержит последовательность цепочек (Chains), каждая цепочка — последовательность фраз (Phrases). Фразы — 16-шаговые последовательности нот. Нота содержит высоту, инструмент, velocity и до 3 FX дорожки. Инструмент — источник звука.

## 4. Song, Chain и Phrase

### Song

Экран Song содержит 8 колонок — по одной на аудиодорожку. Каждая ячейка ссылается на цепочку. Песня может содержать до 256 строк (`00-FF`).

Дорожки расположены слева направо, цепочки — вертикально внутри дорожек. Каждая дорожка независима, цепочки могут содержать от 1 до 16 фраз, поэтому дорожки могут сдвигаться относительно друг друга. Планируйте цепочки, чтобы они оставались синхронизированы, или позволяйте им «плавать», если это нужно для трека.

В трекер-сообществе обычно 1 цепочка зарезервирована для пустых фраз — обычно `00` или `FE`.

Вы можете хранить несколько под-песен (sub-songs) в проекте, создавая «острова» — участки, разделённые пустыми строками.

#### Live Mode

Двойное нажатие **OPT** включает или отключает Live Mode; вместо названия песни появляется `LIVE`. В Live Mode **PLAY** запускает выбранную цепочку своей дорожки, если она остановлена. Если дорожка уже играет, выбранная цепочка ставится в очередь до следующей цепочки; нажатие **PLAY** дважды наперёд ставит её в первую очередь на следующий такт фразы. Выделенная пустая ячейка в Song ставит в очередь квантованную остановку. Символы: `+` — цепочка в очереди, `!` — срочная цепочка, `-` — очередь остановки.

Выделите одну строку Song по нескольким колонкам для одновременного управления треками. Множественный выбор строк запрещён. Очереди Live стираются при активном цикле диапазона в Song. Live — режим выступления, состояние не сохраняется в проекте.

#### Управление

- **OPT + [UP/DOWN]**: прыжок на 16 позиций вверх или вниз
- Выделите диапазон, затем **SHIFT + EDIT**: поверхностное клонирование цепочек с сохранением фраз
- Выделите диапазон, затем двойное нажатие **SHIFT + EDIT**: глубокое клонирование цепочек и фраз
- Выделите диапазон, затем **EDIT + [UP/DOWN]**: сдвинуть выделение вверх или вниз
- Тройное нажатие **OPT**: добавить или убрать выделение для визуальной организации
- **OPT + SHIFT**: приглушить текущую дорожку или выделенные колонки (сначала отпустите **OPT**, чтобы сохранить состояние приглушения)
- **OPT + PLAY**: соло текущей дорожки или выделенных колонок (отпустите **OPT** для сохранения соло)
- **OPT + [LEFT/RIGHT]**: включить соло всех дорожек слева или справа от текущей
- Выделите диапазон, затем двойное нажатие **EDIT**: открыть экран BOUNCE TO SAMPLE (см. Bounce выше)

Остановка воспроизведения и изменение mute или solo используют короткую выходную коррекцию в 3 мс для уменьшения щелчков. Это относится и к снятию mute и к отключению solo во время воспроизведения.

### Chain

Цепочка — упорядоченный список 16-шаговых фраз с возможностью транспонирования. Может содержать до 16 фраз, одна и та же фраза может встречаться несколько раз. Второй столбец задаёт транспозицию в полутоновах.

Звёздочка (`*`) возле цепочки означает, что она используется более одного раза в проекте. Цепочки можно клонировать из экрана Song.

#### Управление

- **OPT + [LEFT/RIGHT]**: переключение между дорожками
- **OPT + [UP/DOWN]**: переключение между цепочками текущей дорожки
- Выделите диапазон, затем **SHIFT + EDIT**: клонировать фразы
- Выделите диапазон, затем двойное нажатие **EDIT**: открыть BOUNCE TO SAMPLE для строк текущей цепочки (см. Bounce в разделе Song)

### Phrase

Фраза — шаблон дорожки в традиционном степ-секвенсоре.

Она состоит из 16 шагов, по одной строке на шаг. Каждая строка содержит ноту, инструмент, громкость от `00` до `7F` и FX-колонки. Ноты записываются в трекерской нотации, например `C-4` (нота и октава).

Для остановки ноты используйте `NOTE OFF`, FX убийства ноты или сыграйте другую ноту без инструмента.

Если цепочка содержит несколько фраз, экран Phrase работает как непрерывный редактор паттернов. Перемещение ниже строки `F` или выше `0` открывает следующую или предыдущую фразу цепочки.

Звёздочка (`*`) рядом с фразой означает, что она используется несколько раз в проекте. Фразы можно клонировать из экрана Chain.

Селектор FX показывает только часто используемые команды и те, что поддерживает инструмент в данной строке. Это заменяет длинный общий список движковых команд. ChooChooTracker поддерживает больше FX, чем ChipNomad.

### Управление- **OPT + EDIT** на пустой ноте: вставить `NOTE OFF`
- **EDIT + [UP/DOWN]** на столбце с названием FX: открыть экран выбора FX
- **OPT + [LEFT/RIGHT]**: переключение между дорожками
- **OPT + [UP/DOWN]**: переключение между фразами в текущей цепочке
- Выделите диапазон в столбце инструмента, затем нажмите **SHIFT + EDIT**: клонировать инструменты
- Выделите диапазон, затем нажмите **EDIT + [UP/DOWN]**: вращать ряды фраз
- Выделите диапазон, затем дважды нажмите **EDIT**: открыть экран BOUNCE TO SAMPLE для выделенных рядов фраз текущей дорожки (см. Bounce в разделе Song)

На этом экране, при активном выделении, столбец нот можно заполнять ритмическими паттернами:

- **OPT + LEFT** заполняет выделение фиксированным 16-шаговым паттерном и при каждом нажатии переключает на следующий паттерн. После последнего паттерна ноты стираются и цикл начинается заново. Паттерны выровнены по абсолютным рядам фразы, поэтому частичное выделение получает только шаги внутри себя.
- **OPT + RIGHT** заполняет выделение случайным паттерном из 3-8 нот (7 и 8 реже), циклически повторяя, пока **OPT** удерживается.
- **OPT + UP** мутирует уже размещённые ноты в выделении: каждый клик случайным образом выбирает 1-3 ноты и сдвигает каждую на случайное количество полутонов в пределах октавы (смещения ближе к исходной ноте встречаются чаще). При 8-м нажатии восстанавливаются исходные ноты выделения и цикл повторяется.
- **OPT + UP** при выделении, покрывающем только столбец громкости (без нот, инструментов или FX), вместо мутации происходит рандомизация скоростей: первое нажатие — паттерн Minimal (значения смещаются до +-20), второе — Medium (до +-50), третье — Random (полностью случайные значения), четвёртое — восстановление исходных значений. Отпускание **OPT** сбрасывает цикл к Minimal. Ряды без значения громкости остаются без изменений.
- **OPT + DOWN** распределяет размещённые ноты срезанных инструментов Sampler в выделении в хроматическую последовательность: первая нота каждого инструмента (самая высокая в секвенсоре) остаётся без изменений, последующие ноты инструмента поднимаются на полутон выше предыдущей, превращая стопку идентичных нот в последовательность триггеров срезов. Несколько срезанных инструментов распространяются независимо, ноты на несрезанных инструментах не изменяются, и результат не привязывается к шкале проекта. Последняя записанная нота становится последней используемой для ввода, позволяя продолжить ход вручную, выбирая следующий срез. Если выделены только срезанные инструменты, они распространяются при каждом нажатии; если присутствуют также несрезанные ноты, первое нажатие разносит срезы, а со второго нажания на них действует случайный арпеджиатор.
- **OPT + DOWN** на выделении без нот срезанных инструментов — случайный арпеджиатор для размещённых нот. Выбирается аккорд из палитры CRD: 3-нотовые аккорды для выборов из 1-2 нот, аккорды из 3+ нот для выделений из 3, любой аккорд для 4 и более нот. Корень аккорда ставится на случайную ноту из шкалы проекта в пределах регистра выделения (при отключённой шкале или исключённой дорожке — любая хроматическая нота). Тоны квантуются по шкале так же, как при воспроизведении CRD. Каждый клик перестраивает аккорд заново — в случайном порядке, от низшего к высшему, от высшего к низшему, затем вверх-вниз. Пятое нажатие восстанавливает исходные ноты, следующее выбирает новый аккорд. Название аккорда отображается в строке состояния, ноты не добавляются и не удаляются, отпускание **OPT** сбрасывает процесс.
- Каждое заполнение сначала стирает ноты выделения, а наложенные ноты получают последний использованный инструмент. Отпускание **OPT** сбрасывает циклы к первому шагу.

### Key jazz (только для десктопа)

Нажмите **Esc** на экране Phrase для переключения key jazz — режима ввода нот в стиле пианино на QWERTY-клавиатуре (как [m8c](https://github.com/laamaa/m8c)):

- `Z S X D C V G B H N J M` и `Q 2 W 3 E R 5 T 6 Y 7 U I 9 O 0 P` вводят ноты по хроматике в более чем двух октавах, соответствуя физическому расположению клавиш, поэтому раскладка одинаковая для AZERTY, QWERTY и QWERTZ.
- При каждом нажатии нота записывается в текущий ряд и курсор переходит к следующему ряду.
- `[` / `]` сдвигают октаву.
- **Shift + стрелки** выделяют диапазон рядов и столбцов; простое нажатие стрелки после этого снимает выделение.
- **Ctrl+C** / **Ctrl+X** копируют или вырезают выделенные столбцы, либо ноту/инструмент/громкость текущего ряда, если выделения нет; **Ctrl+V** вставляет в курсор.
- **Delete** удаляет весь ряд(ы) (все столбцы) и сдвигает выше расположенные ряды вверх; курсор остаётся на том же ряду.
- **Backspace** удаляет элемент под курсором в текущем столбце (или во всех столбцах выделения, если оно есть), сдвигает ниже расположенные ряды вверх и перемещает курсор на один ряд назад, как в текстовом редакторе.
- **Insert** вставляет пустой ряд, сдвигая остальные вниз.
- **Ctrl+S** сохраняет проект. За пределами key jazz Ctrl+S не работает.
- Повторное нажатие Esc отключает key jazz.

Когда key jazz включён, он полностью захватывает клавиши нот на экране Phrase, включая сочетания Edit/Opt/Motion, которые используют эти клавиши — выключите его через Esc, чтобы вернуть их.

Key jazz также работает, независимо переключаясь через Esc, на:

- **Song** и **Chain**: вводит 16-ричные индексы цепочек или фраз напрямую (`0-9`, `A-F`) вместо переключения клавишами Up/Down. Первый введённый символ заменяет значение ячейки; последующие символы вводятся сдвигая значение (например, ввод "3" затем "F" даёт 3F). В Song **Shift+стрелки** выделяют диапазон, **Delete** удаляет целые ряды и сдвигает остальные вверх, **Backspace** удаляет текущий или выделенные столбцы и сдвигает вниз содержимое, **Insert** вставляет пустой ряд, а **Ctrl+C**/**Ctrl+X**/**Ctrl+V** копируют/вырезают/вставляют выделенные ряды (или текущий ряд, если выделения нет) — те же сочетания для работы со структурой, что и на экране Phrase. Это захватывает Shift, поэтому Shift+Right/Up больше не переключает Chain/Project, пока key jazz активен — нажмите Esc, чтобы вернуть эти сочетания.
- **Любой экран с текстовым полем**: ввод напрямую с клавиатуры вместо виртуальной клавиатуры на экране. Это касается имени файла проекта, заголовка и автора, имени инструмента, названия цветовой темы, имени таблицы высоты тона, имени bounce-файла и диалогов с именами (ввод имени, создание папки). Backspace работает как в обычном текстовом поле; Shift вводит заглавные буквы. Esc переключает этот режим сразу для всех этих экранов, при выключенном key jazz виртуальная клавиатура открывается обычным способом.
- **Instrument**: при включённом key jazz клавиши нот проигрывают инструмент текущей дорожки для прослушивания, не записывая ноты (тот же пиано-расклад, что и в Phrase; слышен последний нажатый ключ, звук прекращается при отпускании клавиш). Клавиши октавы сдвигают октаву, начиная от октавы первой ноты инструмента. В поле **Name** клавиши печатают текст как обычно. Во время воспроизведения песни этот режим не звучит для дорожки.

## 5. Инструменты

Все инструменты имеют несколько общих параметров:

- Тип инструмента
- Название, до 15 символов
- Скорость таблицы по умолчанию, в тиках на строку таблицы
- Громкость
- Панорама
- Транспонирование включено или выключено

Каждый инструмент имеет таблицу по умолчанию с тем же номером из диапазона `00-7F`. Можно использовать их как вспомогательные таблицы, но лучше хранить вспомогательные таблицы в диапазоне `80-FE`, чтобы избежать конфликтов и путаницы. Таблицы — одни из основных средств звукового дизайна в ChooChooTracker.

### Управление

- **OPT + [LEFT/RIGHT]**: переключение между инструментами
- **EDIT + PLAY**: прослушать инструмент
- **SHIFT + OPT**: копировать инструмент
- **SHIFT + EDIT**: вставить инструмент

### SOUNDFONT (экспериментальный)

Копируйте оригинальные банки SF2/SF3, инструменты SFZ/EXS с их сэмплами или ZIP-архивы
в папку `instruments/USER/soundfont`. Выберите **SOUNDFONT** в Instrument. Строка сканирования показывает **Not scanned**, **Scanning...** или **Scanned** с кнопкой **Rescan**. Сканирование читает метаданные; оно не загружает все сэмплы пресетов в память.

Строка **Preset** показывает активный пресет. Нажмите и отпустите EDIT, чтобы открыть браузер в этом пресете: коллекции отображаются слева, пресеты — справа. Каждая коллекция — это плоский список, включая пресеты из банков и ZIP-архивов. Поддерживаемые WAV/AIFF-файлы остаются с привязанными инструментами; коллекции, содержащие только отдельные сэмплы, показывают их как пресеты. ID загрузок и хеши архивов убраны из отображаемых названий; сохранены номера нот, BPM и take. EDIT выбирает пресет; EDIT+PLAY прослушивает выделенный пресет.

Удерживайте EDIT и нажимайте Left/Right на Preset для последовательного перебора в том же порядке, что и в браузере, переходя в следующую коллекцию и замыкаясь по концам библиотеки. Быстрая прокрутка подготавливает последний выбранный пресет. Текущий пресет остаётся воспроизводимым, пока загружается следующий. При ошибке загрузки выбираемый пресет остаётся активным, а инструмент становится беззвучным. **Error:** и причина выводятся внизу Instrument; циклирование продолжается от этого пресета в обе стороны. Пересканируйте после импорта или изменения файлов библиотеки. Статус пресета отображается прямо под Preset фиксированным цветом. Загрузка не пишет сообщений на SONG или других страницах.

**Native keys** показывает диапазон нот звучания выбранного пресета, считая C4 как MIDI-ноту 60. **(gaps)** значит, что в этих пределах некоторые ноты не имеют зон покрытия. Это объединение нескольких velocity-слоёв; не обязательно каждый velocity или артикуляция звучит на каждой отображаемой клавише. Сэмплы с откликом только на отпускание клавиши не расширяют диапазон. Настройка тона и FX питча не меняют это отображение и не расширяют диапазон.

**Edit**, справа от Preset, открывает экспериментальный редактор SoundFont:
настройка тона (−2400 до +2400 центов), cutoff (20–20000 Гц), резонанса (0–40 дБ), задержки/атаки/удержания/затухания/отпуска огибающей (0–20000 мс), сустейна (0–100%), громкости, панорамы и **Bend step** (1–100 центов за единицу PBN). Новые инструменты используют шаг бенда 1 цент. Старые файлы показывают **Stock**, сохраняя предыдущую шкалу PBN (25 центов для линейного режима, 1 — для period режима); для более мелких изменений укажите Bend step 1. Clear сбрасывает на 1 цент. Это влияет только на SoundFont PBN; FPT остаётся с постоянной настройкой. Громкость и панорама совпадают со значениями инструмента на главной странице. Поля тона и огибающей по умолчанию **Bank**, сохраняя значение каждого слоя из банка. Явное значение переопределяет параметр для всех слоёв пресета. Clear восстанавливает **Bank**, 0 центов для Tune, полную громкость и центр панорамы. EDIT+Left/Right делает мелкие изменения, EDIT+Up/Down — крупные. OPT возвращает назад в Instrument; EDIT+PLAY прослушивает инструмент на песенной ноте или по умолчанию. Это редактирует параметры воспроизведения инструмента, а не карту сэмплов, зоны по клавишам/velocity или луп-поинты банка.

Настройка тона, cutoff и резонанс применяются в реальном времени. Атака, задержка и удержание устанавливаются при note-on. Затухание, сустейн и отпуск могут обновлять воспроизводимый голос; отпуск начинается с note OFF, не только на пустой строке. Затухание не слышно при 100% сустейне. Время отпуска не может удлинять сэмпл за пределы доступного аудио. Явное переопределение отпуска заставляет одношот-сэмпл реагировать на note OFF. При установках Bank сохраняется исходное поведение одношота. Диапазоны по клавишам и velocity пресета остаются авторитетными; ноты вне диапазона молчат. FPT может изменять питч уже выбранного сэмпла за пределы этого диапазона без изменения карты. Правки сохраняются в файлах инструмента и проекта без модификации исходного банка; старые песни без переопределений сохраняют прежние настройки банка.WAV с неизвестным сэмплер-специфичным типом лупа может воспроизводить аудио без этого лупа. В предупреждении инструмента называется игнорируемый тип лупа; исходный файл остаётся без изменений. Прямой WAV луп, заканчивающийся ровно на один сэмпл за пределами аудио, принимается как исключительный конец на границе сэмпла с предупреждением; PCM и явные SFZ/EXS маппинги лупов не меняются. Другие неверные границы лупов и root notes вызывают конкретные ошибки. Один нулевой байт выравнивания RIFF, ошибочно учтённый в нечетной PCM-рамке, игнорируется с предупреждением; другие частичные PCM-рамы остаются ошибками. Стандартные чередующиеся/обратные WAV лупы пока не поддерживаются.

**SoundFont FX** открывает восемь контролов в контекстном выборе Lane FX. Все значения ниже даны в шестнадцатеричной нотации трекера. FX влияют только на свой трек и не меняют сохранённые настройки инструмента. Каждая новая нота начинается с настроек инструмента, затем применяются команды на её строке и последующих.

| FX | Контроль | Значения |
| --- | --- | --- |
| FPT | Pitch | `00` = −24 полутона, `18` = ноль, `30` = +24; точные полутоны |
| FCF | Cutoff | `00`–`FE`: 20 Гц–20 кГц, логарифмически |
| FRS | Resonance | `00`–`FE`: 0–40 дБ |
| FAT | Attack | `00`–`FE`: 0–20 секунд, более точные шаги на малых значениях |
| FHD | Hold | `00`–`FE`: 0–20 секунд перед decay, задаётся на нота-строке |
| FSU | Sustain | `00`–`FE`: 0–100% удерживаемого уровня |
| FDC | Decay | `00`–`FE`: 0–20 секунд, более точные шаги на малых значениях |
| FRL | Release | `00`–`FE`: 0–20 секунд, более точные шаги на малых значениях |

Для FCF/FRS/FAT/FHD/FDC/FSU/FRL значение `FF` возвращает к настройке Edit (включая **Bank**). Attack/Hold ставьте на нота-строку. Decay/Sustain/Release могут менять активную ноту; используйте OFF, чтобы слышать её релиз. Громкость и панорама управляются общими контролами; устаревшие команды FVL/FPN по-прежнему загружаются и играются, но не предлагаются. Pitch FX меняют строй без изменения выделенной зоны ключей банка. Существующие pitch/fine-pitch команды, MODы и эффекты трека остаются доступными. Проекты сохраняют стабильные ссылки на банк/пресет и FX; библиотеки сэмплов остаются внешними.

Все банки — это USER банки. Крупные инструменты могут превысить объём кэша PCM по умолчанию (64 МиБ), не поддерживаемые параметры источника вызывают предупреждения. См. [SoundBanks guide](soundbanks/README.md) для путей платформы, импорта из браузера, настройки кэша, покрытия форматов и текущих ограничений валидации.

#### Совместимость SoundFont: банки, пресеты и модуляция

Один SF2 или SF3 **файл банка** может содержать множество **пресетов** вместе с их сэмплами. Коллекция библиотеки — это папка, используемая для группировки этих файлов в браузере. Это разные уровни: пресет может иметь неподдерживаемое поведение, даже если другие пресеты в том же файле работают хорошо.

**Модуляция пресета** означает программируемые связи от входов, таких как velocity, клавиша, mod wheel или давление, к параметру звука. Эти связи могут принадлежать пресету или внутреннему слою инструмента, разделяемому несколькими пресетами. Это не обязательно настройка, влияющая на каждый звук в банке.

| Особенность пресета | Текущая реализация |
| --- | --- |
| Маппинг сэмплов/клавиш/velocity, root pitch и тюнинг | Реализовано; авторские диапазоны сохраняются. Зоны velocity и обычный tracker velocity работают. |
| Смещения сэмплов, поддерживаемые лупы, усиление/панорама и эксклюзивные группы | Реализовано в парсере и голосовых ограничениях. |
| Статический low-pass фильтр, резонанс и огибающая громкости | Реализовано рендерером трекера; не гарантирует идентичный отклик в других SoundFont-плеерах. |
| Кастомные маршруты модуляции пресета/инструмента (`pmod` / `imod`) | Не реализовано. Авторские маппинги контроллеров, значения и кривые отклика игнорируются. |
| SoundFont LFO модуляции/вибрато и маршрутизация огибающей модуляции | Не реализовано; может отсутствовать запрограммированное движение pitch, фильтра и громкости. |
| Клавиатурно-зависимая огибающая объёма hold/decay, фиксированные генераторы клавиш/velocity | Не реализовано. |
| Посылки в хорусы/реверберации SoundFont | Не реализовано. Эффекты трекера можно ставить вручную, но они не воспроизводят настройки пресета автоматически. |

Сообщение **“Custom bank modulation ignored”** описывает проверку на уровне файла: парсер нашёл кастомную модуляцию где-то в банке. Это **не значит**, что выбранный пресет её использует, или что банк полностью непригоден. Это общее ограничение описано здесь, а не выводится повторно под каждым пресетом. Детальные диагностики парсера сохраняют записи; другие ошибки загрузки и предупреждения совместимости показываются при необходимости. Движок не гарантирует полного поведения стандартных SoundFont-модуляторов. Tracker PBN, вибрато, Edit и Lane FX — независимые контролы, а не автоматический перевод пропущенной пресетной логики.

При выборе библиотеки ориентируйтесь прежде всего на пресеты с поддерживаемым маппингом сэмплов, лупами и статическими огибающими. Звуки, зависящие от контроллерных артикуляций, анимированных фильтров или программируемых LFO, требуют детального сравнения в полном SoundFont-плеере. **Загрузились и играют** не значит **полностью воспроизводят пресет**. Сравнивайте релевантные ноты, velocity, удерживаемые ноты и note OFF. Переконвертация между SF2 и SF3 сама по себе не устраняет эти потребности в модуляции. Конверсия должна трансформировать маппинг и поведение в возможности данного движка; рендеринг эффекта в сэмпл сохраняет только сам результат, не интерактивный ответ контроллеров. См. [формат покрытия и ограничения](soundbanks/README.md#format-coverage) и [примечания по валидации](soundbanks/validation.md) перед выбором или конвертацией банка. Эти ограничения описывают текущую экспериментальную реализацию, а не общие ограничения всех SoundFont-плееров.

#### Просмотр коллекций SoundFont

В SAMPLE → SOUNDFONT **Preset** открывает ваши коллекции. **Right** или **EDIT/A** входит прямо в папку. В конечной коллекции Right переходит к её пресетам; ещё один Right сдвигает на 15 записей без загрузки. EDIT/A загружает выделенный пресет. Left возвращает к коллекциям, затем в родительскую папку; OPT тоже возвращает назад. PLAY запускает/останавливает песню во время просмотра.

Значки папки и звука обозначают записи. Коллекции занимают всю высоту панели. Выбранный пресет остаётся под восемью превью дорожек; длинные имена прокручиваются после секунды бездействия на выборе и сбрасываются при перемещении. EDIT+Left/Right на странице инструмента следует тому же порядку вложенных папок, сохраняя звуки каждой коллекции вместе. EDIT+PLAY прослушивает.

Третья строка сообщает Reading preset, Finding samples, Unzipping, Checking samples или Loading samples. Инструменты EXS с пустыми или `(null)` встроенными именами используют имена файлов. Исходные банки и аудио не меняются. Используйте **Rescan** после изменения файлов вашей библиотеки.

См. [покрытие форматов и ограничения](soundbanks/README.md#format-coverage) о поддерживаемом поведении сэмплера и форматах сэмплов.

### AY Classic, AY Plus и AY Sample

Это оригинальные движки ChipNomad AY/YM. AY Classic даёт аппаратные регуляторы тона, шума и огибающей. AY Plus добавляет софтверные осцилляторы и расширенную модуляцию. AY Sample воспроизводит сэмпл через уровни громкости в AY-стиле; отличается от движка Sampler.

#### AY Classic

Наследуемый тип инструмента из ChipNomad `v1.0.0`. Новый AY Plus предлагает больше возможностей.

Инструменты AY Classic имеют параметры:

- Mixer: тон включён/выключен, шум включён/выключен, форма огибающей (`0-F`)
- Громкость: софтверная ADSR огибающая
- Автоматический период огибающей: вкл/выкл, с частотой от `1:1` до `F:F`

**AY Quality** в Settings влияет только на рендеринг AY/YM. Она не меняет качество Braids, Plaits или Sampler. **Sample dithering** применяется к квантованию AY Sample.

Подробности чипа см. в [документации ChipNomad AY-3-8910](https://chipnomad.org/chips/ay-3-8910/).

#### AY Plus

AY Plus применяет классические концепции синтезатора к AY-3-8910/YM2149F. AY можно представить как синтезатор с 5 осцилляторами:

- 3 тона с квадратным сигналом
- 1 шумовой осциллятор
- 1 генератор амплитудной огибающей, который можно использовать как осциллятор

У каждого инструмента 3 аппаратных осциллятора: тон, шум и огибающая. AY Plus добавляет 4-й, программный осциллятор. Обновление AY-регистров быстрее, чем такт проекта, открывает новые возможности дизайна звука. Осцилляторы смешиваются с кольцевой модуляцией. Экспериментируйте с разными смещениями тона, детюнингом и комбинациями осцилляторов.

Каждый тональный осциллятор можно настраивать независимо по pitch и fine tune.

Типы софтверных осцилляторов и их параметры:

- Pulse — квадратная волна с регулируемой шириной импульса
  - FM Depth — глубина простой FM
  - Pulse width — диапазон `00-FF`, количество шагов задаётся на экране Project
  - Pulse low — управляет низким значением в паре повторений, где высокий всегда `15`
- Sync Tone — эффект жёсткой синхронизации для тона
  - FM Depth — простая FM глубина
- Sync Env — жёсткая синхронизация для огибающей осциллятора
  - FM Depth — простая FM глубина
  - Pulse width — отношение длительности двух форм огибающей в паре
  - Envelope Pair — 2 формы огибающей для переключения
- Wavetable — 32-шаговые волновые таблицы, редактируются на экране Wavetable
  - FM Depth — простая FM глубина
  - Wavetable index
- Tone FM — простой FM-подобный эффект для тона
  - FM Depth — глубина tone FM
- Env FM — простой FM-подобный эффект для огибающей
  - FM Depth — глубина огибающей FM

Pulse и Wavetable нельзя использовать с огибающим осциллятором. Огибающий осциллятор выключается автоматически.

Простая FM быстро переключается между двумя значениями периода: одно ниже, другое выше. Это похоже на использование квадратной волны как FM-модулятора. Pulse, Sync Tone, Sync Env и Wavetable используют отношение `1:1` между FM-носителем и модулятором. Tone FM и Env FM имитируют другие отношения через смещения pitch софтверных осцилляторов.

#### AY Sample

Можно загружать моно и стерео WAV-файлы с разрядностью `8-bit`, `16-bit`, `24-bit` или `32-bit`. Они конвертируются в `8-bit` и усекутся до `16 KB`. Это соответствует размеру страницы памяти ZX Spectrum.

AY воспроизводит сэмплы быстрыми записями в регистр громкости. Выход однополярный, поэтому сэмплы нужно "поднимать к нулю" для чистого звучания. Это убирает щелчки в конце и улучшает затухание.

AY имеет `4-bit` DAC с нелинейной шкалой громкости, поэтому при воспроизведении `8-bit` сэмплы конвертируются в `4-bit`. Опция Sample dithering в Settings улучшает восприятие битовой глубины. Дизеринг неэффективен на ретро-платформах типа ZX Spectrum и Atari ST, поэтому лучше его отключать для реального железа или зернистого лоу-фай звучания.

Сэмплы ведут себя как ещё один софтверный осциллятор AY Plus, но их дополнительные параметры упрощают работу как отдельным типом инструмента.

Параметры сэмпла:

- Частота сэмплирования — при игре с оригинальной частотой звучит как `C-4`
- Start — начало сэмпла
- Length — длина сэмпла
- Loop start — начало лупа
- Pitch offset — смещение тона сэмпла
- Fine pitch offset — тонкое смещение

Секции тонального и шумового осцилляторов совпадают с AY Plus. Из-за особенностей AY осцилляторы смешиваются кольцевой модуляцией.

### Braids

Braids предлагает 47 моделей синтеза. Основные контролы:

- **Model**: осциллятор или алгоритм синтеза
- **Timbre** и **Color**: макропараметры, зависящие от модели
- **Filter**: дополнительный фильтр LP/BP/HP, `12` или `24 дБ` наклон, cutoff и резонанс

#### VCF и VCA

#### Настройки

Глобальные настройки Braids доступны в общих настройках приложения:

### aChChid**aChChid** — монофонический acid басовый движок на базе Open303. `Square` и `Saw` используют встроенный осциллятор TB-303, фильтр, огибающую и поведение акцента. `Braids` заменяет только осциллятор, далее сигнал идёт через тот же 303 фильтр и усилитель. Здесь доступны параметры Model, Timbre, Color и дополнительный waveshaper. Waveshaper плавно переходит от мягкой сатурации к волновому фолдингу.

Cutoff и Decay редактируются логарифмически: **EDIT + LEFT/RIGHT** двигает параметр на один музыкальный шаг, **EDIT + UP/DOWN** — на шестнадцать шагов. Cutoff охватывает 200 Гц — 20 кГц, Decay — 200 мс — 2 с.

`F` в колонке громкости нот запускает акцент. `ASL` скользит к этой ноте от предыдущего тона без перезапуска 303 огибающей; она автоматически удерживает предшествующий гейт, а `ASL 00` даёт 60 мс глайда. `ATY` держит ноту открытой на весь текущий шаг. Ноты без `ASL` всегда перезапускают огибающую.

Назначения модуляции включают Decay и Accent, а в режиме волны Braids — Timbre и Color.

### Bogie

**Bogie** — нативный однострочный драм-синтезатор. Ноты трекера задают питч, а громкость трекера/инструмента — уровень; у каждого триггера своя внутренняя задержка затухания, поэтому ADSR отсутствует. Есть 12 моделей: `Kick`, `Snare`, `Hat`, `Clap`, `Tom`, `Rim`, `FM`, `Noise`, `Cowbell`, `Cymbal`, `Shaker` и `Clave`.

Шесть макросов — **Decay**, **Tone**, **Sweep**, **Noise**, **FM** и **Drive**. Их подписи меняются по смыслу (например, у Kick Noise называется `Click`, у Cowbell FM — металлическая кросс-модуляция). Каждый макрос активен во всех моделях, но музыкально меняет роль: Sweep может менять высоту, интервалы отрывков или металлический спектр; FM — добавлять кросс-модуляцию, металлический слой или окрас типа колокола. Нижняя половина диапазона служит для классических звуков барабанов, верхняя — для расширенных тембральных преобразований и синтетических эффектов.

Все модели используют общий мультимодовый фильтр LP/BP/HP с характеристикой Clean, Classic, Aggro или Acid, с крутизной `12` или `24 dB`, с управлением cutoff и резонансом. Bogie поддерживает активные макросы и модуляцию Volume, Pitch, Cutoff и Resonance, а также запись движений. Короткий Decay на Cowbell даёт острые phonk атаки, увеличение FM добавляет жёсткости и металлической окраски.

На экране модуляции удерживайте **EDIT** на источнике, чтобы выбрать семействo (Envelopes, LFO или Sticks), затем источник. Стрелки Left/Right переключают источники напрямую.

### Sintered

**Sintered** — нативный однострочный цифровой перкуссионный синтезатор. Ноты задают фундаментальный тон; шесть моделей: `Knot`, `Shard`, `Burst`, `Comb`, `Logic` и `Melt`. У каждой модели есть **Decay**, **Mod** и **Motion**, плюс три уникальных параметра: Knot — Ratio/Spread/Fold, Shard — Ratio/Feedback/Bite, Burst — Noise/Color/Feedback, Comb — Time/Damping/Regen, Logic — Rate/Pattern/Crush, Melt — Ratio/Chaos/Drive. **Mod** всегда регулирует глубину внутренней связи.

Motion — внутренняя макро-огибающая: значения ниже `80` задают AD форму, `80` — выключает огибающую, значения выше `80` — decay-only форму. Удаление ползунка от центра ускоряет огибающую. К каждому параметру фиксированы назначения модуляции, чтобы сохранять предсказуемость в трекере: Knot анимирует Mod/Fold; Shard — Feedback/Bite; Burst — Noise/Color/Feedback; Comb — Damping/Regen; Logic — Rate/Crush; Melt — Chaos/Drive. Все модели сбрасывают состояние при запуске ноты и ограничивают внутреннюю обратную связь для повторяемости звуков.

### MonkSynth

MonkSynth - вокальный синтезатор. На странице Instrument он моделирует гласную, характер голоса, придыхание, glide, вибрато, унисон и задержку. EDIT открывает все регуляторы и имя патча.

Выберите банк и пресет на регуляторах VOICE. ALL включает FACTORY и USER; EDIT+PLAY прослушивает выделенный пресет, а EDIT выбирает его. Сохраняйте собственные звуки в `instruments/USER/monk/`. Сохранённые инструменты и песни сохраняют настройки MonkSynth.

Значения шестнадцатеричные `00..FF`, кроме Voices (`01..0A`, от одного до десяти). Attack, decay и release охватывают 0..5 секунд; detune 0..50 центов, а раскрытие голосов 0..0,5. Volume, Pitch и шесть основных голосовых регуляторов доступны как назначения модуляции и motion recording.

Все шестнадцать регуляторов собраны в **MonkSynth FX**: `MWV` (гласная), `MIN` (голос), `MAM` (придыхание), `MFL` (glide), `MFB` (глубина вибрато), `MSH` (скорость вибрато), `MUV` (голоса), `MDT` (detune), `MVS` (раскрытие), `MDM` (микс задержки), `MDR` (скорость задержки), `MLV` (уровень) и `EAT`/`EDC`/`ESU`/`ERL` (ADSR). Эти значения действуют, когда активный инструмент - MONK; существующие значения команд MME не меняются. Общая группа Trigger FX сохраняет TDC/TCL без дублирующих записей огибающей.

### MME

**MME** (Multi Modulation Engine) — синтезатор с двумя осцилляторами, ориентированный на взаимодействие между ними. Модели: `Ring`, `Fold`, `Cross`, `VPM`, `Sync`, `Logic` и `Vocode`. Оба осциллятора внутренние и следуют за нотами трекера; `Interval` регулирует их взаимосвязь.

Шесть макросов — **Waves**, **Interval**, **Amount**, **Flow**, **Feedback** и **Shaper**. Waves интерполируют между музыкальными парами волн A/B. Amount управляет основным взаимодействием, Flow меняет направление или вариант алгоритма, Feedback ограничен, но становится хаотичным в верхнем диапазоне. Shaper — общий финальный эффект, который трансформируется от чистого сигнала через сатурацию до волнового фолдинга.

MME использует общий мультимодовый фильтр LP/BP/HP и ADSR. Все шесть макросов, Cutoff и Resonance доступны для модуляции и записи движений. Удерживайте **EDIT** на Model для вызова меню выбора модели.

### MIDI Out

**MIDI Out** (десктоп, PortMaster и Web MIDI-браузеры) управляет внешним MIDI-устройством вместо генерации звука: при триггере ноты отправляется реальный MIDI Note On на выбранный **Channel** (`1-16`), а при окончании — Note Off. Громкость становится velocity, и голос каждого аккордного трека получает свой Note On/Off. Звука из ChooChooTracker нет — нужно сначала выбрать MIDI-устройство в [Settings](#13-settings). Полная информация в разделе [MIDI](#15-midi), включая превью с MIDI-клавиатуры.

**Program** и **Bank high/low** (CC0/CC32) опциональны — отображаются как `--`, когда выключены; `Clear` отключает поле и запоминает значение. При установке команды шлются один раз перед следующей нотой, если отличаются от предыдущих, чтобы не перезапускать встроенные огибающие/пресеты.

**MC1 number**-**MC4 number** выбирают номера CC (`00-7F`), на которые посылают каждый из четырёх ряда MC1-MC4 FX — см. [MIDI Out FX](#midi-out-fx). Также `--`/опционально; слот без значения делает FX неактивным.

### Classic architecture engines

Движки этой категории используют классическую архитектуру VCO → VCF → VCA.

Доступны типы VCO:

- **Braids**
- **Plaits**
- **Plaits-Alt**
- **Sampler**
- **2xSCWF**
- **BYOWTBL**

Каждый инструмент подаёт VCO в мультимодовый фильтр.

Фильтр с переключаемым наклоном `12 dB` или `24 dB`, работает как низкочастотный (LP), полосовой (BP) или высокочастотный (HP).

Характеристики фильтра:

- **Clean**: стерильный и цифровой
- **Classic**: вдохновлён классическими американскими аналоговыми синтами
- **Aggro**: вдохновлён ревущими японскими аналоговыми синтами
- **Acid**: вдвое агрессивнее Aggro

Classic, Aggro и Acid могут давать сильный резонанс — начинайте с низких значений и аккуратно поднимайте.

Фильтр питается в VCA, управляемый огибающей ADSR. Форма огибающей может менять кривую между экспоненциальной, линейной и логарифмической.

#### Plaits и Plaits-Alt

**Plaits** предлагает 24 движка, сгруппированных так:

| Категория | Движки |

| FM | `02 6-OP FM 1`, `03 6-OP FM 2`, `04 6-OP FM 3`, `10 2-OP FM` |
| Digital | `07 CHIPTUNE`, `15 SPEECH` |
| Texture / Noise | `16 SWARM`, `17 NOISE`, `18 PARTICLE` |
| Physical | `19 STRING`, `20 MODAL` |
| Drums | `21 BASS DRUM`, `22 SNARE DRUM`, `23 HI-HAT` |

**Plaits-Alt** — коллекция альтернативных моделей для оригинального Plaits, более странных и экспериментальных:

| Категория | Движки |
|---|---|
| Granular / Micro | `GLISSON`, `PULSAR`, `GENDY`, `SCANNED`, `LOOPBACK` |
| Phase / Harmonic | `PHASE WEAVE`, `SIDEBAND BANK`, `UNDERTOW`, `ATTRACTOR`, `LOCKSTEP` |
| Acoustic / Physical | `REED PIPE`, `BRASS`, `SHAKERS`, `CLAPS`, `FRESHETS FORMANT` |

Параметры следуют дизайну Mutable:

- **Harmonic** управляет гармоническими отношениями, балансом или выбором модели внутри движка.
- **Timbre** обычно меняет спектр от тёмного/редкого к яркому/плотному.

Значение параметров зависит от движка: например, аккордовые движки используют их для типа аккорда, обращения и волны; физические модели — для материала, возбуждения и затухания; барабанные — для тембра, характера и затухания. См. подробности в руководстве Plaits.

Для `CHORD`, `DIATONIC CHORD` и `WT DIATONIC CHORD` Harmonic показывает имя выбранного аккорда (`MIN`, `MAJ`, `MIN7`, `MAJ7` и т. п.) вместо числового значения. Braids `WAVE PARA` аналогично именует варианты Color.

Нажмите на **Engine** для выбора движка из категорий.

**Env Mode** имеет 2 варианта маршрутизации:

- `TRIG` воспроизводит модуль с соединённым TRIG и незанятым LEVEL
- `VCA` удерживает LEVEL открытым и применяет ADSR трекера после голоса

#### Sampler

Чистый Sample движок воспроизводит моно или стерео PCM сэмплы, загруженные в RAM.- Нажмите **Sample**, чтобы загрузить несжатый `8-bit`, `16-bit` или `24-bit` PCM WAV. Нажмите **PLAY** в браузере, чтобы прослушать выделенный файл.
- Когда сэмпл загружен, рядом с его именем появляется **EDIT**. Нажмите, чтобы открыть экран редактирования Sample. **OPT** или **SELECT + [LEFT]** возвращают к инструменту.
- Экран редактирования Sample показывает имя файла (с маркером `*`, если сэмпл в RAM отличается от файла на диске), информацию о формате (частота дискретизации, каналы), высокий вид формы волны и поля **Region**, **Select**, **Slice**, **Process** и **File**.
- Изменения живут только в RAM до сохранения: проект хранит путь к файлу сэмпла и при следующей загрузке проекта подгружает WAV с диска, поэтому выход из трекера без **Save**/**Save As** отменяет все операции (маркер `*` — предупреждение). Загрузка другого сэмпла в инструмент также сбрасывает несохранённые изменения и возвращает Region на весь сэмпл (Start `00`, End `FF`).
- **Region** задаёт маркеры начала/конца воспроизведения, также доступные на экране Sampler. Они устанавливают нормализованные границы воспроизведения (`00-FF`); если Start после End, сэмпл играет в обратную сторону. **EDIT + [LEFT/RIGHT]** тонко двигает маркер на шаг `01` и зумит вокруг него при удержании **EDIT**; **EDIT + [UP/DOWN]** крупно двигает (шаг 16) и возвращает вид на полный сэмпл. **EDIT + OPT** сбрасывает маркер к значению по умолчанию (Start `00`, End `FF`).
- Вид формы волны зумится на фиксированное окно одну секунду аудио вокруг редактируемого маркера и панорамируется, чтобы держать его видимым; сэмплы, помещающиеся в окно, показываются в полном масштабе 1:1. Зум временный: длится пока держат **EDIT**, отпускание возвращает полный 1:1 вид, как и крупные шаги. При входе в экран вид всегда сбрасывается на весь сэмпл.
- **Select** задаёт область обработки в абсолютных кадрах, независимо от маркеров Start/End воспроизведения. **EDIT + [LEFT/RIGHT]** двигает маркер на 20 кадров и зумит на него при удержании **EDIT**; **EDIT + [UP/DOWN]** прыгает на `frameCount/64` (минимум 16) и возвращает полный вид сэмпла. **EDIT (тап)** на маркере копирует туда текущую позицию Start или End. **EDIT + OPT** на любом маркере очищает выделение. При пустом выделении оба маркера показывают `-`; при инверсии маркеры меняются местами автоматически. Выделение — это состояние редактора только на сессию: оно не сохраняется в проекте, при входе в экран оно инициализируется диапазоном воспроизведения Region (весь сэмпл с настройками по умолчанию).
- **Slice** — одна строка с четырьмя значениями: **Mode**, **Count**, **Slice** и **Frame**, сохраняющимися в инструменте. Off воспроизводит окно Start/End. Ноты Phrase выбирают срезы хроматически с **C-0**, ноты за последним срезом переходят обратно к началу (нота N играет срез `N % count`, поэтому переходы цикличны). Срезы не транспонируют высоту и не используют квантование Scale, но **CRD** сохраняет выбранный срез и транспонирует его голоса как аккорд. Начала срезов отмечены на форме двумя пикселями тёмно-оранжевого цвета; текущий срез подсвечен ярче. Срез под курсором выделен чёрной полосой на волновой форме (цвет выделения не перекрывает эту полосу, она остаётся полностью чёрной и ясно отличимой).
  - **Mode** переключает режимы `OFF` / `EQUAL` / `AUTO` / `LAZY` (EDIT + влево/вправо или тап; EDIT + OPT выключает срезание). При смене режима инициализируются точки среза: **EQUAL** делит окно Start/End равными частями по количеству **Count**; **AUTO** запускает обнаружение атак в окне и ставит срез на каждую найденную (до **Count**); **LAZY** начинает с одного среза на всё окно. Переключение на LAZY сохраняет текущие настройки EQUAL/AUTO (количество и границы), возвращение восстанавливает их точно без подтверждений и потерь. Срез и Stretch взаимно исключают друг друга: при включении одного другой отключается, и ячейки Slice тускнеют, пока Duration контролируется Stretch.
  - **Count** показывает общее число срезов (`01`..`64`). **EDIT + [LEFT/RIGHT]** меняет на один (мин 1, макс 64), **EDIT + [UP/DOWN]** переключает степень двойки из `2 / 4 / 8 / 16 / 32 / 64` с циклом. Любое изменение пересчитывает деление: **EQUAL** делит окно равномерно, **AUTO** заново запускает обнаружение с новым количеством (чувствительность зависит от количества — больше срезов, ниже порог). В режиме OFF поле показывает `-`. В **LAZY** поле яркое (считает вручную поставленные срезы), но только для отображения: курсор его пропускает — вправо от **Mode** или влево от **Slice** сразу встаёт на **Slice**, со строки **Select** с End тоже попадает туда, нажатие не действует (ручные срезы не пересчитываются). **EDIT + OPT** и простой тап не работают здесь: выключение срезов происходит в **Mode**, удаление среза — в **Slice**.
  - **Slice** — браузер 1-индексированного текущего среза (`01`..количество). **EDIT + [LEFT/RIGHT]** переключает срезы по одному, **EDIT + [UP/DOWN]** прыгает на 4 среза (ограничено, без цикла); выбранный срез отмечен ярче и чёрной полосой, зум центрируется на начало среза. **EDIT + OPT** удаляет текущий срез (смерживается с предыдущим; первый срез нельзя удалить, удаление последнего оставшегося выключает режим срезов — границы остаются после OFF и возвращаются при повторном включении). **EDIT (тап)** проигрывает выбранный срез однократно (работает во всех режимах; проигрывание останавливается при отпускании клавиши или выходе из экрана). В режиме OFF поле показывает `-`.
  - **Frame** показывает стартовый кадр текущего среза в HEX. **EDIT + [LEFT/RIGHT]** сдвигает на 10 кадров (с зумом на маркер при удержании **EDIT**), **EDIT + [UP/DOWN]** на 100 кадров и возвращает полный вид. Маркер ограничен своим срезом: не может пересечь начало соседних срезов. **EDIT + OPT** удаляет срез.
  - **B** возвращается к инструменту из строки Slice, как и везде на этом экране; **SHIFT + LEFT** выходит из любого места.
  - **LAZY workflow**: при выборе LAZY нажмите **PLAY** для однократного воспроизведения всего сэмпла — играет один раз с начала и сам останавливается на оригинальной высоте и скорости (зелёный маркер 2 px обозначает позицию на форме волны); повторный тап **PLAY** остановит воспроизведение раньше. Во время игры каждый клик **EDIT** создаёт срез на позиции воспроизведения, независимо от положения курсора (срезы ближе 50 мс от существующих отклоняются с сообщением `Too close to slice`). Повторение воспроизведения сохраняет уже созданные срезы и добавляет новые по каждой нажатой позиции, в порядке — поле **Count** обновляется, браузер **Slice** переходит к новому. Те же правила навигации и редактирования применимы к ручным срезам: **EDIT + направление** на **Slice** листает срезы, **Frame** движет выбранное начало, **EDIT + OPT** удаляет текущий срез. Ячейка Frame тускнеет во время ожидания позиции для нового среза при воспроизведении. **SHIFT + PLAY** не блокируется в LAZY: запускает воспроизведение Phrase как на других экранах. LAZY-срезы воспроизводятся в секвенсоре так же, как EQUAL и AUTO: ноты Phrase хроматично мапятся с **C-0** по ручным срезам, циклично.
  - **Подсказки по сочетаниям**: когда курсор у строки Slice и нет других сообщений, строка статуса показывает подсказку для выделенной ячейки и держит её, пока курсор там. Для **Mode** подсказка зависит от режима и показывает только описание (имя режима уже есть в ячейке): `Divides sample in equal parts`, `Divides sample based on transients`, `Press Play and add slices with EDIT` — при смене режима текст меняется мгновенно, OFF очищает строку. Для **Count** — `Adjust the number of slices`, для **Slice** — `Browse slices`, для **Frame** — `Adjust slice start`. Любое сообщение о действии заменяет подсказку до истечения времени.
- **Process** выбирает деструктивную операцию редактирования: **Crop**, **Normalize**, **Delete**, **Silence**, **Fade In**, **Fade Out** или **Reverse** (EDIT + влево/вправо переключает, тап переключает вперёд, EDIT + OPT снимает выбор). **GO** (в той же строке) запускает операцию на выбранной области или на всем сэмпле, если выделение пусто. **Crop** оставляет только выделение; **Normalize** масштабирует выделение так, что пик достигает максимума (оба канала делят усиление, сохраняется стерео); **Delete** удаляет выделение и склеивает хвосты (удаление всего сэмпла запрещено); **Silence** обнуляет выделение; **Fade In**/ **Fade Out** линейно заворачивают выделение от/до тишины; **Reverse** проигрывает выделение в обратную сторону (кадры меняются местами, оба канала кадра двигаются вместе, длина и маркеры неизменны). Crop и Delete требуют выделения — если выделение пусто, показывают `Select region first`. Каждая операция на секунду ставит аудио на паузу, оставляет один уровень отмены и помечает сэмпл как изменённый в RAM: файл на диске не трогается до сохранения (см. ниже), выход с экрана стирает слот Undo.
- **UNDO** (рядом с GO) возвращает сэмпл в состояние перед последней операцией. Затемнена, пока операция не выполнена, по повторным нажатием переключается между состоянием до и после операции, сбрасывается при повторном входе на экран.
- **File** содержит операции сохранения. Инструмент хранит полный путь WAV-файла, из которого был загружен; эти операции записывают этот файл или указывают инструменту новый. Имя инструмента не меняется.
  - Поле File переключается между **Save** и **Save As** (EDIT + влево/вправо или тап); **GO** (в той же строке) выполняет выбранное действие.
  - **Save** перезаписывает WAV, из которого загружен сэмпл. Для сэмпла без срезов спрашивает сначала `Overwrite <name>?`. Для срезанного сэмпла открывается диалог **SAVE SLICES**, где выбирают, куда сохранить срезы: **SAVE TO SAMPLE** записывает их в WAV как cue-чанки (переносимо — DAW отображают их как маркеры) и сохраняет в проекте, **SAVE TO PROJECT** пишет обычный WAV и оставляет точки срезов только в проекте, **CANCEL** отменяет. Флажок `Don't ask again in this project` сохраняет выбранный вариант с проектом и пропускает диалог (опция сохраняется как `- Sample save choice:` в .cct и меняется только редактированием файла проекта). Диалог пропускается для сэмплов без срезов. **Save** затемнён (и пропускается навигацией), пока не загружен сэмпл с путём файла. Ошибка записи сохраняет маркер изменений и показывает ошибку.
  - **Save As** записывает текущий сэмпл в новый файл: введите имя файла (предзаполнено текущим без расширения), затем выберите папку в браузере. Сэмпл сохраняется как `<папка>/<имя>.wav`, инструмент указывает на новый файл, папка сохраняется как дефолт для сэмплов. Затемнён (и пропускается навигацией), пока нет загруженных данных сэмпла, чтобы свежезагруженному сэмплу можно было задать путь. Пути длиннее 255 символов отклоняются.
  - Маркер `*` перед именем файла означает отличие сэмпла в RAM от файла на диске (ставится при любых процессах, сбрасывается Save и Save As). Маркер сессионный: он не сохраняется и сбрасывается при повторном входе на экран. Если несколько инструментов ссылаются на один WAV, сохранение в одном перезаписывает файл для всех.
- На экране Sample используйте **EDIT + [LEFT/RIGHT]** для загрузки предыдущего или следующего WAV в той же папке.
- **Pitch** транспонирует на полутона (`-48` до `+48`).
- **Loop** выбирает Off, Loop или Ping-Pong.
- **Speed** управляет гранулярным тайм-стретчем от `0%` до `500%` (`100%` — нормальная скорость).Неподдерживаемые форматы WAV вызывают ошибку. Конвертируйте нестандартные файлы в WAV `PCM8`, `PCM16` или `PCM24` перед импортом.

##### Аудиовход

Откройте **Settings → Audio → Audio Input** перед записью с микрофона или USB-аудиоинтерфейса. Список показывает входы, доступные на устройстве в данный момент. Если вооружённый интерфейс отключить, захват прерывается, а аудиоменеджер перезапускается, чтобы приложение продолжало работать. Если вы записывали, нажмите **STOP**, чтобы завершить прерванный дубль. После повторного подключения выберите **[Refresh]** и убедитесь, что нужный вход вооружён, прежде чем записывать снова; одно лишь переподключение не вооружает его надёжно. **[List]** перечитывает текущий список входов без перезапуска аудио.

Отметьте флажок **ARM** у входа, чтобы сделать его доступным рекордеру Sampler; маленький индикатор показывает входной уровень. Вооружайте один интерфейс за раз: эта версия открывает только первый вооружённый интерфейс, даже если отмечено несколько флажков. Ваш выбор запоминается по имени устройства, поэтому недоступный интерфейс остаётся невооружённым, а не заменяется другим входом. Нажмите **OPT**, чтобы вернуться к настройкам Audio.

##### Запись с аудиовхода

На экране инструмента Sample **REC** (или **EDIT/REC**, когда загружен сэмпл) открывает редактор сэмплов, объединяющий запись и редактирование на одном экране. Сначала вооружите входы на экране **Settings → Audio → Audio Input** (см. [Аудиовход](#аудиовход)). Верхние строки редактора управляют записью:

- **Input** перебирает источник записи: `T1`..`T8` записывают восемь дорожек трекера, затем вооружённый микрофон или USB-интерфейс. Чтобы записать внешний источник, продолжайте за `T8`, пока не появится имя устройства. `-` означает, что источник явно не выбран; тогда **REC** использует первый вооружённый вход и показывает его имя. Удерживайте **EDIT** и нажимайте **LEFT**/**RIGHT** для движения назад/вперёд или **EDIT+OPT**, чтобы вернуться к `-`. Касание Input переключает его вперёд.
- Индикатор уровня рядом с **Input** показывает текущий уровень вооружённого входа (только внешние источники). **MON** включает мониторинг входа: вооружённый вход отправляется на выход с -6 дБ для снижения обратной связи. Настройка сохраняется в файле настроек.
- **REC** начинает запись. Внешние источники записываются сразу; источник-дорожка показывает **ARMED**, и запись начинается при запуске воспроизведения (нажмите **PLAY**). **STOP** завершает запись: WAV записывается в папку экспорта проекта (`recNNN.wav`), загружается в текущий инструмент Sampler, а Region снова охватывает весь сэмпл. Выход с экрана по **OPT** во время записи завершает её так же.
- **PLAY** (показывается после записи) прослушивает дубль; во время предпрослушивания превращается в **STOP**. **CLEAR** (рядом) удаляет WAV-файл и выгружает сэмпл из инструмента; после удаления **REC** возвращается на своё место.
- Волна показывает живой вход во время записи и полную волну после завершения. Строка состояния показывает имя файла во время записи и число кадров после; внешний дубль также показывает `drop 0`, если не потеряно ни одного аудиокадра. Записанный сэмпл полностью редактируем: область цикла, выделение, нарезка, обработка и сохранение работают как для любого загруженного файла.

Записи пишутся на выбранной частоте дискретизации как 16-битный стерео WAV. Источники-дорожки захватывают то, что рендерят инструменты дорожки (после FX); внешние источники захватывают вход устройства напрямую.

#### 2xSCWF

2xSCWF — это двойной одноцикловый осциллятор. Загрузите 1 моно WAV, содержащий ровно 1 период, в каждый осциллятор. Оба осциллятора читают вперёд и зацикливаются в конце цикла.

Смешивайте кроссфейды A и B.

Детюн регулируется плавно и экспоненциально от unison до `+200 ct`, затем идёт шагами в полтона от `+3 st` до `+24 st`.

2xSCWF рассматривает каждый файл как таблицу из 1 цикла и читает её ровно один раз за цикл осциллятора. Это позволяет смешивать и детюнить 2 одноцикловых волны.

Папка `waveforms/AKWF/` содержит волны из библиотеки Adventure Kid. В сети доступно множество других, если хотите расширить коллекцию.

#### BYOWTBL

BYOWTBL — двойной вейтбл осциллятор, совместимый с таблицами Serum. Каждый осциллятор загружает моно WAV с последовательными одноцикловыми кадрами. `Pos A` и `Pos B` независимо сканируют таблицы от `00` до `FF`. В движке линейная интерполяция внутри кадра и между соседними. `Mix` кроссфейдит осцилляторы, `Detune` сдвигает осциллятор B.

### Семейство FM инструментов

#### Нативные инструменты OPLL и VRC7

Селектор Instrument Type содержит FM-группу с **OPLL / MSX** (YM2413) и **VRC7** (DS1001). Каждая теперь предлагает **73 программы** в скроллируемых списках Bank / Preset: оригинальные 15 тонов, 40 дополнительных уникальных тонов из таблиц emu2413 YM2413/VRC7/YMF281B и 18 двухоператорных программ от ChooChoo. Точные дубликаты тонов исключены в пределах каждого движка. Дополнительные палитры используют программируемый слот чипа, расширения ROM нет. Программа ноль обозначает кастомный тон. EDIT + влево/вправо переключают предыдущий или следующий пресет в фильтре банка. Fine ct меняет настройку от -100 до +100 центов.

В списке программ EDIT + PLAY прослушивает выделенный звук; отпустите кнопки — остановка. EDIT подтверждает, OPT отменяет. Обзор и прослушивание не меняют инструмент, таблицу или песню. Обычный жест прослушивания на странице инструмента продолжает работать после выбора. Нативные чип-энвелопы обеспечивают атаку/релиз; опциональный Amp env добавляет софтверный ADSR (см. ниже Native chip controls). Полного редактора операторов нет.

#### AdLib / OPL2 и OPL3

FM включает AdLib / OPL2 (YM3812) и OPL3 (YMF262). Bank фильтрует заводской список; Preset открывает категории и общий просмотр All. EDIT + PLAY прослушивает до выбора, EDIT выбирает, OPT отменяет, EDIT + влево/вправо на Preset загружает предыдущий/следующий подходящий. Fine ct регулирует локальную настройку. Mode показывает 2-операторный, 4-операторный или Dual voice режим. OPL2 скрывает несовместимые OPL3 патчи; OPL3 может воспроизводить общий двухоператорный набор.

Заголовки popup для Bank и Preset показывают текущий движок. Переключение движка или слота инструмента сбрасывает фильтр банка на **All banks**, включая смену между совместимыми движками AdLib и OPL3. Возврат из popup в том же слоте сохраняет выбранный фильтр. Отмена импорта банка DX7 восстанавливает предыдущий фильтр.

Подтверждение пресета публикует изменения сразу после отпускания кнопки на следующий UI/audio такт. Воспроизведение песен теперь не требует дополнительного нажатия кнопки или перезапуска транспорта для применения патча. Выход всё ещё следует настроенному аудиобуферу и поведению обёртки/ретриггера движка.

Заводская коллекция содержит 697 исходных записей из The Fat Man 2-op, The Fat Man 4-op и DMXOPL3, с 589 нормализованными уникальными патчами. Алиасы сохраняют исходные имена и авторство. Нативные уровни операторов, флаги глубины LFO, смещения нот, фиксированные тоны перкуссии и настройка Dual voice сохраняются. Громкость трекера использует программную амплитуду; она не воспроизводит оригинальные кривые громкости MIDI-плееров или политику смещения velocity. Оценки длительности релиза исходного патча не обрезают удерживаемые ноты. Некоторые эффекты имеют медленную атаку: удерживайте Seashore, не ожидайте короткого клика, чтобы услышать.

Выбор пресета не меняет таблицу слота и вставки трека.

#### Нативные инструменты Sega PSG и Game Boy

CHIP включает Sega PSG, GB Pulse и GB Noise. Для Sega PSG **Bass range: Extended** сохраняет низкие ноты отчётливыми. Выбирайте **Chip** для оригинального ограниченного диапазона, где низкие ноты сближаются. Фиксированная частота шумов сохраняет исходный тон; шумы из тона подстраиваются под выбранный басовый диапазон. Инструменты GB используют регистры DMG pulse/noise; волновой канал Game Boy не доступен. Их списки пресетов содержат **24, 24 и 28** пресетов соответственно. Добавлены печатные/периодические шумы Sega, GB pitch sweeps, короткая перкуссия, металлический шум, дроны и нарастания. Это оригинальные программы, а не извлечённые игровые звуки. Страница предлагает нативные режимы/duty/width, управление огибающей / sweep / шумом по возможности, плюс софтверный амплитудный ADSR.

#### DX7 FM

Выберите **Type → FM → DX7 FM**; DX7 — седьмой в списке после Arcade / YM2151. DX7 FM использует шесть операторов. На странице доступны Bank, Preset и Fine ct наряду с общими настройками инструмента. Обзор пресетов идёт по спискам банка/категории. Удерживайте EDIT+PLAY для прослушивания выделенного звука; отпускание останавливает. Только EDIT подтверждает на отпускании; OPT — отмена. Загрузка звука копирует полный патч без изменения таблиц трекера или вставок FX на дорожке.

Для постоянной личной библиотеки положите `.syx` файлы в
**`instruments/banks/dx7/`** рядом с существующей библиотекой инструментов. Подпапки поддерживаются. Откройте **DX7 → Bank**: каждый файл появляется как именованный банк для просмотра Preset. Перезагрузите Bank после добавления или удаления файлов; конвертация и Load Instrument не нужны. Стандартный оригинальный банк DX7/TX7 содержит **32 голоса**. Файл с четырьмя сообщениями банка отображается как четыре пронумерованных банка (128 голосов всего). Принимаются и файлы с одним голосом. Выбранный патч сохраняется с инструментом, поэтому удаление исходного банка не меняет песню.

**Load Instrument** также принимает оригинальные DX7/TX7 `.syx` одиночные голоса и банки из 32 голосов. Выберите пресет для использования или отмените, чтобы оставить текущий инструмент. Для постоянной библиотеки используйте папку Bank выше; сохраните песню или `.cni`, чтобы сохранить отредактированный патч. Неподдерживаемые форматы Yamaha отклоняются.

У DX7 ограничение в **16 активных нот всего в песне**, включая аккордовые голоса и релизные хвосты. При достижении лимита хвосты релиза отключаются первыми, затем тихие удерживаемые ноты, чтобы новые атаки оставались сыгрываемыми. Прослушивание пресетов недоступно во время воспроизведения песни.

#### Редактор операторов FM

Genesis FM, Arcade FM, OPL2, OPL3, OPLL и VRC7 имеют кнопку **EDIT** справа от Fine ct. Открывает таблицу параметров патча:

- Genesis FM / Arcade FM
- OPL2 / OPL3: в OPL3 здесь можно менять режим (2op, 4op, dual).
- OPLL / VRC7: редактирование ROM-пресета превращает его в "Custom".

Лево/Право и привычные клавиши редактирования меняют значения; инструмент играет в реальном времени, чтобы слышать изменения. Строка состояния показывает параметр под курсором. OPT или Left+Shift возвращают к экрану инструмента. DX7 и SID редактора операторов не имеют.

Genesis FM (YM2612) и Arcade FM (YM2151) используют общий браузер Bank/Preset, прослушивание и настройку fine-tune, как и другие FM движки. Их нативные огибающие контролируют релиз; изменение громкости или высоты в трекере не ретриггерит их.

#### Заводские и USER пресеты FM

Нативные чип-инструменты используют **Bank:** для выбора ALL, включённой коллекции или USER. **Preset:** выбирает звук в этом наборе. Удерживайте EDIT и нажмите Влево или Вправо на любой строке, чтобы циклить; короткий тап EDIT открывает выбор.

Включённые коллекции — ZIP-паки в `instruments/FACTORY/`. USER-файлы — в `instruments/USER/<engine>/`: `dx7`, `opll`, `vrc7`, `opl2`, `opl3`, `genesis`, `arcade`, `sid`, `sega`, `gb-pulse` или `gb-noise`. Просматривайте папки напрямую или кладите туда ZIP с совместимыми пресетами. ZIP остаются целыми на диске. Все эти папки принимают совместимые `.cni` файлы; CNI — портативный формат инструментов ChooChoo/ChipNomad, не стандарт производителя чипов. Браузер USER также читает следующие исходные форматы, включая ZIP:

| Папка USER | Дополнительные форматы |
| --- | --- |
| `dx7` | Yamaha DX7/TX7 `.syx` одиночные голоса и банки из 32 голосов |
| `genesis` | `.tfi`, DefleMask `.dmp`, Furnace `.fui` |
| `arcade` | VOPM `.opm` банки, DefleMask `.dmp`, Furnace `.fui` |
| `opl2`, `opl3` | `.wopl`, `.opli`, `.woplx`, `.sbi`, Furnace `.fui` |
| `opll`, `vrc7` | Furnace `.fui` кастомные патчи и выбранные ROM пресеты |
| `sega`, `gb-pulse`, `gb-noise` | Furnace `.fui`, DefleMask `.dmp` |
| `sid` | GoatTracker 2 `.ins` (GTI5), Furnace `.fui` |

Банк открывается в совместимые голоса. Неподдерживаемые файлы или функции показывают причину; несовместимые голоса в смешанном банке исключаются, сохраняя стабильные исходные номера. Загрузка атомарна: отвергнутый пресет не меняет текущий инструмент. Исходные пресеты заменяют таблицу трекера инструмента пустой, кроме DX7 SysEx, который сохраняет существующую. CNI восстанавливает сохранённую таблицу. Загрузанные патчи принадлежат песне и продолжают работать после перемещения или удаления исходного пакета.

WOPL банки могут содержать пустые слоты без явного флага. Браузер пропускает безымянные слоты с полностью аттенюированными операторами и без атаки. Безымянные играемые голоса доступны как `Program N [Bbank]` или `Drum N [Bbank]`, используя нулевой индекс программы и банка источника. Безымянный одиночный инструмент OPLI берёт имя из имени файла. Безымянные тихие патчи сохраняются.

Файлы Furnace, DefleMask и GoatTracker импортируются как инструменты, не целые песни. Анимированные макросы, сэмплы и специфичные настройки воспроизведения могут не переноситься. Положите файлы Game Boy в назначенную папку Pulse или Noise.

Циклирование User пресетов продолжается по файлам, папкам, банкам и ZIP по обеим направлениям с зацикливанием на концах. Повторное открытие браузера USER следует текущему выбору. ALL включает USER звуки в Unsorted для категоризированных движков; USER остаётся отдельным верхним уровнем. Sega PSG и Game Boy используют плоские списки ALL/Factory и иерархический браузер USER без панели Unsorted. Старые файлы DX7 в `instruments/banks/dx7/` остаются доступны из USER.

Движок показывает только совместимые включённые коллекции. Factory Presets объединяют включённые наборы тонов OPLL/VRC7 для выбранного движка; DX7 — оригиналы ChooChoo и YSE. Загруженные именованные коллекции остаются отдельными. Fat Man 2-op в списке OPL2, Fat Man 4-op в OPL3. Совместимые OPL2 CNI файлы можно использовать в OPL3 USER.

#### Нативное управление чипом

Превью волновых форм нативных инструментов обновляется при перерисовке их контролов. FM инструменты могут накладывать опциональную кривую Amp env; SID сохраняет превью волны без этого FM-специфичного оверлея, включая просмотр банков и пресетов.

Все семь FM движков предлагают **Bright**, **Feedback** и **Amp env**. Bright варьируется от -63 до +63, при нуле патч сохраняется; меняет уровни операторов модуляции, сохраняя уровни несущих. Его слышимый эффект зависит от алгоритма. Feedback по умолчанию из **Preset**, или задаётся вручную от 0 до 7, заменяя нативный feedback. Эти управления не переписывают сохранённые нативные байты операторов.Амплитудный огибающий генератор по умолчанию стоит в положении **Bypass**. Выберите **ADSR**, чтобы добавить атаку, спад, удержание, релиз и форму вокруг исходного звука. A/D/R используют общий квадратичный диапазон от 0 до 5 секунд; уровень удержания изменяется от тишины до полной громкости. Исконные огибающие всё ещё работают, поэтому этот огибающий генератор не может удлинить звук за пределы его родного релиза. При переключении пресетов сохраняются FM амплитуда и тональные параметры слота.

Следующие FX-фразы также доступны как поддерживаемые пункты модуляции и записи движений. Значения в колонке FX заданы в шестнадцатеричном формате. Настройки влияют на воспроизведение, не изменяя сохранённый инструмент. Родные параметры GB sweep и огибающей замыкаются на следующий триггер ноты; duty/width и частота шума могут изменяться в реальном времени.

| Engines | FX | Control |
|---|---|---|
| Native FM | `OL1`–`OL6` | Абсолютные уровни выхода операторов: модулятор OPLL/VRC7 и OPL `00–3F`; карриер OPLL/VRC7 `00–0F`; Genesis/Arcade `00–7F`; DX7 `00–63` (0–99). Чем выше, тем больше выход. Отображаются только поддерживаемые операторы. |
| OPLL/VRC7/OPL2/OPL3 | `OAR`, `ODR`, `ORR`, `OSL` | Аттак, decay, release и уменьшение сустейна оператора 1, диапазон `00–0F`. |
| OPLL/VRC7/OPL2/OPL3/Genesis/Arcade | `OMU 00–0F` | Мультипликатор частоты оператора 1. |
| Genesis/Arcade | `LFR` | Родная частота LFO: Genesis `00–07`, Arcade `00–FF`. |
| Arcade | `LAD`, `LPD 00–7F` | Отдельные глубины амплитуды и питча LFO. |
| Genesis/Arcade | `LAS`, `LEN` | Родная амплитудная чувствительность `00–03` и включение LFO `00–01`. |
| Genesis/Arcade | `LPS 00–07` | Родная чувствительность к питчу. |
| SID | `SAT`, `SDE`, `SSU`, `SRL 00–0F` | Родные параметры атаки, спадa, сустейна и релиза. Значения времени растут к `0F`; сустейн — к полной громкости. |
| SID | `SPR 01–10` | Частота silent partner от 1× до 16×; влияет на кольцевую модуляцию и хард-синхронизацию. |
| Все native FM | `FBK 00–07` | Абсолютная родная обратная связь, инициализированная из инструмента. |
| Все native FM с включённой Amp env; Sega/GB | `EAT`, `EDC`, `ESU`, `ERL`, `ESH 00–FF` | Аттак, decay, сустейн, релиз, форма. Не активируют обходной FM амплитудный огибающий генератор. |
| Sega PSG | `CMD 00–02`, `CNR 00–03` | Тон/белый шум/периодический шум; три фиксированных скорости шума или скорость, зависящая от тона. |
| GB Pulse | `CMD 00–03` | Родной duty пульсации. |
| GB Noise | `CMD 00–01`, `CND 00–07`, `CNS 00–0D` | Ширина шума, частота тактового делителя и сдвиг. |
| GB Pulse | `CSP 00–07`, `CSS 00–07`, `CSD 00–01` | Период sweep, сдвиг, направление вниз. |
| GB Pulse / Noise | `CEI 00–0F`, `CEP 00–07`, `CED 00–01` | Родной начальный уровень огибающей, период, направление подъёма. |

Выбор Native FX происходит с использованием инструмента, указанного в колонке `I` строки фразы, либо активного инструмента, найденного при поиске назад, если `I` пусто. Всплывающее окно FX показывает краткое описание управления, текущее значение пресета и допустимый диапазон команд в компактном блоке. Выбор другого native эффекта начинается с сохранённого значения; повторный выбор того же эффекта сохраняет отредактированное значение. Мультистрочный выбор обрабатывает инструменты каждой строки отдельно. Таблицы работают в контексте соответствующего инструмента. Изменения значений native прекращаются на их разрешённых пределах, включая duty, шум, sweep, ADSR, feedback и уровни операторов. Значения заданы в шестнадцатеричной системе: например, максимум `63` для DX7 соответствует десятичному 99.

#### SID инструменты и Phrase FX

Выберите **CHIP → SID**. Банк предлагает **ChooChoo SID Originals** и **SIDkit Effects**. Просматривайте, прослушивайте и сохраняйте их как и другие пресеты native-чипов.

Страница инструмента содержит параметры формы волны/ширины импульса, режим фильтра/среза/резонанса и родные ADSR-контролы. **EDIT**, рядом с названием пресета, открывает **SID EDIT**. Волна и PW имеют отдельные метки; фильтр содержит строку режима, затем срез и резонанс; ADSR метки находятся рядом со значениями. Касание каждого поля выбирает точный параметр. Сохраняются существующие диапазоны параметров и поведение точной/грубой настройки.

SID EDIT использует компактные ряды FM редактора, цветовую схему темы, шестнадцатеричные значения и управление EDIT+направлением. OPT или Left+Shift возвращают назад; EDIT+PLAY прослушивает инструмент. Страница редактирует сохранённый патч напрямую, поэтому изменения сохраняются вместе с инструментом и проектом.

SID EDIT группирует форму волны, кольцевую/синхронизирующую модуляцию, ADSR, ширину импульса, фильтр, движение, арпеджио, sweep питча и вибрато. Строка состояния показывает описание каждого параметра и его диапазона. Кольцевая и синхронная модуляция используют по два из четырёх доступных голосов SID, позволяя создавать аккорды с меньшим количеством нот при их активации.

| FX | Диапазон | Действие |
| --- | --- | --- |
| `SCP` | `00–FF` | Базовая ширина импульса, масштабируется до родной 12-битной ширины; движение pulse из рецепта остаётся активным. |
| `SCT` | `00–FF` | Базовый срез, масштабируется до родного 11-битного среза; движение фильтра из рецепта остаётся активным. |
| `SRN` | `00–0F` | Родная резонансность. |
| `SWV` | `00–07` | Triangle, saw, tri+saw, pulse, tri+pulse, saw+pulse, tri+saw+pulse, noise. |
| `SFI` | `00–07` | Биты режима фильтра: 1 – low-pass, 2 – band-pass, 4 – high-pass; 0 — обход. |
| `SMR` | `00–FF` | Частота рецепта в Гц, масштабирована от 1 до 200 Гц. |
| `SRG` | `00–01` | Треугольная кольцевая модуляция с silent partner. |
| `SSY` | `00–01` | Синхронизация осциллятора с silent partner. |

Ширина импульса и срез поддерживают `SLE`. Дискретные формы волн, переключатели, резонанс и обратная связь FM сохраняют полезные родные шаги; более широкие байты не создадут больше состояний железа. `FBK` напрямую выбирает обратную связь в диапазоне `00–07`. Уровни операторов используют указанные выше диапазоны, характерные для движка. Яркость и мастер-вазы сохраняют полный байтовый диапазон.

#### Заводские и USER пресеты для SID и native-чипов

Инструменты native-чипов используют **Bank:** для выбора ALL, включённой коллекции или USER. **Preset:** выбирает звук внутри выбранного банка. Удерживая EDIT, нажмите Left или Right на любой строке для переключения; короткое нажатие EDIT открывает выбор.

Включённые коллекции — ZIP-паки в `instruments/FACTORY/`. USER-файлы размещаются в `instruments/USER/<engine>/`: `dx7`, `opll`, `vrc7`, `opl2`, `opl3`, `genesis`, `arcade`, `sid`, `sega`, `gb-pulse` или `gb-noise`.
Открывайте папки напрямую или поместите там ZIP с папками и совместимыми `.cni` пресетами. DX7 также поддерживает совместимые `.syx` одиночные голоса и банки на 32 голоса, включая архивы ZIP. ZIP остаются неповреждёнными на диске. Прямой загрузки WOPL/WOPLX нет; используйте совместимые CNI или конвертируйте исходные форматы офлайн.

Цикл USER пресетов продолжается по файлам, папкам, банкам и ZIP-пакам в обе стороны, замыкаясь на концах. Повторное открытие USER-браузера сохраняет текущий выбор. ALL включает USER-звуки в Unsorted для категоризированных движков; USER остаётся отдельным верхним уровнем. Sega PSG и Game Boy используют плоские списки ALL/Factory и иерархический USER-браузер без панели Unsorted. Старые файлы DX7 в `instruments/banks/dx7/` остаются доступными в USER.

Движок показывает только совместимые включённые коллекции. Factory Presets объединяет включённые наборы тонов OPLL/VRC7 для выбранного движка; DX7 объединяет ChooChoo и YSE Originals. Загруженные именованные коллекции остаются отдельными. Fat Man 2-op указан в OPL2, а Fat Man 4-op — в OPL3. Совместимые OPL2 CNI-файлы можно использовать в папках USER OPL3.

## 6. Модуляция и запись движений

Для каждого инструмента доступно до 4 слотов модуляции. Аудиоинструменты могут нацеливаться на **Instrument Pan** или **Track Pan**; оба используют `00` — влево, `80` — центр, `FF` — вправо.

Доступные типы модуляции:

- ADSR — классический огибающий аттак-декей-сустейн-релиз
- AHD — огибающий аттак-холд-декей
- LFO — низкочастотный осциллятор с разными формами
- syncLFO (прежний SLFO) - LFO с настройкой тиков на единицу и множителем периода
- slowLFO - длинные циклы с пропорциональным регулятором периода, начинающиеся сразу за диапазоном обычного LFO
- FLFO — LFO на аудиочастоте, достигающий кГц; сильно нагружает CPU
- SLIN — линейное джойстиковое управление
- SRAT — управление скоростью джойстика
- Sequence - читает последовательность трекера как сигнал модуляции: **PITCH** - итоговая секвенированная высота, **VOL** - итоговая секвенированная громкость, **TRANCE GATE** - независимый ритмический модулятор. Motif, Rate и Length выбирают рисунок гейта; Trigger определяет, работает ли он свободно, перезапускается с каждой нотой или сбрасывается на границах фразы или цепочки. Закрытые гейты дают ноль, открытые - половинный уровень, а Accents равномерно (по Евклиду) распределяет гейты полного уровня среди активных. Не использует и не меняет вставки дорожки.

Список назначений модуляции зависит от типа инструмента.

Когда огибающий ADSR или AHD нацелен на Volume, он становится огибающей громкости инструмента. LFO на Volume смещает текущий выходной уровень громкости.

Величина модуляции может быть положительной или отрицательной. Диапазон зависит от назначения. Если полный диапазон назначения ≤127, как для большинства параметров, величина задаёт абсолютный диапазон. Для более широких назначений, например питча, используется масштабированная величина.

У источников Sequence PITCH и VOL есть **Mode**. **Normal** оставляет значение трекера слышимым и одновременно использует его как модуляцию. **Bypass** делает его только источником: PITCH повторно запускается на последней высоте (или C-4 на первой ноте), а VOL держит последний слышимый уровень. Trance Gate уже только источник. Если любой активный слот Sequence ставит PITCH или VOL в bypass, побеждает bypass. Чтобы избежать обратной связи, PITCH и VOL не могут указывать на Pitch или Volume.

Все временные параметры, включая аттак, холд, декей и период, измеряются в тиках.

**syncLFO** - прежний SLFO: настройте его тики и множитель для движения, синхронизированного с темпом. Существующие настройки SLFO и песни сохраняют тот же тайминг.

Используйте **slowLFO** для развёрток длиннее, чем может обычный LFO. Его регулятор Period идёт от 256 до 131 072 тиков. Все LFO на тиках следуют темпу песни и разделяют одни и те же формы, выбор wavetable и режимы триггера. Выберите Free для развёртки, продолжающейся между нотами; Retrig, Phrase и Chain перезапускают её на соответствующих границах.

Формы LFO:

- Tri — биполярная треугольная волна
- Sin — биполярная синусоида
- UniTri — унимодальная треугольная волна
- UniSin — унимодальная синусоида
- RampDn — линейный спад (пила вниз)
- RampUp — линейный подъём (пила вверх)
- ExpDn — экспоненциальный спад (экспоненциальная пила вниз)
- ExpUp — экспоненциальный подъём (экспоненциальная пила вверх)
- Square — квадратная волна
- Random — сэмпл-энд-холд случайная волна
- Wavetable — читает одну из 32-шаговых AY вейвтейблов проекта. Значения `00`–`0F` отображаются от `-100%` до `+100%` без интерполяции.

Типы триггеров LFO:

- Free — перезапуск LFO только при смене инструмента
- Retrig — перезапуск LFO на каждой ноте
- Phrase — перезапуск LFO, syncLFO и slowLFO при входе в новую фразу
- Chain — перезапуск LFO, syncLFO и slowLFO при входе в новую цепочку
- Hold — после 1 цикла останавливается и удерживает последнее значение
- Once — после 1 цикла останавливается и возвращается к нулю

### Запись движений

- **STICK LIVE** (`L1` по умолчанию) применяет модуляцию стиком без изменения фразы. В **Settings > Stick live mode** `HOLD` (по умолчанию) включает модуляцию при удержании; `TOGGLE` включает при первом нажатии и выключает при следующем; `FREE` оставляет включённой постоянно. Отпускание кнопки в режиме `TOGGLE` оставляет её включённой.
- Во время воспроизведения удерживайте **MOTION RECORD** (`L2`), чтобы применить модуляцию стиком и записать изменённые назначения как абсолютные значения FX.
- Удерживайте **MOTION ERASE** (`R2`), чтобы удалить совпадающие FX назначения из текущей строки.

В правом нижнем углу `~` означает активный Stick live. Индикаторы записи (`*` или `!` при переполнении) и удаления (`x`) имеют приоритет и моментальны в обоих режимах. Оба нажимаемых переключателя позволяют обрабатывать модуляцию стиком в реальном времени при удержании; отпускание их не отключает отдельно включённый live toggle.

Режим сохраняется в настройках приложения, но переключатель live всегда выключен при запуске. Смена режима сбрасывает toggle: `HOLD` следует за удерживаемой кнопкой Stick live, `TOGGLE` ждёт нового нажатия, `FREE` активен сразу.

Запись движений записывает трековые FX в текущую воспроизводимую фразу. Сначала обновляются совпадающие FX, затем используются свободные слоты справа налево. Запись не перезаписывает другие FX. Если все 3 слота заняты, движение не записывается на шаге. `!` в правом нижнем углу обозначает, что изменилось больше назначений, чем помещается в 3 FX колонки.

Запись движений поддерживает назначения Braids, Plaits, Sampler, 2xSCWF, BYOWTBL и Bogie, включая активные макросы Bogie и управление фильтром там, где возможно.

## 7. Вставные эффекты трека

Каждый из восьми треков имеет два последовательных слота, **TF1 → TF2**. Чтобы открыть MOD из Instrument, используйте привычное Shift+Up, затем снова Shift+Up для **F: Insert FX**. Shift+Down возвращает к MOD. OPT+Left/Right переключает трек (1–8), не изменяя выбор инструмента. Заголовок модуля открывает текущий выбор; обход (bypass) сохраняет модуль, настроенные значения и автоматизацию. Параметры — байтовые значения: левая колонка 1–4, правая 5–8. Контекстный текст показывает полные имена и расшифрованные значения. Старые проекты загружаются с обоими слотами в выключенном состоянии.

Навигационный дисплей постоянно отображает полный столбец F–M–I–P на всех экранах инструмента, включая Insert FX и пул инструментов, выделяя текущий экран.| Модуль | Параметры в порядке |
| --- | --- |
| Work Compressor | Threshold, Attack, Release, Makeup, Ratio, Detector source, Detector filter, Mix |
| Airwindows Distortion | Input, Mode, Output, Mix |
| Airwindows StereoDoubler | Detune, Mix |
| TAPESCAM | Input, Drive, Color, Wobble, Tone, Output |
| OTT (Rui-727) | Depth, Time, Upward, Downward, Input, Output |
| Chorus | Rate, Depth, Tone, Mix, Feedback |
| Flanger | Rate, Depth, Feedback, Mix |
| Phaser | Rate, Depth, Feedback, Mix, Stages |
| Rotary | Speed, Depth, Drive, Mix |
| Saturation | Drive, Tone, Level, Mix |
| Bitcrusher | Bit depth, Rate reduction, Tone, Mix |
| Destruction | Mode, Amount, Tone, Mix |
| FORMANT | Mode, Vowel, First formant, Second formant, Resonance, Mix |
| Trance Gate | Pattern, Rate, Length, Gate, Phase, Mode, Smooth, Mix |
| Beads (Mutable Instruments) | Time, Size, Density, Pitch, Scatter, Feedback, Shape/Freeze, Mix |

Непрерывные регуляторы используют значения 00–FF, включая допустимые ноль и максимум FF, кроме FORMANT VOW (00–7F). Биполярные регуляторы имеют точный нейтралитет на 80. Режимы distortion: 00 Density, 01 Drive, 02 Spiral, 03 Mojo, 04 Dyno. Соотношения сжатия 00–07: 1.5, 2, 3, 4, 6, 8, 16, 20:1; Compressor Detect 00–02 слушает собственный стереовход, левый или правый; 03–0A слушает вместо этого дорожки 1–8. Фильтр детектора 80 нейтрален, ниже - низкочастотный, выше - высокочастотный. Источник-дорожка берётся после её громкости, панорамы и Tilt EQ, но до её вставок; заглушённый или отсутствующий источник даёт тишину. В любом слоте может быть любой модуль; повторяющиеся модули независимы. Chorus и Phaser начинают с слышимой, но контролируемой модуляции. Для почти прозрачного эффекта уменьшите Mix, Depth или Feedback; высокие значения Depth, Feedback и Mix создают умышленно экстремальный эффект. Flanger и Rotary используют мягкие значения модуляции по умолчанию. Скорость Rotary охватывает весь диапазон **00-FF**: **00 = 0.01 Гц** (один оборот за 100 секунд), **FF = 25 Гц** (максимум Chaos). Экспоненциальное распределение обеспечивает точное управление низкими скоростями LFO. Новые вставки Rotary устанавливаются по умолчанию в **8F**, около 0.8 Гц. Это заменяет четыре дискретных значения скорости; существующие настройки Rotary и автоматизация скорости F11/F21 требуют настройки под новый масштаб (старые Slow/Fast/Hyper/Chaos примерно соответствуют **8F/CB/E7/FF**). Остальные параметры не изменены. Глубина битов Bitcrusher — от 4 до 16 бит, редукция скорости — от 1x до 32x. Режимы Destruction — Fold, Clip и Crush. Saturation и distortion имеют управление выходным уровнем или миксом для балансировки с необработанным сигналом. Параметрический эквалайзер имеет полки ±24 дБ на 60–500 Гц и 2–14 кГц, а также колоколообразный фильтр с фиксированным Q=0.9 на 250 Гц–5 кГц. Контроллеры усиления нейтральны на 80; при нейтрали всех трёх он точно обходит сигнал. Активный EQ строит плавный мягкий сгиб при превышении полного сигнала и достигает максимума 1.5 для контроля экстремальных подъёмов.

Trance Gate — амплитудный sequencer, синхронизированный с темпом, для падов, лидов и стэбов. Значения Pattern 00–3F выбирают именованные музыкальные мотивы: 00–1F — основные грувы, 20–3F — экспериментальные варианты. Rate предлагает прямые, триольные и точечные значения от 1/2 до 1/32. Length усечёт независимо повернутый 16-шаговый мотив до 1–16 шагов. Каждый note-on трека перезапускает последовательность; note-off оставляет её работать через релиз. Forward, Reverse и Ping-Pong задают порядок проигрывания; Chaos применяет повторяемую мутацию с сохранением плотности каждые четыре цикла. В мастере вставка следует за транспортным временем без повторных триггеров. Gate задаёт ширину каждого открытого шага, Smooth сглаживает края, сохраняя минимальный безщелчковый фэйд, Mix кроссфейдит между сухим и заблокированным аудио.

**Beads** использует оригинальную гранулярную обработку Mutable Instruments как стерео вставку. Выберите Beads в слоте вставки дорожки. Восемь регуляторов также используют существующие команды F11–F18 / F21–F28 и вставочные MOD назначения; новых FX ID и формата проекта не требуется. Зерна запускаются непрерывно без дополнительный событий.

- **Time:** позиция в четырёхсекундном буфере записи.
- **Size:** длинные реверсные зерна при 00, самые короткие зерна около 55, затем постепенно увеличивающиеся вперёд. FF включает оригинальный режим задержки после перехода.
- **Density:** регулярные зерна ниже центра, случайное время выше; центральная зона останавливает новые зерна. Отдаление от центра увеличивает частоту.
- **Pitch:** −24 до +24 полутона; 80 — точный унисон.
- **Scatter:** 00 — отсутствие случайности параметра. Увеличение включает внутреннюю равномерную случайность Time на полной величине и Size на половине, независимо для каждого зерна. Pitch и Shape остаются фиксированными.
- **Feedback:** возвращает обработанные зерна в путь записи.
- **Shape/Freeze:** 00–7F — запись, 80–FF — заморозка. Внутри диапазона младшие 7 битов изменяют огибающую с прямоугольной через спад и колокол до реверса. Добавление/вычитание 80 переключает freeze без изменения Shape: 40 и C0 имеют одинаковую огибающую. Подсказка показывает позицию огибающей и статус записи/заморозки. Зажмите EDIT + Up/Down для изменения на 10 hex (16); Left/Right меняет на 1. Управление упаковано дискретно, так что перемещение не пересекает бит freeze; модуляция всего байта может умышленно переключать состояния.
- **Mix:** 00 — сухой сигнал, FF — полностью обработанный. Изменения сглажены.

Freeze удерживает текущее захваченное аудио; выбор другого модуля или сброс Beads очищает его. Реверберация трека остаётся доступной.

### Заставить кик качать микс или другую дорожку

Для качающего мастера поставьте кик на дорожку 1, выберите Compressor в MASTER FX, установите Detect 03 (Track 1), Ratio 04 (6:1), Attack около 60 (примерно 1,6 мс), Release около C0 (примерно 115 мс), Makeup 00 и Mix FF. Понижайте Threshold, пока остальные звуки не начнут проседать на каждом кике, затем подстройте Release, чтобы они успевали восстановиться до следующего. Прямой звук кика сохраняет собственные вставки дорожки, но обходит два мастер-слота вставок; его возвраты реверберации и задержки всё равно качают.

Чтобы приглушать только бас, пэд или синтезатор, поместите его Compressor на эту дорожку и выберите дорожку кика через Detect. Исходный кик остаётся слышимым, а его громкость не меняется компрессором этой дорожки. Кик и бас, объединённые на одной дорожке, при такой маршрутизации разделить нельзя.

### FORMANT

Выберите **FORMANT** в TF1 или TF2, чтобы формировать звук в гласноподобные тона. Лучше всего работает с протяжным источником, богатым гармониками, например пилообразной волной.

Установите MODE в `00` VOW и используйте **VOW** для развёртки от A (`00`) до U (`7F`) через E, I и O. Установите MODE в `01` CUSTOM, чтобы настроить **F1** и **F2** самостоятельно. **RES** сужает или расширяет гласный характер; **MIX** смешивает эффект с исходным сигналом. Используйте MOD → INSERT FX для движения активных регуляторов. MODE не является назначением MOD.

### Lane FX для вставок

Команды вставок используют **F11–F18** для TF1 и **F21–F28** для TF2. Выпадающий список FX и окно Phrase/Table показывают только параметры, используемые выбранными в треке вставками. Группировка: **TF1: имя эффекта** и **TF2: имя эффекта**; слоты OFF скрыты. Отключённые вставки доступны для редактирования. В окне FX для Phrase и Table описание следует за слотом вставки трека: показывает модуль, название параметра, декодированные границы и сохранённое значение. Если при смене модуля команда становится неактуальной, она сохраняется; выбор параметра начинается с доступного управления. В процессе редактирования в подсказке снизу показывается декодированное значение и единицы измерения.

Любой столбец Phrase или Table FX может управлять любым слотом; сетка Phrase сохраняет свои три столбца. Эти значения сохраняются во время проигрывания, между нотами, инструментами, фразами, цепочками и обычными петлями. Перезапуск или принудительная остановка сбрасывают их. Изменение базового значения на странице F сбрасывает только этот параметр в переопределении. MOD действует на итоговое базовое/автоматизированное значение, не сохраняя смещения. Выбор нового модуля восстанавливает значения по умолчанию и сбрасывает переопределения слота. Байпас сохраняет автоматизацию, приостанавливая обработку после короткого фэйда.

**Адресация относится к слотам трека/позициям параметров, а не к именованным эффектам.** Повторно используемая Phrase на другом треке подключает модули этого трека. Смена модулей может изменить смысл команды, они не переписываются. Адреса OFF/неиспользуемые безопасны и остаются в сохранённых данных Phrase/Table.

Выбор MOD инструмента добавляет категорию Insert FX. Источники инструмента управляют вставками на любом треке, который играет его, включая сложенный сигнал аккорда. Один и тот же инструмент на двух треках влияет на разные цепи. Правила синхронизации, знаковые значения, сочетание источников, режимы стик и запись движений сохраняются. Дискретные регуляторы квантизированы и ограничены доступными значениями. Нет новой модульной банковской системы модулей, принадлежащей треку.

Начинайте с нескольких вставок, следите за перегрузками и треском, отключайте эффекты, не помогающие песне. Настройки Drive и усиления могут клиппировать микс, используйте индикатор клипа Mixer для контроля.

## 8. Таблицы

Таблицы — ключевой инструмент звукового дизайна в трекерах. В терминах Vortex Tracker они сочетают инструменты и орнаменты, но могут делать гораздо больше. Если вы знакомы с LSDj или NerdSEQ, идея будет знакома.

Столбец Pitch принимает относительные (`~`) или абсолютные (`=`) значения в полутоновах. Столбец Volume — `00`-`0F`, влияет на каждый движок поверх огибающей и может использоваться как гейт: чередуйте `0F` и `00` и затем зацикливайте с `HOP 00`. 4 FX дорожки в основном совпадают с дорожками фразы, хотя некоторые FX ведут себя иначе в таблицах.

FX `TIC` в последней строке таблицы устанавливает скорость колонки и переопределяет стандартную скорость таблицы инструмента. Каждая колонка FX может иметь свою скорость. Pitch и Volume следуют скорости первой колонки FX.

16 строк могут выглядеть мало по сравнению с длинным инструментом Vortex Tracker, но FX `HOP` создаёт условные циклы вроде «повторить эти строки 5 раз», а также вложенные циклы. Вместе с циклами и независимой скоростью FX колонок, эти 16 строк могут использоваться очень эффективно.

Можно копировать и вставлять lane FX между фразами и таблицами ;)

### Режим рестарта

Поле `Retrig` в верхней части экрана Table выбирает, когда перезапускать уже активную таблицу. `Inst` — режим по умолчанию и совместимый: строка с инструментом выбирает таблицу по умолчанию этого инструмента и запускает её с `00`. `Phrase` рестартует активную таблицу при входе в фразу, `Chain` — при входе в цепочку, `Free` — оставляет таблицу играть до остановки трека или явной замены командой.

Структурный режим не смотрит назад во времени. Если в треке нет активной таблицы инструмента, первая строка фразы с инструментом активирует таблицу именно с этой строки, будь то 4, 8 или F. Позже номера инструментов не заменяют активные таблицы режимов `Phrase`, `Chain` или `Free`. Это делает таблицы удобными для похожей на LFO автоматики без скрытого моделирования предыдущих шагов фразы.

Команды `TBL`, `TBX` и `RET` всегда явные: выбор или рестарт сразу, независимо от режима. На границах Phrase или Chain рестарт происходит до чтения новой строки, поэтому команды `TBL` или `TBX` имеют решающее значение. FX в строке таблицы `00` запускаются заново как обычно; накопительные FX продолжают накапливаться.

Таблицы `00-7F` зарезервированы для стандартных инструментальных таблиц. Таблицы `80-FE` предназначены для вспомогательных таблиц, запускаемых эффектом `TBX`. Нижний диапазон также работает для вспомогательных таблиц, но его использование может приводить к конфликтам.

### Управление

- **EDIT + [UP/DOWN]** по столбцу с названием FX: открыть экран выбора FX
- **OPT + [НАПРАВЛЕНИЕ]**: переход между таблицами

## 9. Пул инструментов и AY Wavetable

### Пул инструментов

Пул инструментов показывает все инструменты проекта и позволяет менять их порядок. Во время воспроизведения также показывает, какие инструменты активны в данный момент.

#### Управление

- **EDIT**: редактировать инструмент и перейти на экран инструмента
- **SHIFT + OPT**: копировать инструмент
- **SHIFT + EDIT**: вставить инструмент
- **EDIT + [UP/DOWN]**: изменить порядок инструментов
- **EDIT + PLAY**: превью инструмента

### AY Wavetable

Wavetable — это тип программного осциллятора AY Plus. В проекте может быть до 256 вейвтейблов по 32 шага. Все инструменты wavetable используют один набор волн. Здесь вы их редактируете.

Уровни громкости AY нелинейны, поэтому форма волны в Standard view отрисована с учётом реальных уровней выхода. Двойной тап по **OPT** переключает между Standard view и сохранённым **LFO view**, используя тот же шорткат, что и Song/Live Mode: в LFO view шаги `0`–`15` рисуются линейно, с центральной линией между `7` и `8` как нулёвым уровнем модуляции.

Экран делится на логические ряды. Верхний — кнопки **Load** и **Save**, второй — редактор wavetable.

#### Управление

- **OPT + [LEFT/RIGHT]**: переход по списку вейвтейблов
- **OPT + [UP/DOWN]**: переход по списку блоками по 16 волн
- **SHIFT + OPT**: копировать вейвтейбл
- **SHIFT + EDIT**: вставить вейвтейбл
- **OPT + PLAY**: переключить между Standard и LFO вид

#### Условия

Вдохновлённые шведскими "условиями триггера", трекер поддерживает вероятности триггера и условия по модулю.

| FX | Значение | Значение |
|---|---|---|
| `PRO` | `00-64` | Абсолютная вероятность триггера от `0%` до `100%` |
| `MOD` | `AB` | Триггер на итерации `A` из `B`; например `12`, `22`, `14`, `34` |

Счётчики `MOD` локальны для трека и фразы. Неверные комбинации, например `A` больше `B`, не вызывают триггер.

`MOD34` срабатывает на 3-м проходе из 4, `MOD1F` — на 1-м из 16.

#### Скорость воспроизведения

Как и NerdSEQ, ChooChooTracker поддерживает независимую скорость воспроизведения для каждого трека.

`SPD` читает значение как знаковый байт. `00` — нормальная скорость, положительные значения ускоряют трек, отрицательные замедляют. Настройка активна до следующей команды `SPD`.

| Значение | Скорость |
|---|---:|
| `00` | `x1` |
| `01` | `x2` |
| `02` | `x3` |
| `7F` | `x128` |
| `FF` | `/2` |
| `FE` | `/3` |
| `80` | `/129` |

Старые проекты без поддержки знакового `SPD` сохраняют старое отображение `00-10` и воспроизводятся как раньше.

Очень высокие множители могут превысить разрешение планировщика тиков и не были аппаратно протестированы.

### Scale & chords FX

#### Автоматизация шкалы

`SCL XY` меняет глобальную шкалу воспроизведения и тональность без изменения нот во фразах. `X` выбирает шкалу (`0` Хроматическая, `1` Мажор, `2` Минор, до `C` Пользовательская); `Y` выбирает тональность (`0` C до `B` B). Команда действует только на FX фраз, не на таблицах. При нескольких командах `SCL` в один тик побеждает трек с меньшим номером.

`SCL` применяется в режиме Quantizer. При включённом **Note Lock** команда не доступна в списке FX, и любые `SCL` в фразах игнорируются.

#### Аккорды

`CRD XY` превращает ноту на своей строке фразы в аккорд. `Y` выбирает тип: `0` Мажор, `1` Минор, `2` Уменьшенный, `3` Увеличенный, `4` Sus2, `5` Sus4, `6` Power, `7` Maj7, `8` Min7, `9` Dom7, `A` Min7b5, `B` Dim7, `C` Add9, `D` MinAdd9, `E` Maj9, `F` Min9. `X` выбирает один из 16 голосов: `0-3` — восходящий цикл замкнутых обращений; `4-7` добавляет drop-2; `8-B` — drop-3; `C-F` — оба приёма. Цикл продолжается на октаву выше для триад и power-аккордов, каждый вариант уникален; большие значения шире и менее классичны. Например, `CRD 4Y` — drop-2 в основной позиции, `CRD DY` — первое обращение с двумя drop. Вокалы при этом зажимаются в пределах таблицы высоты. Команда непостоянна: пишите на каждой строке с аккордом. Каждая нота квантуется отдельно при активной шкале в режимах Quantizer и Note Lock. Доступна только для софтверных движков; AY инструменты игнорируют и остаются монофоничными.

## 11. Микшер, Реверберация и Задержка

Микшер — левый главный экран. Отображает загрузку ЦП и предупреждения о клиппинге. Красный `!` в колонке **CLIP** указывает дорожку, чей сухой сигнал превысил безопасный уровень микса.

Используйте микшер для балансировки 8 дорожек, формирования звучания каждой дорожки с помощью Tilt EQ и отправки аудио на реверберацию или задержку:

| Поле | Значение |
|---|---|
| LVL | Уровень дорожки после движка, `000-100` |
| REV | Отсылка в общий реверб, `000-100` |
| DLY | Отсылка в общий пинг-понг дилэй, `000-100` |
| PAN | Панорамирование звука влево или вправо |
| TLT | Tilt EQ для каждой дорожки, `00-FF`; `80` — нейтрально, низкие значения усиливают басы, высокие — верхние частоты. Низкие значения вносят мягкий овердрайв. |
| M | `*` заглушает дорожку |
| S | `*` включает соло для дорожки |

Микшер привязан к дорожкам, а не к инструментам. Если дорожка меняет инструмент, её уровень, PAN, Tilt и отправки остаются за дорожкой. У инструментов также есть свои `00-FF` **Vol** и **Pan** в верхнем ряду экрана Instrument. Панорамирование инструмента применяется сначала, затем панорамирование дорожки. Оба сохраняют стереообраз при центре и постепенно ослабляют противоположный канал при движении влево или вправо.

### Auto Mix

В Mixer есть кнопка **AUTO MIX**. Она рендерит `6 секунд` офлайн, выравнивает громкость дорожек, затем сравнивает 8 октавных полос с профилем розового шума и мягко приглушает дорожки, перегружающие эти полосы. Она предлагает осторожные изменения уровней, оставляет запас по пику и запускает временное предпрослушивание. **Apply** сохраняет предложенные уровни, а **Cancel** восстанавливает прежние 8 уровней. Это хорошая отправная точка, но результат, скорее всего, захочется подправить.

### Реверберация

Используйте **SELECT + [UP]** из микшера для открытия экрана настроек реверба.

- **Algorithm**: выбирает Clouds или Beads. Каждый алгоритм имеет собственные параметры.
- **Return**: уровень влажного сигнала реверба в мастере.
- **Clouds**: **Time**, **Damping**, а также предусилительные фильтры **LP** и **HP**.
- **Beads**: **Time**, внутренний фильтр обратной связи **Tone**, и предусилительный фильтр **HP**.

Это только секция отправки в реверб Clouds или Beads, не гранулярный процессор.

### Пинг-понг задержка

Используйте **SELECT + [DOWN]** из микшера для открытия экрана задержки, затем **SELECT + [UP]** для возврата. Реверберация работает противоположно: **SELECT + [UP]** открывает её, а **SELECT + [DOWN]** возвращает в микшер.

- **Return**: уровень влажного сигнала задержки.
- **To Reverb**: доля влажного сигнала задержки, направляемого в общий реверб, `0-100%`.
- **Ticks**: время задержки в тиках трекера (`9 тиков` = `1 такт` по умолчанию).
- **Feedback**: уровень перекрёстной обратной связи, ограничен `95%`.
- **Filter**: низкочастотный фильтр на пути сигнала задержки.

Первое повторение следует за стереовходом. Поздняя обратная связь перекрещивается между левым и правым каналами.

## 12. Экран проекта

Экран проекта предоставляет команды **Load**, **Save**, **New**, **Export**, **Manage** и **Scale**, а также отображает имя файла, название и автора.

### Место экспорта

Экспорты, стемы и рендеры сохраняются в отдельную папку проекта внутри существующей папки с сэмплами приложения:

- **По умолчанию**: `<app folder>/samples/Exports/<project name>/`. Пока проект без имени, папка — `current-project`.
- В веб-версии по умолчанию это `/user/samples/Exports/<project name>/`.
- На Android папка samples внутри рабочего пространства приложения: приватна для приложения в версии Play Store, `samples` в выбранной директории при прямой сборке APK.

Строка **Folder** на экране EXPORT показывает текущую папку назначения:

- Нажмите **EDIT** для выбора папки через файловый браузер. Выбранная папка используется как есть (подпапка проекта не добавляется) и запоминается в настройках.
- **EDIT + OPT** (очистить) сбрасывает в папку по умолчанию.

При сохранении именованного проекта под новым именем, папка экспорта по умолчанию переименовывается соответственно, сохраняя ранее экспортированные файлы с проектом. Переименование не распространяется на настраиваемые папки, и папка не переименовывается при автосохранении. Если папка с целевым именем уже существует, обе папки сохраняются. Если трекер потерял связь с папкой (например, после перезапуска), сохранение именованного проекта переименовывает существующую папку `current-project`. Инструменты продолжают работать после переименования: пути загруженных сэмплов автоматически обновляются.

**Load** принимает `.mid`/`.midi` файлы, импортируя их как новый проект: ноты группируются по MIDI-каналам (по одному каналу на дорожку, максимум по числу дорожек), квантованы до 4 строк на такт и размещаются на одном дефолтном AY инструменте — номера MIDI программ не имеют чиптюн-эквивалентов, поэтому нужно подобрать реальные инструменты после импорта. Используется только первый темп из файла (один глобальный тикрейт, без локальных изменений темпа). Строка **MIDI** экрана Export делает обратное: сохраняет ноты, громкость и темп/ритм текущей аранжировки в стандартный MIDI файл (по одной MIDI-дорожке на дорожку трекера); [MIDI Out](#midi-out) инструменты и другие FX на строках, кроме громкости и глобального ритма, MIDI не поддерживают и не конвертируются.

**Load** принимает Dirtywave M8 песни (`.m8s`, прошивки 2.x-4.x), импортируя как новый проект. Импортируются только структура и ноты (строки песни, цепочки с транспозицией, фразы с нотами, скоростью и номером инструмента, note-off, темп и имя песни); ноты сохраняют реальную высоту (M8 обозначает октавы на две выше: его `C-6` здесь — `C-4`). Каждый инструмент, используемый в фразе, импортируется под именем инструмента M8. M8 **MACROSYN** инструменты становятся Braids (47 форм — это модели Braids с теми же номерами; тембр, цвет, тип фильтра, срез, резонанс и панорама переносятся, кривая среза приблизительна). **SAMPLER** инструменты становятся Sample: `.m8s` хранит только путь к WAV на карте M8, поэтому файл ищется в папке `.m8s` и ее родительских папках (работает копия структуры карты) и в текущей папке сэмплов (`Samples` или `samples`); если не найден, инструмент сохраняет путь M8 и молчит. Импортированные сэмплы получают +24 полутона в настройке Pitch, т.к. M8 воспроизводит сэмпл на 2 октавы ниже оригинала. **FMSYNTH** становится инструментом Genesis FM (приблизительное преобразование), **WAVSYNTH** и **HYPERSYNTH** становятся aChChid. **MIDI OUT** становится MIDI Out инструментом (канал, банк, программа и первые четыре CC). Другие (внешние) типы становятся дефолтным AY инструментом — подберите реальные звуки позже. FX и таблицы игнорируются.

**Load** принимает Little Sound Dj песни (`.lsdsng`, одна песня на файл), импортируя их как новый проект. Загрузка всего LSDj сэйва (`.sav`, до 32 песен) открывает список песен (слот, имя, версия, размер); выберите для импорта (редактируемая при сохранении песня не отображается). Импортируются только структура и ноты (строки песни, цепочки с транспозицией, фразы с нотами и номером инструмента, темп и имя песни); все ноты получают максимальную громкость, так как LSDj не поддерживает громкость нот, а 4 канала LSDj PU1, PU2, WAV и NOI становятся дорожками 1-4. Пульсовые инструменты становятся GB Pulse (долгота импульса, огибающая и панорама переносятся; пульсовый свип — нет), шумовые — GB Noise (огибающая, стабильность и панорама), волновые — пресетом GB Pulse Hollow Lead и набором дефолтного GB Noise. Ритмы импортируются, команды фраз `C` (аккорд), `D` (задержка), `E` (огибающие пульса и шума, не для волны), `G` (ритм), `K` (выключить) и `V` (вибрато) становятся `ARP`, `DEL`, `CEI`/`CEP`/`CED`, `GGR`, `KIL` и `PVB`. Остальные команды (`A`, `F`, `H`, `L`, `M`, `O`, `P`, `R`, `S`, `T`, `W`, `Z`), таблицы, волновые фреймы, сэмплы наборов и синтез остаются без внимания, поэтому песня с активным их использованием зазвучит иначе. Темп конвертируется под ритм 6 тиков.

На десктопе и Android строка **LSDJ** экрана Export делает обратное с ограничениями: нажмите и выберите существующий `.lsdsng` как **template** (запоминается до выхода, **EDIT + OPT** очищает). Его строки, цепочки, фразы, темп и заголовок заменяются, остальное (таблицы, ритмы, волны, наборы, настройки синта) сохраняется. Дорожки 1-4 становятся PU1, PU2, WAV и NOI; GB Pulse и GB Noise инструменты записываются обратно как LSDj пульсовые и шумовые инструменты, остальные — как дефолтный пульсовый инструмент. FX, громкости нот и note-off не экспортируются, песня с цепочкой `80` или выше или фразой `FF` и выше не экспортируется (в LSDj 128 цепочек и 255 фраз). Экспорт не тестировался в LSDj.

На десктопе строка **M8S** экрана Export делает обратное с ограничениями: нажмите и выберите `.m8s` как **template** (запоминается до выхода, **EDIT + OPT** очищает). Песня, цепочки, фразы, темп и заголовок заменяются, остальное сохраняется, кроме того, что Braids инструменты записываются обратно как MacroSynth, а Sample инструменты как Sampler (путь `/Samples/<file name>`, копируйте WAV на M8 самостоятельно), если шаблон содержит такой тип инструмента для копирования параметров. FX не экспортируются, песня с фразой `FF` и выше не экспортируется (в M8 255 фраз). Экспорт не тестировался на живом M8. Подробнее см. [M8 songs](m8s-format.md).

На десктопе key jazz позволяет набирать имя файла, заголовок и автора с клавиатуры без виртуальной клавиатуры — см. [Key jazz](#key-jazz-desktop-only).

### Scale / Quantize

Экран Scale управляет глобальным движком шкалы 12-TET. Строка **Mode** выбирает между двумя режимами:- **Квантизатор** (по умолчанию): ввод фраз остаётся хроматическим; при включении ноты сразу округляются вниз перед попаданием в звуковой движок, так что изменение тональности или гаммы перестраивает гармонию песни без редактирования фраз.
- **Залочка нот**: введённые в фразы ноты автоматически фиксируются на ближайшую ноту гаммы при вводе, так что можно записывать только ноты из гаммы. Новые ноты и понижения сдвигаются вниз; `EDIT + RIGHT` / `EDIT + UP` повышают ноту к следующей ноте гаммы сверху. Ввод всегда следует текущей гамме проекта на этом экране: изменение тональности или гаммы сразу влияет на вновь введённые ноты на включённых дорожках, а уже записанные ноты остаются без изменений. FX `SCL` недоступен в этом режиме, а уже записанный `SCL` игнорируется. Квантизация при воспроизведении обычных нот обходится (ввод уже зафиксирован); квантизация аккордов через `CRD` сохраняется.

- **Clock source** выбирает между **Internal** (собственный темп проекта), **Midi Clock** (секвенсор следует входящим MIDI-часам) и **Ableton Link** (секвенсор следует темпу сессии Link в локальной сети). При **Midi Clock** строка **Tempo** затемнена и показывает измеренный темп входящих часов; транспортом (play/stop) управляют сообщения Start/Continue/Stop отправителя, поэтому кнопка PLAY приложения не нужна. При **Ableton Link** строка становится строкой **Link**: вместо поля темпа в ней переключатель подключения/отключения от сессии (см. ниже). Источник часов сохраняется в settings.txt и действует для всех проектов.
- **Tempo** задаёт темп проекта в целых BPM (`3-500`). Внутри трекер по-прежнему хранит свой tick rate в Гц (`tick rate = BPM x 0,4`), поэтому существующие проекты загружаются и сохраняются без изменений; проект с дробным темпом показывает его округлённым и привязывается к целому BPM при первом изменении темпа. Грубая настройка идёт шагом 5 BPM, точная - 1 BPM; удаление восстанавливает значение по умолчанию 125 BPM.

ChooChooTracker сохраняет проекты в формате `.cct`. Это проприетарный формат, который легко читается даже человеком.

Используйте **Save** перед сменой типа инструмента или загрузкой другого проекта.

### Ableton Link

Ableton Link позволяет ChooChooTracker следовать темпу других приложений с поддержкой Link (Ableton Live, LinkHut и др.) в той же локальной сети (Wi-Fi или Ethernet). Это только приёмник: трекер подстраивает собственный темп под сессию и никогда не отправляет темп или транспорт другим участникам.

**Что синхронизируется:**

- Темп сессии - трекер непрерывно следует темпу сессии Link (в пределах диапазона трекера 3-500 BPM).
- Фаза бита - нажатие PLAY выравнивает воспроизведение по сетке битов сессии: песня начинается со следующего такта (квант 4 бита).

**Что не синхронизируется:**

Во время воспроизведения с Link ChooChooTracker проверяет общую фазу бита раз в такт 4/4 и при необходимости плавно подстраивает собственный tick rate. Это компенсирует небольшие расхождения часов между устройствами без пропуска или повтора тиков трекера и никогда не меняет сессию Link другого участника.

- Грувы и значения `SPD` и `DELAY` не затрагиваются - они остаются относительными к отслеживаемому темпу.
- Позиции курсора в song/chain/phrase и настройки микшера никогда не передаются.

**Как использовать:**

1. Откройте экран Project и установите **Clock source** в **Ableton Link**. Строка ниже становится строкой **Link**.
2. Нажмите EDIT на **[Connect]**, чтобы присоединиться к сессии. Сообщение о состоянии справа показывает ход: `Wait...` при подключении, `No net` при отсутствии сети, `No sess` если сессия не найдена, `Err` при внутреннем сбое. Пока вы подключены, кнопка показывает **[Disconnect]**, а состояние примерно раз в секунду чередуется между `connected` и `Peers: N` (N - число пиров).
3. Дождитесь `connected` и нажмите PLAY - воспроизведение начнётся выровненным со следующим тактом сессии.
4. Нажмите EDIT на **[Disconnect]** (или верните источник часов в Internal), чтобы покинуть сессию.

В режиме Link темпом владеет сессия: в строке нет поля BPM, а темп сессии применяется к проекту автоматически (в пределах диапазона трекера 3-500 BPM).

**Доступность по платформам:** поддерживаются PortMaster (основная цель), Windows, Linux, macOS и Android. Web-версия и версии для Miyoo не включают Link.

**Примечание о PortMaster:** на устройствах PortMaster аудиобуфер больше (512 кадров при 48 кГц), поэтому выравнивание бита приблизительное, в пределах около 10-15 мс, а не с точностью до сэмпла. Сама синхронизация темпа не затрагивается.

## 13. Настройки

Настройки задают предпочтения, которые сохраняются с приложением, а не с текущим проектом. Управление проектом — темп, грув и уровни микшера — находятся на отдельных экранах.

### Управление

- **Задержка повтора** и **Скорость повтора** определяют через сколько и как быстро будет срабатывать зажатая кнопка навигации или редактирования. Увеличьте задержку, если повтор срабатывает слишком быстро; уменьшите для быстрого ввода трекером.
- **Режим STICK LIVE** выбирает, как работает назначенная кнопка **STICK LIVE**: `HOLD` — активна пока зажата, `TOGGLE` — остаётся активной после нажатия, `FREE` — постоянно активна. Подробнее в [Запись движения](#motion-recording).
- **Назначение клавиш** присваивает управление для клавиатуры или контроллера. Выберите команду, нажмите новую клавишу, затем выберите **Done** для сохранения.

### Аудио

**Sample rate** предлагает `32 kHz` или `48 kHz` (по умолчанию). Изменения применяются сразу и сохраняются. Смена частоты дискретизации останавливает воспроизведение и предпрослушивание сэмплов, пока звуковые движки и любой вооружённый аудиовход переоткрываются на новой частоте. Если устройство отклоняет новую частоту, остаётся прежняя настройка. `32 kHz` уменьшает нагрузку обработки и ограничивает наивысшую воспроизводимую частоту до 16 кГц. Индикатор загрузки CPU показывает стоимость рендеринга звука.

**Размер буфера** балансирует отзывчивость и стабильность. Установите меньшее значение для более быстрой реакции во время игры; увеличьте, если слышите потрескивания или ЦП загружен постоянно. Доступные значения: `32`, `64`, `128`, `256`, `512` и `1024` сэмпла. Помогает индикатор загрузки ЦП при выборе стабильного значения.

### MIDI

Выберите устройства ввода и вывода, назначайте MIDI-каналы инструментам, настраивайте управление MIDI CC. См. [MIDI](#15-midi) для подключения клавиатуры, управления микшером или отправки нот на внешнее железо.

### Синтезаторы

- **AY Quality** выбирает качество звука для AY/YM инструментов. **AY Sample dithering** может сглаживать проигрывание AY-сэмплов; выключите для более чёткого, лоу-фай звучания или если ориентируетесь на оригинальное железо.
- **Braids BITS**, **DRFT** и **SIGN** — глобальные настройки характера Braids, общие для всех инструментов Braids. Устанавливайте общую детализацию, дрейф и характер перед точной настройкой отдельных звуков. Подробнее в [Braids](#braids).

### Микшер

- **Громкость Микса** — общий уровень вывода приложения. Уменьшайте при подаче сигнала на другой микшер или рекордер; не меняет баланс дорожек песни.
- **Tilt pivot** задаёт центральную частоту всех регуляторов **Tilt** микшера в проекте, от `250 Гц` до `4000 Гц` (по умолчанию `1 кГц`).

### Графика

- **Тема цвета интерфейса** меняет цвета интерфейса. **Load font** загружает шрифт `.cnfont` для отображения.
- **Song waveform** включает или отключает отображение волновой формы микса на странице Song; см. [Song waveform](#song-waveform).
- **Визуализация дорожки** выбирает для каждой дорожки либо **Detailed** (волновая форма инструмента с наложениями), либо **Audio waveform** (итоговый звук дорожки). Используйте **All detailed** или **All audio** для смены всех дорожек сразу.
- **FPS волновой формы** задаёт частоту обновления осциллографа инструмента и визуализаторов микшера — от `1` до `60` кадров в секунду. Понижайте для спокойного отображения или чтобы снизить нагрузку.
- **Renderer** показывает, используется ли в приложении `GPU` или `Software` рендеринг.

### Отчёт поддержки и выход

**Support report** создаёт небольшой диагностический файл для отчёта о баге. Прикрепляйте его вместе с `.cct` проектом, если проблема связана с конкретной песней. **Quit ChooChooTracker** корректно закрывает приложение.

### Волновая форма песни

Graphics → Song waveform отключена по умолчанию. Нажмите EDIT, чтобы переключить, или используйте EDIT + направление; выбор сохраняется в настройках приложения. При включении над страницей SONG показывается двухрядная монофоническая волновая форма итогового микса. Все остальные страницы сохраняют нормальный макет, отступы и предпросмотры инструментов независимо от этой опции. Сохранённые настройки совместимы с предыдущими версиями. Точки касания на странице SONG следуют отображаемым рядам в обоих режимах.

## 14. Решение проблем

### ЦП

Загрузка ЦП зависит от активных движков и эффектов. Физические модели Plaits и реверберация Clouds потребляют больше ресурсов, чем базовые голоса AY. Проверяйте производительность на целевой консоли, особенно с 8 голосами Plaits и обоими send’ами включеными. Значение ЦП около `100%` может вызывать щелчки и пропуски звука.

Если возникают щелчки, сбои или торможения — используйте **Settings > Support report** и прикрепите созданный `support-report.txt` к отчёту. Если проблема вызвана конкретной песней, приложите и `.cct`.

### Нет звука

Проверьте номер инструмента, состояние дорожки (mute или solo), уровень LVL дорожки, общий уровень mix volume и огибающую инструмента. Для сэмплов удостоверьтесь, что оригинальный WAV-файл существует по сохранённому пути.

В ArkOS нажмите **MENU + L3** для переключения системного звука mute. Если не помогает — перезагрузите устройство и переподключите аудиоинтерфейс. Попробуйте опцию "repair audio" в ArkOS, она может помочь.

### Ввод ощущается неправильно

Отрегулируйте Repeat delay и Repeat speed в настройках. Если при одном нажатии происходит двойное движение, проверьте, что только один физический контроллер назначен на это направление, и сообщите точный экран и сочетание клавиш.

## 15. MIDI

Settings > **MIDI** открывает подменю: **MIDI In** / **MIDI Out** — выберите подключённое устройство, переключаясь между обнаруженными портами, по краям доступен `OFF`; для обоих направлений нужно выбрать устройство.

- **Предпрослушивание с MIDI-клавиатуры**: при подключении MIDI In, игра на клавиатуре воспроизводит выбранный инструмент на любом экране, как если бы нажимали **EDIT + PLAY** на экране [Instrument](#5-instruments). Это только предпрослушивание, ноты не добавляются в песню.
- **Назначение каналов**: отображается список из 16 MIDI-каналов; назначьте каждому канал инструмент (`OFF` по умолчанию), так, чтобы ноты с этого канала активировали предпрослушивание указанного инструмента независимо от выбора на экране Instrument — например, канал `01` -> инструмент `05`. Канал, оставленный в `OFF`, переключается на текущий выбранный инструмент, как было ранее. Эта карта сохраняется в settings.txt.
- **Назначение MIDI CC**: назначает входящий контроллер параметру инструмента, включая **Volume**, или глобальным контролям. Глобальные строки показывают `TRK 1`–`TRK 8` вместо инструмента и предоставляют управление дорожками: **Mute**, **Solo**, **Volume**, **Reverb send**, **Delay send**; для **Song play/stop** цели нет. Новая привязка игнорирует оригинальный CC и вступает в силу при следующем движении физического контроллера, поэтому настройка во время воспроизведения не обнуляет патч. Мute и solo работают по схеме `0-63` = выкл, `64-127` = вкл.
- **Синхронизация по MIDI-часам**: при выбранном устройстве MIDI In установите **Clock source** на экране Project в **Midi Clock**, чтобы следовать внешнему секвенсору. Трекер измеряет темп входящих часов (24 импульса на четверть) и показывает его в затемнённой строке **Tempo**; сообщения **Start**, **Continue** и **Stop** управляют воспроизведением. Источник часов запоминается в settings.txt.
- **Управление внешним MIDI-устройством**: назначьте дорожке тип инструмента [MIDI Out](#midi-out) и выберите канал; сыгранные на этой дорожке ноты пойдут в реальный MIDI Out, а не будут воспроизводиться в ChooChooTracker.
