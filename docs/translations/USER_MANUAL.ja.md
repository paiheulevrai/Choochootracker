# ChooChooTracker ユーザーマニュアル
> これは現在の英語マニュアル `docs/USER_MANUAL.md` の自動生成翻訳です。英語版と異なる場合は英語版が優先されます。

> **慣例** アプリケーションのインターフェースは英語のままです。画面、メニュー、フィールド、ボタン名、FXコード、モジュールやエンジン名、ファイル拡張子は英語のままにしてください。


ChooChooTrackerは携帯ゲーム機向けの8トラック音楽トラッカーです。

LSDjのクラシックなワークフローとナビゲーションシステムを踏襲し、以下の音作りオプションを備えています：

- ビンテージチップとコンソールのエミュレーション
- サウンドフォント
- Mutable InstrumentsのBraids、Plaits、Plaits-Altオシレーターとマルチモードフィルター
- PCMサンプル、シングルサイクル波形、ウェーブテーブルオシレーター（マルチモードフィルター付き）
- Open303ベースの多用途アシッドシンセ aChChid
- ネイティブ12モデルドラムシンセサイザー Bogie（マルチモードフィルター付き）
- 10ボイスユニゾンとステレオディレイを備えたボーカルシンセサイザー MonkSynth
- 2オシレーター多重変調シンセサイザー MME（マルチモードフィルター付き）
- ネイティブ6モデル実験的デジタルドラムシンセ Sintered

## 1. インストールとファイル

### ArkOS / PortMaster

`choochootracker.zip`をPortMaster経由でインストールするか、解凍したパッケージをコンソールの`ports`ディレクトリにコピーします。Portsメニューから**ChooChooTracker**を起動してください。

### Miyoo Mini / Mini Plus (Onion OS)

MiyooPortsのアーカイブをSDカードのルートに展開し、`Roms/PORTS/`フォルダがOnionの既存フォルダと統合されるようにします。コレクションをリフレッシュ後、Portsメニューから**ChooChooTracker**を起動してください。既存インストールを上書きする際は、`projects/`フォルダをバックアップしておきます。

プロジェクトの読み込み時間は、曲で使われているインストゥルメントの種類によって異なる場合があります。起動やプロジェクトの読み込みが異常に遅い場合は、それぞれの所要時間を、本体のモデルとOnion OSのバージョンとともにお知らせください。

### Raspberry Pi OS 64ビット

Raspberry Pi AArch64のアーカイブを展開し、SDL2ランタイム（`sudo apt install libsdl2-2.0-0`）をインストールして、展開したフォルダから `./chipnomad.sh` を実行します。同梱のインストゥルメントやその他のリソースは実行ファイルと同じ場所に置いてください。

### Windows

`choochootracker.exe`と同じフォルダに `SDL2.dll` と `libwinpthread-1.dll` を置いて実行します。

Windowsではキーボード（詳細はJazzモード参照）またはゲームパッドが使えます。

### Web

https://choochootracker.vercel.app/ でオンラインで利用可能です。

このバージョンはキーボード、モバイル端末の画面内コントロール、ゲームパッドで操作できます。

設定、サンプル、テーマ、プロジェクトなどはブラウザのストレージに保存されます。

**Download .cct** でプロジェクトをエクスポート可能です。

注意：iOSの制限により、iPhoneでのウェブ版のMIDI使用は困難な場合があります。

## 2. 操作方法

ChooChooTrackerはDパッド、アナログスティック2本、7ボタンを備えたゲームパッドでの操作が最適です。

| 論理操作 | 携帯機デフォルト | Windowsデフォルト |
|---|---|---|
| **[LEFT/RIGHT/UP/DOWN]** | D-pad | 矢印キー |
| **EDIT** | A | X |
| **OPT** | B | Z |
| **PLAY** | Start | Space |
| **SELECT** | Select | Shift |
| モジュレーション軸 | 左右スティック | ゲームコントローラースティック |
| **STICK LIVE** | L1 | Q |
| **MOTION RECORD** | L2 | W |
| **MOTION ERASE** | R2 | E |

マッピングは**Settings > Controls > Key mapping**で変更可能（Androidでは外部ゲームパッドでも可）。PortMasterではリマップしたら**Done**で保存し、設定を続ける前にボタンを離してください。

### ナビゲーション

- **[UP/DOWN/LEFT/RIGHT]**でカーソル移動。
- **SELECT + [方向]**で画面間移動。
- **OPT + [方向]**で画面固有のナビゲーション。
- 値を編集する時は**EDIT + [LEFT/RIGHT]**で微調整、**EDIT + [UP/DOWN]**で大幅変更。
- **EDIT**をタップして値入力またはコマンド実行。

### 選択とクリップボード

- **SELECT + OPT** で選択モードに入り、有用な選択範囲を切り替え。
- **[方向]**で選択範囲拡大。
- **OPT**をタップして選択をコピーし、選択モードを終了。
- **OPT + EDIT** で切り取り。
- 選択モード外で**SELECT**をホールドしながら**EDIT**で貼り付け。
- **EDIT + [方向]**で選択セルを一括編集。

### 再生

- **PLAY**でカーソル位置から再生開始。再度押すと停止。
- 再生中でもノート、インストゥルメント、チェーンを編集可能。変更は次シーケンサーのティックで反映。
- **SELECT + PLAY** はSong画面以外で全トラック再生。
- **EDIT + PLAY** でInstrument Poolからインストゥルメントをプレビュー。

### グローバルバウンス

Song、Chain、Phraseの行・列範囲を選択し、**EDIT**をダブルタップでBOUNCE TO SAMPLE画面を開きます。バウンスには選択された全トラックが含まれ、開始チェーンが遅いトラックは静かに待機し最初のチェーンから再生されるため、すべてのトラックのチェーンを含むファイルが生成されます。

画面には以下があります：

- **ファイル名**：文字キーボードで編集可能。画面起動時には、出力フォルダにまだ無い次の連番（`001`、`002`...）が提案されます。自由に編集可。既存ファイル名と重複すると`_001`、`_002`…のサフィックスが付加され、既存ファイルは上書きされません。カウンターはプロジェクト読み込みや新規作成時にリセット。

- **サンプルレート**と**ビット深度**：エクスポート画面と同様の選択肢。

- **ファイル名に含めるタグ**：3つのチェックボックスで、**Start**を押した際にファイル名にコンテキストタグを前置します（デフォルトはすべてオフ）:
  - **[BPM]** — 現在のテンポ例 `[120]`
  - **[Key]** — ルートノートとスケール例 `[Cmaj]`、`[F#min Pent]`
  - **[Bars:Beats:16ths]** — バウンス長。1フレーズ＝1小節（16分割16個）、ビートは4つの16分音符。フルフレーズは小節数だけ表示(`[2]`)、部分的フレーズは `[0:2]`（2ビート）や`[0:1:3]`（1ビート＋3個16分）で示す。マルチトラックの場合は最長トラックで決定。中途半端なビート終端は16分音符1つ減算。選択の最終行がカット地点で、そのノートオフは前の16分の終わりになる。

  タグは `[BPM][Key][Length]` の順にファイル名の先頭に付与。

- **Start**：選択範囲をWAVファイルにレンダリングし、出力フォルダへ保存（詳細はProject画面の*Export location*参照）

- **Cancel**：バウンスせずに戻る

バウンス中は**OPT**でキャンセル可能。完了・キャンセル時は元の画面に戻ります。

## 3. 曲構成と画面マップ

**SELECT + [方向]**で画面間移動。

メインのナビゲーション行は以下の通り：

<pre>
        I
R P   G M
<strong>M S C P I T</strong>
D S     P W
</pre>

中央行：

- **M**：Mixer（Reverb、Delayへ分岐）
- **S**：Song（Project、Settingsへ分岐）
- **C**：Chain
- **P**：Phrase（Grooveへ分岐）
- **I**：Instrument（Modulation、Instrument Poolへ分岐）
- **T**：Table（AY Wavetableエディタへ分岐）

上行：

- **R**：Reverb
- **P**：Project
- **G**：Groove
- **M**：Modulation
- **I**：Insert FX

下行：

- **D**：Delay
- **S**：Settings
- **P**：Instrument Pool
- **W**：AY Wavetableエディタ

ChooChooTrackerの曲は以下の階層構造を持ちます：

```text
Song -> Chain -> Phrase行 -> Note + Instrument + FX
```

曲は8トラックあります。各トラックは連続したチェーンのシーケンスを持ち、各チェーンは連続したフレーズのシーケンス。フレーズは16ステップのノート列。ノートにはピッチ、インストゥルメント、ベロシティ、最大3トラックFXが含まれます。インストゥルメントは音を出すものです。

## 4. Song、Chain、Phrase

### Song

Song画面は8列あり、1列につき1トラック。各セルはチェーンを指します。Songは最大256行（`00-FF`）を持てます。

トラックは左から右へ、チェーンは縦に並びます。各トラックは独立しており、チェーンは1～16フレーズを含みます。トラックは同期がずれることがあります。チェーンをあえて同期させるか、トラックの必要に応じ自由に使ってください。

トラッカーコミュニティでは、空フレーズ用に1チェーンを予約することが一般的で、多くは`00`か`FE`です。

空行で区切られたセクションを作り「島（islands）」としてサブソングを複数持つこともできます。

#### ライブモード

**OPT**をダブルタップでライブモードの切り替え。`LIVE`がSongタイトルの代わりに表示されます。ライブモードでは、停止中のトラックで**PLAY**を押すと選択中のチェーンが単独で再生開始。再生中は次のチェーン境界で切り替え予約、**PLAY**を2回押すと次のフレーズ境界で即座に切替。選択中の空Songセルは量子化された停止予約。キュー状態は `+`がキュー済チェーン、`!`が急遽チェーン、`-`が停止キュー。

複数列にわたるSongの1行を選択してトラック単位で曲再生や停止予約が可能。複数行選択は意図的に拒否。Songの範囲ループ中はライブキューはクリアされます。ライブはパフォーマンス用でプロジェクトには保存されません。

#### 操作

- **OPT + [UP/DOWN]**：16行ずつジャンプ
- 範囲選択後 **SHIFT + EDIT**：チェーンをシャロークローン。ただしフレーズはオリジナルを維持
- 範囲選択後 **SHIFT + EDIT**をダブルタップ：チェーンとフレーズのディープクローン
- 範囲選択後 **EDIT + [UP/DOWN]**：選択範囲を上下に移動
- **OPT**を3回タップ：視覚的整理のためのハイライト追加/削除
- **OPT + SHIFT**：現在のトラックまたは選択された列のミュート（**OPT**を先に離すとミュート維持）
- **OPT + PLAY**：現在のトラックまたは選択された列をソロに（**OPT**を先に離すとソロ維持）
- **OPT + [LEFT/RIGHT]**：現在トラックの左右のトラックをすべてソロに
- 範囲選択後 **EDIT**をダブルタップで BOUNCE TO SAMPLE画面を開く（詳細はSongの Bounce項目）

再生の停止、およびミュートやソロの変更には、クリックノイズを減らすため3 msの短い出力補正が使われます。再生中のミュート解除やソロ解除も同様です。

### Chain

チェーンは16ステップフレーズの順序付きリストで、半音単位のトランスポーズを設定可能。最大16フレーズまで含められ、同じフレーズを複数回使えます。2列目が半音単位のトランスポーズ設定。

プロジェクト内で再利用されているチェーンにはアスタリスク（`*`）が付きます。チェーンはSong画面からクローン可能。

#### 操作

- **OPT + [LEFT/RIGHT]**：トラック間移動
- **OPT + [UP/DOWN]**：現在トラック内のチェーン間移動
- 範囲選択後 **SHIFT + EDIT**：フレーズのクローン
- 範囲選択後 **EDIT**をダブルタップ：現在トラックのチェーン行に対するBOUNCE TO SAMPLE画面を開く（SongのBounce参照）

### Phrase

フレーズは従来型ステップシーケンサーのパターン。

16ステップ（行）で構成され、各行にノート、インストゥルメント、`00`～`7F`の音量、FX列を持ちます。ノートは`C-4`などのトラッカー表記（音階とオクターブ）を使用。

ノート終了は`NOTE OFF`の挿入、ノートキルFXの使用、別のノートをインストゥルメント無しで再生が可能。

チェーンに複数フレーズがある場合、Phrase画面は連続したパターンエディタとして機能。行`F`の下や行`0`の上に移動すると次または前のフレーズを開きます。

プロジェクト内で再利用されているフレーズにはアスタリスク（`*`）が付きます。フレーズはChain画面からクローン可能。

FXセレクターには一般的なコマンドと、その行のインストゥルメントがサポートするコマンドが表示されます。全エンジンの長いグローバルリストは避けています。ChooChooTrackerはChipNomadより多くのFXに対応しています。

### 操作- **OPT + EDIT** 空のノート上で: `NOTE OFF` を挿入
- **EDIT + [UP/DOWN]** FX名の列で: FX選択画面を開く
- **OPT + [LEFT/RIGHT]**: トラック間を移動
- **OPT + [UP/DOWN]**: 現在のchain内のPhrase間を移動
- インストゥルメント列で範囲選択し、**SHIFT + EDIT**: インストをクローン
- 範囲選択し、**EDIT + [UP/DOWN]**: フレーズ行を回転
- 範囲選択し、**EDIT**をダブルタップ: 現トラックの選択されたPhrase行のBOUNCE TO SAMPLE画面を開く（SongのBounce参照）

この画面で選択中に、ノート列をリズムパターンで埋められます：

- **OPT + LEFT** 選択範囲のノートセルを固定16ステップパターンで埋め、押すたびに次のパターンへ。最後のパターン後はノートを消去しサイクル開始。パターンは絶対フレーズ行に揃えられるため、部分選択は内部のステップのみ受け取る。
- **OPT + RIGHT** 選択範囲を3～8ノートのランダムパターンで埋める（7と8は低確率）、**OPT**を押し続ける限り無限サイクル。
- **OPT + UP** 選択内の既存ノートを変異させる：毎押下で1～3ノートをランダムに1オクターブ内でシフト（小さなシフトが多い）。8回目でサイクル開始時のノートを復元し、再度サイクル。
- **OPT + UP** 音量列のみが選択されている場合（ノート・インスト・FXセルなし）は、変異ではなくベロシティをランダム化：初回はMinimal（±20以内）、2回目はMedium（±50以内）、3回目は完全ランダム、4回目で元の音量に戻る。**OPT**解除でMinimalにリセット。音量未設定の行はそのまま。
- **OPT + DOWN** 選択内でスライス済みSamplerインストの配置されたノートを半音刻みのランに広げる：各インストの最初の（最高位）ノートはそのまま、以降のノートを1ずつ半音上げて連続スライストリガーに変換。各スライス済みインストは独立して広がり、未スライスのノートは無加工。結果はプロジェクト・スケールにスナップしない。広げた最後のノートが次のノート入力基準となるため、手動で続けると次のスライスを選択。スライス済みインストだけの選択では毎押しで広がり、未スライスノートもある場合は初回で広げ、2回目以降はそれらを使いランダムアルペジエータになる。
- **OPT + DOWN** スライス済みインストのノートなし選択では、配置済みノートに対するランダムアルペジエータ動作：CRDパレットからコードを選択（1～2ノートなら3和音、3ノートなら3和音以上、4ノート以上は任意のコード）、選択範囲内のスケール上のランダムルート（スケールOFFやトラック除外時は全半音可能）。コード音は再生時CRD同様スケールへクオンタイズ。押すごとに音の並べ替えをランダム、低→高、高→低、往復の順で繰り返し、5回目で元のノートに戻り次の押下で新コード選択。状態はステータスバーに表示され、ノートの追加・削除はなし。**OPT**解除で全リセット。
- いずれのフィル操作も書き込み前に選択ノートを消去し、配置ノートは最後に使ったインストを保持。**OPT**解除でサイクルは最初に戻る。

### Key jazz（デスクトップ限定）

Phrase画面で**Esc**を押すとkey jazzが切り替わる。QWERTYピアノスタイルのノート入力モード（[m8c](https://github.com/laamaa/m8c)に類似）：

- `Z S X D C V G B H N J M` と `Q 2 W 3 E R 5 T 6 Y 7 U I 9 O 0 P` が2オクターブ超の半音階ノート入力（キーの物理位置を使用し、AZERTY、QWERTY、QWERTZで同じ配置）
- キーを押すごとに現在行にノート入力し、カーソルは次の行へ
- `[` / `]` でオクターブシフト
- **Shift + 矢印キー**で行列の範囲選択。単純な矢印押下で選択解除
- **Ctrl+C / Ctrl+X** 選択中の列または何も選択されていなければ現在行のノート/インスト/ボリュームをコピー/カット、**Ctrl+V**でカーソル位置へ貼り付け
- **Delete** でその行を丸ごと削除し、下を上に詰める。カーソルは同行に残る
- **Backspace** でカーソル位置の要素を選択列に対して削除、下の要素を詰めてカーソルは一行上へ（テキストエディタ型）
- **Insert** 空行を挿入し、下を押し下げる
- **Ctrl+S** でプロジェクト保存（key jazz以外では無効）
- 再度 **Esc** でkey jazz終了

key jazz有効時はPhrase画面のノートキーとEdit/Opt/Motionショートカットを完全に乗っ取る。Escで解除しないと同ショートカットは使えません。

key jazzはEscで独立切替可能で以下の画面でも機能：

- **Song, Chain**: chainやphraseの16進インデックスを直接入力可能（`0-9`, `A-F`）。セル上の最初の入力で値を置き換え、続けて入力するとシフトなしで桁が増える（例：“3”の次に“F”で3F）。Songでは**Shift + 矢印**で範囲選択、**Delete**で行削除＋詰め、**Backspace**で列削除＋詰め、**Insert**で空行挿入、**Ctrl+C / Ctrl+X / Ctrl+V**で選択行（または現在行）をコピー/カット/ペースト。Phrase画面と同じ構造編集ショートカット。Shiftを引き継ぐため、key jazz中はShift+右/上でChain/Projectジャンプ不可（Escで復活）。
- **テキスト入力フィールド全般**: 画面内のバーチャルキーボードではなく直接物理キーボードでタイプ可能。対象はプロジェクトのファイル名、タイトル、作者名、インスト名、カラーテーマ名、ピッチテーブル名、bounceファイル名、名前入力ダイアログ類。Backspaceは通常のテキスト入力動作。Shiftで大文字。Escでこれら全て同時に切替。key jazzオフ時は仮想キーボードが普通に開く。
- **Instrument**: key jazz有効時はノートキーが現在トラックのインスト鳴らしチェックモードに（ノート入力なし）。Phrase画面と同じピアノ配列で、最後に押したキーの音が鳴り、キー離すと音も止まる。オクターブキーはインスト最初のノートのオクターブからシフト。**Name**フィールドは代わりにテキスト入力。曲再生中は鳴らない。

## 5. インストゥルメント

すべてのインストに共通するパラメータ：

- インストタイプ
- 名前（最大15文字）
- デフォルトテーブル速度（1行あたりのティック数）
- ボリューム
- パン
- トランスポーズのON/OFF

各インストは `00-7F` 範囲の同番号のデフォルトテーブルを持つ。補助テーブルとして使えるが、`80-FE` 範囲に補助テーブルを入れると衝突や混乱を避けられる。テーブルはChooChooTrackerの主要なサウンド設計ツールのひとつ。

### 操作

- **OPT + [LEFT/RIGHT]** インスト間移動
- **EDIT + PLAY** インストプレビュー
- **SHIFT + OPT** インストコピー
- **SHIFT + EDIT** インスト貼り付け

### SOUNDFONT（実験的機能）

元のSF2/SF3バンクやSFZ/EXSインスト（サンプル含む）、ZIPアーカイブを `instruments/USER/soundfont` にコピー。Instrument画面で**SOUNDFONT**を選択。スキャン行には **Not scanned**、**Scanning...**、**Scanned** 状態と **Rescan** アクションが表示される。スキャンはメタデータ読み込みのみで、すべてのプリセットのサンプルをメモリにロードしない。

**Preset** 行でアクティブなプリセットを表示。EDITをタップするとブラウザが開き、左にコレクション、右にプリセット一覧が表示される。コレクションはバンクファイルやZIP内のプリセットもフラットリストで表示。WAV/AIFF対応はマッピングされたインストとともに表示。単体サンプルのみのコレクションはプリセットとして列挙。ダウンロードIDやアーカイブハッシュは表示から除外、音階ノート、BPM、テイク番号は維持。EDITでプリセット選択、EDIT+PLAYで選択プリセットを試聴。

EDITを押したままPresetの左/右キーでブラウザ順番に連続移動。次コレクションへ繋ぎ、ライブラリ端でループ。高速切り替えで最新選択が準備される。現在プリセットは切替中も鳴り続け、ロード失敗時は指定プリセットのままサイレンス。**Error:** と理由はInstrument画面下部に表示。切替はそのプリセットから継続。インポートやライブラリ変更後は再スキャン推奨。プリセット状態はPreset直下に色付き表示。ロードはSongなどの他画面にメッセージなし。

**Native keys** は選択プリセットの設定ノートオン範囲をMIDIノート60をC4として表示。**(gaps)** は範囲内にマッピングされていないノートがあることを示す。ベロシティレイヤー全体の和集合であり全てのレイヤーがどのノートでも鳴るわけではない。リリース専用サンプルは範囲に含まれない。チューニングやピッチFXはこの表示もマッピング範囲も変更しない。

**Edit**（Presetの右側）で実験的SoundFontエディタを開く：チューン（-2400～+2400セント）、カットオフ（20～20000Hz）、レゾナンス（0～40dB）、エンベロープのディレイ/アタック/ホールド/ディケイ/リリース（0～20000ms）、サステイン（0～100%）、ボリューム、パン、**Bend step**（1～100セント／PBN単位）。新規インストは1セントBend step。古いファイルは**Stock**表示で過去のPBNスケール（線形モードは25セント、パリオドモードは1）を保持。細かなベンドにしたい場合は1に設定。Clearは1セントに戻す。これはSoundFontのPBNにのみ影響し、FPTは固定チューニング。ボリュームとパンはホームページに表示されるインストの値と同じ。トーンとエンベロープはデフォルトで**Bank**（オーサリング値維持）、明示的に数値を入れるとプリセットの全レイヤーで上書き。Clearは**Bank**に戻し、Tuneは0セント、音量は最大、パンはセンターに戻す。EDIT+左/右で微調整、EDIT+上/下で大きめ調整。OPTでInstrument画面に戻り、EDIT+PLAYで曲のノートかデフォルト音で試聴可能。これは楽器再生パラメータ編集用で、バンクのサンプルごとのマッピング、キー/ベロシティゾーン、ループポイントには影響しない。

チューニング、カットオフ、レゾナンスは即座に反映。アタック、ディレイ、ホールドはノートオン時設定。ディケイ、サステイン、リリースは再生中の音声に適用可能。リリースはノートOFFもしくは空行だけでなく開始される。100%サステイン時はディケイ無音。リリース時間はサンプルの実音長を超えられない。明示的なリリースオーバーライドはワンショットサンプルもノートOFFに反応。Bank設定時はオーサリング済みのワンショット挙動を維持。プリセットのキー・ベロシティ範囲は絶対的で、範囲外のノートは無音。FPTは選択済みサンプルの範囲外ピッチを範囲を変更せずに可能。編集はインストとプロジェクトファイルに保存され、元バンクを変更しない。古い曲はオーバーライドなしで元バンク設定を保持。サンプル固有の不明なループタイプを持つWAVは、そのループなしでオーディオを再生できます。Instrumentの警告は無視されたループタイプを示しますが、元ファイルは変更されません。音声の最後のサンプルを1つ超えて終わるフォワードWAVループは、サンプル境界での排他終了として警告付きで受け入れられます。PCMや明示的なSFZ/EXSループ割り当ては変更されません。他の無効なループ範囲やルートノートは特定のエラーを報告します。奇数サイズのPCMフレームレイアウトで誤って数えられた単一のゼロRIFFアラインメントバイトは警告付きで無視されますが、他の一部のPCMフレームはエラーのままです。標準的な交互/逆方向のWAVループは依然として未対応です。

**SoundFont FX** はコンテキストのLane FXピッカーに8つのコントロールを表示します。以下の値はすべてトラッカーの16進表記を使用します。FXはトラックのみを影響し、Instrumentの保存されたコントロール設定は変更しません。新しいノートはInstrument設定から開始し、その後自身の行と続く行のコマンドを適用します。

| FX | コントロール | 値 |
| --- | --- | --- |
| FPT | ピッチ | `00` = −24セミトーン, `18` = ゼロ, `30` = +24; 正確なセミトーンステップ |
| FCF | カットオフ | `00`–`FE`: 20 Hz–20 kHz, 対数スケール |
| FRS | レゾナンス | `00`–`FE`: 0–40 dB |
| FAT | アタック | `00`–`FE`: 0–20秒、短時間は細かい調整 |
| FHD | ホールド | `00`–`FE`: 減衰までの0–20秒、ノート行で設定 |
| FSU | サステイン | `00`–`FE`: 0–100%ホールドレベル |
| FDC | ディケイ | `00`–`FE`: 0–20秒、短時間は細かい調整 |
| FRL | リリース | `00`–`FE`: 0–20秒、短時間は細かい調整 |

FCF/FRS/FAT/FHD/FDC/FSU/FRLでは、`FF`がEdit設定（**Bank**含む）に戻ります。Attack/Holdはノート行に置きます。Decay/Sustain/Releaseはアクティブなノートを変更可能で、OFFを使うとリリース音を聴けます。ボリュームとパンは共通コントロールを使います。旧FVL/FPNコマンドは読み込み・再生は可能ですが、もはや提供されません。Pitch FXはバンクの選択キーゾーンを変えずにチューニングを変更します。既存のシーケンサーのピッチ/ファインピッチコマンド、MOD、トラックFXは使用可能です。プロジェクトは安定したバンク/プリセット参照とFXコマンドを保存し、サンプルライブラリは外部のままです。

すべてのバンクはUSERバンクです。大きなInstrumentはデフォルトの64 MiB PCMキャッシュを超えることがあり、未対応のソースパラメータは警告を発します。プラットフォームパス、ブラウザインポート、キャッシュ設定、フォーマット対応状況および現在の検証制限は[SoundBanksガイド](soundbanks/README.md)を参照してください。

#### SoundFont互換性: バンク、プリセット、モジュレーション

1つのSF2またはSF3の**バンクファイル**は、多数の**プリセット**とそれらのサンプルを含みます。ライブラリの**コレクション**は、ブラウザ内でこれらのファイルをまとめるフォルダーです。これらは異なるレベルであり、同じファイル内でもプリセットごとに未対応の動作がある場合があります。

**プリセットモジュレーション**とは、ベロシティ、キー、モジュールホイール、プレッシャーなどの入力からサウンドパラメータへのプログラム済みリンクを指します。これらのリンクはプリセット固有であったり、複数プリセットで共有されるInstrumentレイヤーに属したりします。バンク内のすべてのサウンドに影響する設定とは限りません。

| プリセット機能 | 現状の対応 |
| --- | --- |
| サンプル/キー/ベロシティマッピング、ルートピッチとチューニング | 実装済み。作成された範囲は保持。ベロシティゾーンと通常のトラッカーベロシティは動作。 |
| サンプルオフセット、対応するループ、ゲイン/パン、排他グループ | パーサーとボイス制限内で実装。 |
| 静的ローパスのカットオフ/レゾナンスとボリュームエンベロープ | トラッカーのレンダラー経由で実装。他のSoundFontプレイヤーと完全同一の応答は保証しない。 |
| カスタムプリセット/Instrumentモジュレーションルート（`pmod` / `imod`） | 未実装。作成されたコントローラーからパラメータへのマッピング、量、応答曲線は無視。 |
| SoundFontモジュレーション/ビブラートLFOおよびモジュレーションエンベロープルーティング | 未実装。ピッチ、フィルター、ボリュームのプログラムされた動きが欠如する可能性。 |
| キースケールドボリュームエンベロープのホールド/ディケイ、固定キー/固定ベロシティジェネレーター | 未実装。 |
| SoundFontコーラス/リバーブセンド | 未実装。トラッカーエフェクトは手動設定可能だがプリセット設定は自動再現されない。 |

以前のメッセージ**「Custom bank modulation ignored」**はファイルレベルのチェックであり、パーサーがバンク内のどこかでカスタムモジュレーション記録を検出したことを示します。これは選択されたプリセットが使用する、あるいはバンク全体が使えないという意味ではありません。この一般的な制限はここに記載し、プリセットごとにこのメッセージを繰り返しません。詳細なパーサーダイアグノスティクスは記録を保持し、他の読み込みエラーや互換性警告は該当時に表示されます。エンジンは完全なSoundFontのデフォルトモジュレーター動作を主張しません。トラッカーのPBN、ビブラート、Edit、Lane FXは独立したコントロールであり、プリセットの省略されたプログラミングの自動翻訳ではありません。

ライブラリ選択時は主にサンプルマッピング、ループ、静的エンベロープに基づくプリセットから始めてください。コントローラーからのアーティキュレーション、動的フィルター、プログラムLFOに依存するサウンドは、フルSoundFontプレイヤーで更に詳細に比較する必要があります。**読み込み・再生可能**は**プリセットを完全再現**とは異なります。役立つノートやベロシティ、ホールドノートやノートOFFも比較しましょう。SF2からSF3（またはその逆）へ変換しただけではモジュレーションの問題は解決しません。変換時にマッピングと動作をエンジンが対応可能な機能へ適切に翻訳する必要があります。エフェクトをサンプルにレンダリングすると、そのレンダリング結果だけが保存され、対話的コントローラー応答は失われます。[フォーマット対応状況と制限](soundbanks/README.md#format-coverage)および[検証ノート](soundbanks/validation.md)を読み、バンク選択や変換に役立ててください。これらの制限は現在の実験的実装を示し、すべてのSoundFontプレイヤーに共通する制限ではありません。

#### SoundFontコレクションの参照

SAMPLE → SOUNDFONT で **Preset** を押すとコレクションが開きます。**Right** または **EDIT/A** でフォルダに直接入ります。末端のコレクションでは Right でそのプリセットに進み、もう一度 Right で読み込まずに15項目進みます。EDIT/A でハイライト中のプリセットを読み込みます。Left でコレクション、続いて親フォルダに戻り、OPT でも戻れます。参照中は PLAY で曲を開始/停止します。

フォルダとサウンドのアイコンで項目を区別します。コレクションはパネルの全高を使います。選択中のプリセットは8トラックのプレビューの下に残り、長い名前は選択が1秒静止すると流れ、動かすとリセットされます。インストゥルメントページの EDIT+Left/Right も同じ入れ子フォルダの順序に従い、各コレクションのサウンドをまとめて保ちます。EDIT+PLAY で試聴します。

3行目には Reading preset、Finding samples、Unzipping、Checking samples、Loading samples が表示されます。埋め込み名が空または `(null)` の EXS インストゥルメントはファイル名を使います。元のバンクとオーディオは変更されません。ライブラリのファイルを変更したら **Rescan** を使います。

サポートされるサンプラーの動作とサンプル形式については、[形式の対応範囲と制限](soundbanks/README.md#format-coverage)を参照してください。

### AY Classic、AY Plus、AY Sample

これらはChipNomadの元々のAY/YMエンジンです。AY Classicはハードウェアスタイルのトーン、ノイズ、エンベロープコントロールを提供します。AY Plusはソフトウェアオシレーターと豊富なモジュレーションを追加。AY SampleはAYスタイルの音量レベルでサンプルを再生し、Samplerエンジンとは異なります。

#### AY Classic

ChipNomad `v1.0.0`時代のレガシーInstrumentタイプです。新しいAY Plus Instrumentはさらに多くの機能を持ちます。

AY Classic Instrumentのパラメータ:

- Mixer: トーンのオン/オフ、ノイズのオン/オフ、エンベロープ形状（`0-F`）
- Volume: ソフトウェア生成のADSRエンベロープ
- 自動エンベロープ周期: オン/オフ、レートは`1:1`から`F:F`まで

設定の**AY Quality**はAY/YMレンダリングのみに影響し、Braids、Plaits、Samplerの品質は変わりません。**サンプルディザリング**はAY Sampleの量子化に適用されます。

チップの詳細は[ChipNomad AY-3-8910ドキュメント](https://chipnomad.org/chips/ay-3-8910/)を参照してください。

#### AY Plus

AY PlusはAY-3-8910/YM2149Fのサウンド設計にクラシックシンセの概念を適用します。AYは次の5つのオシレーターを持つシンセサイザーと考えられます：

- 3つの矩形波トーンオシレーター
- 1つのノイズオシレーター
- 1つの振幅エンベロープジェネレーター（オシレーターとしても使える）

このモデルでは、各Instrumentは3つのハードウェアオシレーター（トーン、ノイズ、エンベロープ）を持ちます。AY Plusは4つ目のソフトウェアオシレーターを追加。AYレジスターの更新がプロジェクトティック速度より速いと、より多くのサウンド設計オプションが可能です。AYの動作特性上、オシレーターはリングモジュレーションでミックスされます。異なるピッチオフセット、デチューン、オシレーター組み合わせを試してみてください。

各トーンオシレーターはピッチとファインチューンで独立して調整可能です。

ソフトウェアオシレーターのタイプとパラメータ:

- Pulse - パルス幅調整可能な矩形波
  - FM Depth - シンプルなFM深度
  - Pulse width - 範囲は`00-FF`、ステップ数はProject画面で設定
  - Pulse low - 反復ペアの低値（高値は常に`15`）
- Sync Tone - トーンオシレーター用のハード同期効果
  - FM Depth - シンプルなFM深度
- Sync Env - エンベロープオシレーター用ハード同期効果
  - FM Depth - シンプルなFM深度
  - Pulse width - エンベロープペア内2形状の持続比率
  - Envelope Pair - 切り替え可能な2つのエンベロープ形状
- Wavetable - 32ステップのウェーブテーブル（Wavetable画面で編集）
  - FM Depth - シンプルなFM深度
  - Wavetable index
- Tone FM - トーンオシレーター用シンプルなFM風効果
  - FM Depth - トーンFM深度
- Env FM - エンベロープオシレーター用シンプルなFM風効果
  - FM Depth - エンベロープFM深度

PulseおよびWavetableソフトウェアオシレーターはエンベロープオシレーターと同時使用不可。エンベロープオシレーターは自動でオフになります。

シンプルFMは2つの周期値（低い値と高い値）間を高速で切り替えます。これは矩形波をFM変調器として使うのに似ています。Pulse、Sync Tone、Sync Env、WavetableはFM搬送波と変調波の比率が`1:1`です。Tone FMとEnv FMはソフトウェアオシレーターのピッチオフセットを使い他の比率を模倣可能です。

#### AY Sample

`8-bit`, `16-bit`, `24-bit`, `32-bit`のモノまたはステレオWAVファイルを読み込めます。これらは`8-bit`に変換され、16 KBに切り詰められます。この制限はZX SpectrumのRAMページサイズに対応。

AYは音量レジスターへの高速書き込みでサンプルを再生します。出力は片側性なので、サンプルを「ゼロに持ち上げる」処理が必要で、これによってサンプル終端のクリック音が除去され、静かな余韻が改善されます。

AYのDACは4ビットで非線形ボリュームスケールのため、`8-bit`サンプルは再生時に`4-bit`に変換されます。設定のSample ditheringは知覚上のビット深度を改善します。ディザリングはZX SpectrumやAtari STなどレトロプラットフォームでは実用的でないため、実ハードに書き込む場合やザラついたローファイサウンドを狙う場合はオフのままにしてください。

サンプルはAY Plusの別のソフトオシレーターのように動作しますが、追加パラメータによって別Instrumentタイプとして扱いやすくなっています。

サンプルパラメータ:

- サンプルレート - ネイティブレートで再生すると`C-4`になる
- サンプル開始位置
- サンプル長
- サンプルループ開始位置
- サンプルピッチオフセット
- サンプルファインピッチオフセット

トーンとノイズオシレーターのセクションはAY Plusと同じです。AYの動作特性上、すべてのオシレーターはリングモジュレーションでミックスされます。

### Braids

Braidsは47種類の合成モデルを提供します。主なコントロールは:

- **Model**: オシレーターまたは合成アルゴリズム
- **Timbre** と **Color**: モデル依存のマクロパラメータ
- **Filter**: 追加のLP/BP/HPフィルター（`12`または`24 dB`/オクターブ）、カットオフとレゾナンス
- **ADSR**: アタック、ディケイ、サステイン、リリース

**Model**をタップするとカテゴリ別のモデルリストが選べます。

| カテゴリー | モデル |
|---|---|
| Analog | `00 CSAW`, `01 MORPH`, `02 SAW-SQUARE`, `03 SINE-TRI`, `04 BUZZ`, `05 SQUARE-SUB`, `06 SAW-SUB`, `07 SQUARE-SYNC`, `08 SAW-SYNC` |
| Multi Osc | `09 TRIPLE-SAW`, `10 TRIPLE-SQR`, `11 TRIPLE-TRI`, `12 TRIPLE-SINE`, `13 TRIPLE-RING`, `14 SAW-SWARM`, `15 SAW-COMB`, `16 TOY` |
| Filter / Voice | `17 FILTER-LP`, `18 FILTER-PEAK`, `19 FILTER-BP`, `20 FILTER-HP`, `21 VOSIM`, `22 VOWEL`, `23 VOWEL-FOF`, `24 HARMONICS` |
| FM / Chaos | `25 FM`, `26 FEEDBACK-FM`, `27 CHAOTIC-FM` |
| Physical | `28 PLUCKED`, `29 BOWED`, `30 BLOWN`, `31 FLUTED`, `32 STRUCK-BELL`, `33 STRUCK-DRUM` |
| Drums | `34 KICK`, `35 CYMBAL`, `36 SNARE` |
| Wavetables | `37 WAVETABLES`, `38 WAVE-MAP`, `39 WAVE-LINE`, `40 WAVE-PARA` |
| Noise / Granular | `41 FILTER-NOISE`, `42 TWIN-PEAKS`, `43 CLOCK-NOISE`, `44 GRAN-CLOUD`, `45 PARTICLE`, `46 DIGI-MOD` |

#### パラメータ

TimbreとColorは選択モデルによって異なります。全モデル一覧と詳細はMutable InstrumentsのオリジナルBraidsマニュアルを参照するか、耳で確かめながら演奏してください。

#### VCFとVCA

Braidsは標準のChooChooTrackerマルチモードフィルターとADSRエンベロープを供給します。

#### 設定

グローバルなBraids設定はアプリのSettingsで利用可能:

- **BITS**: 出力解像度を下げる
- **DRFT**: オシレーターのピッチ不安定性を追加
- **SIGN**: オリジナルのBraids波形の不完全性アルゴリズムを再現

### aChChid**aChChid** は Open303 ベースのモノフォニック・アシッド・ベースエンジンです。`Square` と `Saw` はネイティブの TB-303 オシレーター、フィルター、エンベロープ、アクセント挙動を使用します。`Braids` はオシレーターのみを置き換え、同じ 303 フィルターとアンプの経路を通ります。Model、Timbre、Color、そして追加のウェーブシェイパーを操作可能です。シェイパーはソフトサチュレーションからウェーブフォールディングへ進行します。

カットオフとディケイは対数編集を使います。**EDIT + LEFT/RIGHT** で音楽的コントロールステップ1刻み、**EDIT + UP/DOWN** で16刻み。カットオフは200 Hz～20 kHz、ディケイは200 ms～2秒の範囲です。

ノートボリューム列に `F` があるとアクセントがトリガーされます。`ASL` は前のピッチから 303 エンベロープを再トリガーせずにそのノートへスライドします。自動的に前のゲートをホールドし、`ASL 00` は `60 ms` のグライドです。`ATY` はそのステップ全体でノートを開いたままにします。`ASL` がないノートは必ず再トリガーされます。

モジュレーションのデスティネーションにはディケイ、アクセントに加え、Braids 波形モードで Timbre と Color があります。

### Bogie

**Bogie** はネイティブのワンショット・ドラムシンセサイザーです。トラッカーノートがピッチを、トラッカー／楽器ボリュームがレベルを設定。トリガーごとに独自のディケイがあり、ADSR ページはありません。12種類のモデルがあり、`Kick`、`Snare`、`Hat`、`Clap`、`Tom`、`Rim`、`FM`、`Noise`、`Cowbell`、`Cymbal`、`Shaker`、`Clave` です。

6つのマクロは **Decay**, **Tone**, **Sweep**, **Noise**, **FM**, **Drive**。ラベルは状況に応じて変わります（例：Kick の Noise は `Click`、Cowbell の FM は金属的なクロスモジュレーション）。どのモデルでも全マクロがアクティブですが、マクロの音楽的役割はモデルによって変わります。Sweep はピッチ、バースト間隔、金属的広がりを変化させ、FM はクロスモジュレーションや金属的なレイヤー、リング状倍音を加えます。各レンジの下半分は通常のドラムサウンド用、上半分は幅広いティンバー変化やよりシンセティックな結果を狙っています。

どのモデルも共有のLP/BP/HPマルチモードフィルターを使用可能。Clean、Classic、Aggro、Acid キャラクター、`12`／`24 dB` スロープ、カットオフ、レゾナンスがあります。Bogie はアクティブなマクロのほか、ボリューム、ピッチ、カットオフ、レゾナンスもモジュレーションとモーション記録の対象です。Cowbell で短めのディケイを使うとシャープなフォンクアタックに。FM を上げるとより硬質で金属的なベル音に。

モジュレーション画面で、ソース上で **EDIT** を押すとファミリー（Envelopes、LFO、Sticks）を選択可能。左右キーでソースを直接切り替えられます。

### Sintered

**Sintered** はネイティブのワンショット・デジタルパーカッションシンセです。ノートが基本ピッチを設定。6モデルは `Knot`、`Shard`、`Burst`、`Comb`、`Logic`、`Melt`。各モデルに **Decay**、**Mod**、**Motion** のほかモデル固有の3つのコントロールがあります。Knot は Ratio/Spread/Fold、Shard は Ratio/Feedback/Bite、Burst は Noise/Color/Feedback、Comb は Time/Damping/Regen、Logic は Rate/Pattern/Crush、Melt は Ratio/Chaos/Drive。**Mod** は常に内部カップリングの深さ。

Motion は内部マクロエンベロープで、値が `80` 未満はAD形状、`80` で無効、`80` 超はディケイのみ形状。中心から離れるほどエンベロープは速くなります。行き先はモデルごとに固定。これで Sintered はトラッカーパターンで予測可能な動作です。Knot は Mod/Fold、Shard は Feedback/Bite、Burst は Noise/Color/Feedback、Comb は Damping/Regen、Logic は Rate/Crush、Melt は Chaos/Drive を動かします。全モデルがノートトリガー時に状態をリセットし、内部フィードバックは繰り返し可能なヒット用に制限されます。

### MonkSynth

MonkSynth はボーカルシンセサイザーです。Instrument ページから母音、声質、息づかい、グライド、ビブラート、ユニゾン、ディレイを操作します。EDIT で全コントロールとパッチ名を開きます。

VOICE コントロールでバンクとプリセットを選びます。ALL は FACTORY と USER を含みます。EDIT+PLAY でハイライト中のプリセットを試聴し、EDIT で選択します。自作サウンドは `instruments/USER/monk/` に保存します。保存したインストゥルメントと曲は MonkSynth の設定を保持します。

値は16進の `00..FF` です（Voices のみ `01..0A`、1〜10ボイス）。Attack、decay、release は 0..5 秒、detune は 0..50 セント、ボイスの広がりは 0..0.5 です。Volume、Pitch、および6つの主要な声のコントロールはモジュレーション先とモーション録音の対象になります。

16個のコントロールは **MonkSynth FX** にまとまっています：`MWV`（母音）、`MIN`（声）、`MAM`（息づかい）、`MFL`（グライド）、`MFB`（ビブラート深さ）、`MSH`（ビブラート速度）、`MUV`（ボイス数）、`MDT`（detune）、`MVS`（広がり）、`MDM`（ディレイミックス）、`MDR`（ディレイ速度）、`MLV`（レベル）、`EAT`/`EDC`/`ESU`/`ERL`（ADSR）。これらの意味は MONK がアクティブなインストゥルメントのときに適用され、MME コマンドの既存の意味は変わりません。共有の Trigger FX グループは TDC/TCL を維持し、エンベロープ項目は重複しません。

### MME

**MME** (Multi Modulation Engine) は2オシレーターのシンセで、オシレーター間の相互作用に特化。モデルは `Ring`、`Fold`、`Cross`、`VPM`、`Sync`、`Logic`、`Vocode`。両オシレーターは内部でトラッカーノートに従い、`Interval` で関係を設定。

6つのマクロは **Waves**、**Interval**、**Amount**、**Flow**、**Feedback**、**Shaper**。Waves は音楽的な A/B 波形ペア間を補間。Amount がモデルのコア相互作用を制御、Flow は方向やアルゴリズムの変種を切り替え、Feedback は範囲内で制限的だが終端は意図的に暴れます。Shaper は共有の最終段で、クリーンからサチュレーション、ウェーブフォールディングへ動きます。

MME は共有のLP/BP/HPマルチモードフィルターと ADSR を使います。6つのマクロ、カットオフ、レゾナンスがモジュレーションとモーション記録に対応。Model 上で **EDIT** を長押しするとモデルポップアップが開きます。

### MIDI Out

**MIDI Out**（デスクトップ、PortMaster、Web MIDI 対応ブラウザ）は音声合成ではなく外部MIDI機器を駆動します。ノートをトリガーすると楽器の **Channel**（`1-16`）で実際の MIDI Note On を送信し、ノート終了時に対応する Note Off。ボリュームはベロシティに変換され、コードトラックの各ボイスは独自のNote On/Offを持ちます。ChooChooTracker 自体からは音は出ません。まず [Settings](#13-settings) で MIDI 出力機器を選択してください。MIDI キーボードからの音のプレビューも含む詳細は [MIDI](#15-midi) を参照。

**Program** と **Bank high/low**（CC0／CC32）は任意で、オフ時は `--` 表示。`Clear` はフィールドをオフにし値を記憶。設定されると、チャネルに最後に送信した値と異なる際に次のノート直前に一度だけ送信（毎ノート前ではない、受信機側のエンベロープ／パッチの再トリガー回避のため）。

**MC1 number**～**MC4 number** は4つの MC1-MC4 行 FX が送る CC 番号（`00-7F`）を選択、詳細は [MIDI Out FX](#midi-out-fx) 参照。こちらも `--` で任意設定。未設定のスロットは FX 無効。

### クラシックアーキテクチャエンジン

このカテゴリのエンジンは VCO → VCF → VCA のアーキテクチャを共有。

利用可能な VCO タイプ：

- **Braids**
- **Plaits**
- **Plaits-Alt**
- **Sampler**
- **2xSCWF**
- **BYOWTBL**

各楽器は VCO をマルチモードフィルターに入力。

フィルターは `12 dB` または `24 dB` スロープ切替可能、ローパス（LP）、バンドパス（BP）、ハイパス（HP）で動作。

利用可能なフィルターキャラクター：

- **Clean**: 無菌的でデジタルな音
- **Classic**: 古典的な米国製アナログシンセに着想
- **Aggro**: 荒々しい日本製アナログシンセに着想
- **Acid**: Aggro の2倍の荒々しさ

Classic、Aggro、Acid は強く共鳴します。最初は低めにして徐々に上げてください。

フィルターは ADSR エンベロープで制御される VCA に入力。エンベロープシェイプは指数、線形、対数曲線間で変化可能。

#### Plaits と Plaits-Alt

**Plaits** は24エンジンを持ち、選択ポップアップで以下のグループに分かれています：

| カテゴリー | エンジン |
|---|---|
| Analog / Waves | `00 VA VCF`, `01 PHASE DIST`, `05 WAVE TERRAIN`, `06 STRING MACH`, `08 VIRTUAL ANALOG`, `09 WAVESHAPING`, `11 FORMANT`, `12 HARMONIC`, `13 WAVETABLE`, `14 CHORD` |
| FM | `02 6-OP FM 1`, `03 6-OP FM 2`, `04 6-OP FM 3`, `10 2-OP FM` |
| Digital | `07 CHIPTUNE`, `15 SPEECH` |
| Texture / Noise | `16 SWARM`, `17 NOISE`, `18 PARTICLE` |
| Physical | `19 STRING`, `20 MODAL` |
| Drums | `21 BASS DRUM`, `22 SNARE DRUM`, `23 HI-HAT` |

**Plaits-Alt** はオリジナル Plaits モジュールの代替モデル集。大半は普通のVCOより奇妙か実験的。

| カテゴリー | エンジン |
|---|---|
| Granular / Micro | `GLISSON`, `PULSAR`, `GENDY`, `SCANNED`, `LOOPBACK` |
| Phase / Harmonic | `PHASE WEAVE`, `SIDEBAND BANK`, `UNDERTOW`, `ATTRACTOR`, `LOCKSTEP` |
| Acoustic / Physical | `REED PIPE`, `BRASS`, `SHAKERS`, `CLAPS`, `FRESHETS FORMANT` |
| Polyphony / Harmony | `DIATONIC CHORD`, `SCALE STACK`, `WT DIATONIC CHORD`, `WT SCALE STACK`, `HELIX` |
| Digital / Weird | `BYTEBEAT`, `RULEFIELD`, `SPECTRAL SPIRAL`, `PHASE FLOCK` |

パラメーターは Mutable の設計に準拠：

- **Harmonic** はエンジン内部の倍音関係、バランス、モデル選択を制御。
- **Timbre** は暗い／疎から明るい／密へスペクトルの変化。
- **Morph** は別のティンバー次元へ探索。
- **Main/Aux** はメイン出力とエンジンの代替出力をブレンド。

意味はエンジンによって異なります。例としてコードエンジンはコードタイプ、転回、波形に使い、フィジカルモデルは材質、励起、ディケイ、ドラムエンジンはトーン、キャラクター、ディケイに使います。詳細は Plaits マニュアル参照。

`CHORD`、`DIATONIC CHORD`、`WT DIATONIC CHORD` では Harmonic が選択されたコード名（`MIN`, `MAJ`, `MIN7`, `MAJ7` など）を表示。Braids の `WAVE PARA` も同様に Color ボイシングを名前表示。

**Engine** をタップするとカテゴリ別エンジンリストから選択可能。

**Env Mode** は2つのルーティング：

- `TRIG` は TRIG 端子接続、LEVEL 未パッチのモジュール動作を再現
- `VCA` は LEVEL を常に開き、トラッカー ADSR をボイス後段に適用

#### Sampler

このクリーンな Sample エンジンは RAM にロードされたモノまたはステレオ PCM サンプルを再生します。- タップして**Sample**、非圧縮の`8-bit`、`16-bit`、または`24-bit` PCM WAVを読み込みます。ブラウザで**PLAY**を押すと、選択中のファイルを試聴できます。
- サンプルが読み込まれると、名前の隣に**EDIT**が表示されます。タップするとSample Edit画面が開きます。**OPT** または **SELECT + [LEFT]**で楽器画面に戻ります。
- Sample Edit画面にはファイル名（RAM内のサンプルがディスク上のファイルと異なるときは`*`マーク付き）、フォーマット情報（サンプルレート、チャンネル）、縦長の波形、**Region**、**Select**、**Slice**、**Process**、**File**フィールドがあります。
- 編集内容は保存するまでRAM上にのみ存在します。プロジェクトはサンプルのファイルパスを保存し、プロジェクト次回読み込み時にディスクからWAVを再読み込みするため、**Save**/**Save As**しないままトラッカーを離れると編集内容は破棄されます（`*`マークが警告）。別のサンプルを読み込むと未保存の編集が破棄され、Regionは全サンプルにリセットされます（Start `00`, End `FF`）。
- **Region**は再生の開始・終了マーカーを設定します。Samplerの楽器画面でも設定可能です。範囲は正規化されており(`00-FF`)、StartがEndより後ろなら逆再生されます。**EDIT + [LEFT/RIGHT]**で1ステップ(`01`)ずつ微調整しながら波形を中心付近にズーム、**EDIT + [UP/DOWN]**で16ステップの大まか調整をし波形を全体表示に戻します。**EDIT + OPT**でマーカーをデフォルト（Start `00`, End `FF`）にリセットします。
- 波形ビューは編集マーカーの周囲1秒間の固定ウィンドウにズームし、見える範囲にパンします。1秒以内のサンプルは1:1表示のままです。ズームは**EDIT**を押している間のみ有効で、離すと全体表示に戻ります。粗調整でも全体表示に戻ります。画面に入るたびに全体表示にリセットされます。
- **Select**は処理対象を絶対フレーム単位で選択し、再生のStart/Endに依存しません。**EDIT + [LEFT/RIGHT]**でハンドルを20フレーム動かしズーム、**EDIT + [UP/DOWN]**で`frameCount/64`（最小16）フレーム跳びながら全体表示に戻ります。**EDIT (タップ)**で現在のStartまたはEndマーカー位置をハンドルにコピーします。**EDIT + OPT**で選択範囲を空にします。空の場合はハンドルに`-`を表示。ハンドルが逆転した場合は自動で入れ替わります。選択はセッション限定の編集状態でプロジェクト保存されません。画面に入ると再生Region範囲（デフォルトマーカーによる全体）で初期化されます。
- **Slice**は1列4セルの**Mode**、**Count**、**Slice**、**Frame**を持ち、楽器に保存されます。OffはStart/End範囲を再生。Phraseノートは**C-0**からクロマティックにスライスを選択。最後のスライスを超えたノートは最初に戻ります（ノートNはスライス`N % count`を再生）。スライスはピッチ変換やScale量子化されませんが、**CRD**は選択スライスを保持しコード調にトランスポーズします。スライス開始点は波形上に2ピクセル幅の短い線（濃オレンジ）で表示され、現在スライスはより明るく表示。ポインター下のスライスは波形上に黒い背景帯が付きます（選択色は帯の上に描画されず、判別しやすくなります）。
  - **Mode**は`OFF` / `EQUAL` / `AUTO` / `LAZY`を切り替えます（EDIT + 左右キーかタップで変更。EDIT + OPTでスライスオフ）。モード切り替えでスライスポイントが初期化されます。**EQUAL**はStart/Endを**Count**に均等分割。**AUTO**は範囲内にある全てのアタックにスライスを設定（最大**Count**まで）。**LAZY**は範囲全体を1スライスで開始。LAZY切り替え時は現在のEQUAL/AUTO設定（カウント・範囲）を保持し、戻すとそのまま復元されます。SliceとStretchは排他機能。片方有効で片方無効。Stretch使用中はSliceのセルが薄くなります。
  - **Count**はスライス総数（`01`〜`64`）表示。**EDIT + [LEFT/RIGHT]**で1ずつ増減（最小1、最大64）、**EDIT + [UP/DOWN]**で`2 / 4 / 8 / 16 / 32 / 64`の値を順送り＋ラップ。変更される度に分割を再計算。**EQUAL**は均等に、**AUTO**は新しいカウントで検出を再実行（スライス数が多いと感度が上がる）。モードがOFF時は`-`表示。LAZY時は手動配置スライス数を表示し続けるが選択不可（カーソル移動で飛ばされ、タップも無効）。**EDIT + OPT**や通常のタップはここでは無効。スライスOFFは**Mode**で切ります。スライス削除は**Slice**で行います。
  - **Slice**はブラウザで1始まり（`01`からスライス数まで）。**EDIT + [LEFT/RIGHT]**で1スライスずつ移動、**EDIT + [UP/DOWN]**で4スライスずつジャンプ（いずれも範囲内）。選択スライスは波形上の明るいマーカーと黒帯で示され、ズームも開始地点にセンター。**EDIT + OPT**で現在スライスを削除（前のスライスに結合）。最初のスライスは削除不可。最後のスライス削除はスライスモードをOFFにし、範囲は保持。**EDIT (タップ)**で現在スライス単発再生（どのモードでも可能。キーを離すか画面を出るまで再生）。モードOFF時は`-`表示。
  - **Frame**は現在スライスの開始フレームを16進数で表示。**EDIT + [LEFT/RIGHT]**で10フレームずつ微調整（EDIT押下中はマーカーにズーム）、**EDIT + [UP/DOWN]**で100フレーム動かして全体表示に戻る。マーカーは自身のスライス内に固定で、隣のスライス開始点を越えられません。**EDIT + OPT**でスライス削除。
  - **B**はどこからでもSlice行で楽器画面に戻ります。**SHIFT + LEFT**はどこからでも終了。
  - **LAZYワークフロー**：LAZY選択中に**PLAY**を押すとサンプル全体の単発再生開始。サンプルの原音程・速度で1回再生し、自動停止します（波形上に緑2ピクセルマーカーが進行位置を示す）。もう一度**PLAY**を押すと停止。再生中に**EDIT**を押すと再生位置にスライスを追加（カーソル位置は問わず）。50ms以内に位置が近いスライスは`Too close to slice`で拒否。再度再生すると既存スライスを保持しつつ追加スライスが順に増え、**Count**と**Slice**が更新されます。手動配置スライスは他モードと同じルールで編集可能：**EDIT + 方向キー**でブラウズ、**Frame**で調整、**EDIT + OPT**で削除。再生時にスライス追加が準備されている間はFrameセルが薄暗くなります。**SHIFT + PLAY**はLAZY中も無効にならず、他画面同様フレーズ再生を開始します。LAZYスライスはEQUALやAUTOと同様にシーケンサー上でフレーズノートが**C-0**からクロマティックに割り振られ、最後のスライスを超えたノートは最初に戻ります。
  - **コンボヒント**：スライス行のセル上にカーソルを置き、他のメッセージがなければステータスバーに該当セルのヒントを表示し、カーソルがある間保持します。**Mode**は現在のモード名がセルにあるため説明文のみ表示：`Divides sample in equal parts`（均等分割）、`Divides sample based on transients`（トランジェント分割）、`Press Play and add slices with EDIT`（PLAYとEDITで追加）など。モードを切り替えると即座にテキストも切り替わり、OFFならバーをクリアします。**Count**は`Adjust the number of slices`（スライス数調整）、**Slice**は`Browse slices`（スライス選択）、**Frame**は`Adjust slice start`（開始位置調整）と表示。操作メッセージが出るとヒントはそれに置き換わります。
- **Process**は破壊的編集操作を選びます：**Crop**, **Normalize**, **Delete**, **Silence**, **Fade In**, **Fade Out**, **Reverse**（EDIT + 左右で循環、タップで前進、EDIT + OPT でなし設定）。同行の**GO**で現在選択範囲、空の場合は全サンプルに適用。**Crop**は選択範囲のみ保持。**Normalize**はピークを最大に拡大（左右チャンネルは同一ゲイン維持しステレオイメージを保つ）。**Delete**は選択削除し残りを接続（全削除は不可）。**Silence**はゼロ化。**Fade In**/**Fade Out**は選択範囲を線形フェード。**Reverse**は選択範囲を波形反転（フレームの配置入れ替え、チャンネルは一緒に、長さやマーカーは維持）。Crop/Deleteは選択必須。空選択時は`Select region first`を表示。すべての処理は音声を一時停止し、1段階のUNDO機能を保持し、RAM上のサンプル状態を変更します。ディスクファイルはSave操作まで更新されません。画面遷移でUNDOは破棄されます。
- **UNDO**は**GO**隣にあり、直前の操作前の状態に切替えます。操作未実行時は薄暗く不活性。繰り返し押すと操作前後を切替。画面再入時にクリア。
- **File**は保存操作を持ちます。楽器は読み込んだWAVファイルのフルパスを持ち、これを上書きまたは別ファイルに書き出します。楽器名は変更されません。
  - ファイル欄は**Save**と**Save As**を切替（EDIT +左右、またはタップ）。同行の**GO**で実行。
  - **Save**は元ファイルを上書き。スライスなしサンプルは`Overwrite <name>?`の確認。スライスがある場合は**SAVE SLICES**ダイアログが開き、スライスポイントの保存先を選択：**SAVE TO SAMPLE**はWAVのcueチャンク内に記録（DAWでマーカー表示可能）しプロジェクトにも保持、**SAVE TO PROJECT**は通常WAVで保存しプロジェクトにのみポイント保持、**CANCEL**で中止。`このプロジェクトで今後聞かない`チェックを付けると選択先がプロジェクトに保存され今後ダイアログは表示されません（.cct内に`- Sample save choice:`として保存、手動編集でのみ変更可能）。スライスなしサンプルはダイアログがスキップされます。サンプルにファイルパスが無い場合はSaveが薄暗くなり選択不可。書き込み失敗時は`*`マークが残りエラー表示。
  - **Save As**は新規ファイルに現在のサンプルを書き込みます。拡張子なしで現在名が初期入力され、ブラウザでフォルダ選択。`<folder>/<name>.wav`として書き込みし、楽器は新ファイルを参照、選択フォルダはデフォルトになります。サンプルが読み込まれるまで薄暗くなり無効。パス長255文字超は拒否。
  - ファイル名前の`*`マークはRAMとディスクのサンプルが異なることを示します（プロセス操作で設定、SaveやSave Asでクリア）。マークはセッション限定で保存されず、画面切替時にリセットされます。複数楽器が同じWAVを参照している場合、1つの保存は全ての楽器に影響します。
- Sample楽器画面で**EDIT + [LEFT/RIGHT]**を押すと同フォルダ内の前後のWAVを読み込みます。
- **Pitch**は半音単位でトランスポーズします（`-48`〜`+48`）。
- **Loop**はOff、Loop、Ping-Pongを選択。
- **Speed**はグラニュラータイムストレッチを`0%`〜`500%`で調整します（`100%`は原速）。サポートされていないWAV形式はエラーを表示します。特殊なファイルはインポート前に`PCM8`、`PCM16`、または`PCM24` WAVに変換してください。

##### オーディオ入力

マイクや USB オーディオインターフェースから録音する前に **Settings → Audio → Audio Input** を開きます。リストには、その時点でデバイス上で利用可能な入力が表示されます。アーム済みのインターフェースが抜かれると、キャプチャは中断され、アプリが動作し続けるようオーディオマネージャーが再起動します。録音中だった場合は **STOP** を押して中断したテイクを終了してください。再接続後は **[Refresh]** を選び、目的の入力がアームされていることを確認してから再度録音します。再接続だけでは確実に再アームされません。**[List]** はオーディオを再起動せずに現在の入力リストを再読み込みします。

入力の **ARM** チェックボックスを選ぶと、Sampler のレコーダーで使えるようになります。小さなメーターが入力レベルを表示します。一度にアームするインターフェースは1つにしてください。このバージョンでは複数チェックしても最初のアーム済みインターフェースしか開きません。選択はデバイス名で記憶されるため、利用できないインターフェースは別の入力に置き換わらずアームされないままになります。**OPT** で Audio 設定に戻ります。

##### オーディオ入力の録音

Sample インストゥルメント画面で **REC**（サンプル読み込み済みなら **EDIT/REC**）を押すと、録音と編集を1画面にまとめたサンプルエディタが開きます。先に **Settings → Audio → Audio Input** 画面で入力をアームしてください（[オーディオ入力](#オーディオ入力)参照）。エディタ上部の行が録音を制御します：

- **Input** は録音ソースを切り替えます：`T1`..`T8` はトラッカーの8トラックを録音し、続いてアーム済みのマイクまたは USB インターフェースになります。外部ソースを録音するには `T8` を越えてデバイス名が表示されるまで進めます。`-` は明示的にソースを選んでいない状態で、**REC** は最初のアーム済み入力を使い、その名前を表示します。**EDIT** を押しながら **LEFT**/**RIGHT** で戻る/進む、**EDIT+OPT** で `-` に戻ります。Input をタップすると直接進みます。
- **Input** 横のレベルメーターは、アーム済み入力のライブレベルを表示します（外部ソースのみ）。**MON** は入力モニタリングを切り替えます：フィードバックを抑えるため、アーム済み入力は -6 dB で出力に送られます。設定は設定ファイルに保存されます。
- **REC** で録音を開始します。外部ソースはすぐに録音され、トラックソースは **ARMED** を表示して再生開始時（**PLAY** を押す）に録音が始まります。**STOP** で録音を終了します：WAV はプロジェクトのエクスポートフォルダ（`recNNN.wav`）に書き込まれ、現在の Sampler インストゥルメントに読み込まれ、Region はサンプル全体に戻ります。録音中に **OPT** で画面を抜けた場合も同様に終了します。
- **PLAY**（録音後に表示）はテイクを試聴し、プレビュー再生中は **STOP** になります。隣の **CLEAR** は WAV ファイルを削除してインストゥルメントからサンプルをアンロードします。削除後は **REC** が元の位置に戻ります。
- 波形は録音中はライブ入力を、終了後は全体の波形を表示します。ステータス行は録音中はファイル名を、その後はフレーム数を表示します。外部テイクではオーディオフレームの欠落がなければ `drop 0` も表示されます。録音したサンプルは完全に編集可能で、ループ領域、選択、スライス、処理、保存は読み込んだ他のファイルと同じように動作します。

録音は選択したオーディオサンプルレートで16ビットステレオ WAV として書き込まれます。トラックソースはトラックのインストゥルメントがレンダリングしたもの（FX 後）を、外部ソースはデバイス入力を直接キャプチャします。

#### 2xSCWF

2xSCWFはデュアルシングルサイクル波形オシレーターです。各オシレーターに正確に1周期を含むモノラルWAVを1ファイル読み込みます。両方のオシレーターは周期の終わりでループしながら順方向に読み込みます。

MixでAとBをクロスフェードします。

Detuneはユニゾンから`+200 ct`まで微調整され、その後`+3 st`から`+24 st`まで半音階単位で変化します。

2xSCWFは各ファイルを1周期のテーブルとして扱い、オシレーター周期ごとに1回だけ正確に読み込みます。これにより2つのシングルサイクル波形をブレンドおよびデチューン可能です。

工場出荷時の`waveforms/AKWF/`フォルダーにはAdventure Kidライブラリの波形が含まれています。コレクション拡張はオンラインに多数あります。

#### BYOWTBL

BYOWTBLはSerum互換のデュアルウェーブテーブルオシレーターです。各オシレーターは連続したシングルサイクルフレームを含むモノラルWAVを読み込みます。`Pos A`と`Pos B`は独立してテーブルを`00`から`FF`までスキャンします。エンジンは各フレーム内および隣接フレーム間を線形補間します。`Mix`はオシレーターをクロスフェードし、`Detune`はオシレーターBのオフセットです。

### FM楽器ファミリー

#### ネイティブOPLLとVRC7楽器

Instrument TypeセレクターにはFMグループがあり、**OPLL / MSX** (YM2413) と **VRC7** (DS1001)があります。それぞれスクロール可能なBank / Presetリストで**73プログラム**を提供：オリジナルの15音色、emu2413のYM2413/VRC7/YMF281Bテーブル由来の40音色、そしてChooChoo製の18の2オペレーター音色。各エンジン内で完全に重複する音色バイトは省かれています。追加のパレットはチップのプログラム可能なトーンスロットを使用し、物理ROMは拡張しません。プログラム0はカスタム音色を示します。EDIT + 左右キーでバンクフィルター内の前後プリセットを選択可能。Fine ctは-100〜+100セントの微調整です。

プログラムリストでEDIT + PLAYはハイライト音色を試聴し、ボタンを離すと停止します。EDITで確定、OPTでキャンセル。ブラウズや試聴は楽器・テーブル・曲を変更しません。通常のInstrumentページの試聴操作も選択後に有効です。ネイティブチップのエンベロープがアタック/リリースを供給し、オプションのAmp envでソフトウェアADSRを追加可能（下記のNative chip controls参照）。完全なオペレーターエディターはありません。

#### AdLib / OPL2とOPL3

FMにはAdLib / OPL2 (YM3812) と OPL3 (YMF262)も含まれます。Bankは工場リストをフィルターし、PresetはカテゴリグループとAll表示を開きます。EDIT + PLAYで選択前に試聴、EDITで選択、OPTでキャンセル、EDIT + 左右で前後の一致するエントリーを読み込み。Fine ctはローカルチューニングを調整。Modeは2オペレーター、4オペレーター、またはDual voiceを表示。OPL2は非対応のOPL3パッチを隠し、OPL3は共有2オペレーターコレクションを再生可能。

BankとPresetのポップアップは現在のエンジンを明示。エンジンや楽器スロットを切り替えるとバンクフィルターが**All banks**にリセットされ、対応するAdLibとOPL3間の切り替え時も同様。同じスロット内のポップアップ終了時は選択されたフィルターを保持。DX7バンクのインポートキャンセル時は前のフィルターに復帰。

プリセット確定はボタンリリース時の編集内容を次のUI/オーディオティックに反映。曲演奏中も再度のボタン押下やトランスポート再起動が不要に。出力は設定されたオーディオバッファとエンジンのエンベロープ/リトリガービヘイビアに従います。

工場コレクションはFat Man 2-op、Fat Man 4-op、DMXOPL3の697エントリーを含み、589個の正規化されたユニークパッチを収録。エイリアスは元名と帰属を保持。元ソースのオペレーターレベル、LFO深度フラグ、ノートオフセット、固定パーカッション音程、デュアルボイスチューニングを維持。Trackerボリュームはソフトウェア振幅を使用し、原MIDIプレイヤーのボリュームカーブやベロシティオフセット方式は再現しません。元ソースのリリース持続時間推定は長音を切りません。効果の中にはアタックが遅いものもあり、Seashoreは短いクリックでの明瞭化を期待せずに保持してください。

プリセット選択ではスロットのテーブルやトラックインサートは変更されません。

#### セガPSGとゲームボーイネイティブ楽器

CHIPにはセガPSG、GB Pulse、GB Noiseが含まれます。セガPSGの**Bass range: Extended**は低音を明確に保持。元の狭い範囲では低音が収束し、**Chip**を選択。固定レートノイズは元のピッチを保ち、トーン由来ノイズは選択されたベースレンジに従います。
GB楽器はDMGパルス/ノイズレジスターを使用し、GB波形チャンネルは公開しません。プリセットリストはそれぞれ**24、24、28**プリセットを含みます。追加はリンク/周期セガノイズ、GBピッチスイープ、短いパーカッション、金属音ノイズ、ドローン、ライジングをカバー。これらはオリジナルプログラムで、ゲームサウンドではありません。
ページはネイティブのモード/デューティ/幅、エンベロープ/スイープ/ノイズコントロール（適用可能な場合）、およびソフトウェア振幅ADSRを提供します。

#### DX7 FM

**Type → FM → DX7 FM**を選択します。DX7はArcade / YM2151に続く7番目です。DX7 FMは6オペレーターを使用。ページには共通設定に加えBank、Preset、Fine ctがあります。プリセットブラウズはバンク/カテゴリリストを使用。EDIT+PLAYを押し続けてハイライト音色を聴き、放すと停止。EDIT単体でリリース時に確定、OPTでキャンセル。サウンドロードはトラッカーテーブルやトラックインサートFXを変更せず完全なパッチをコピー。

永続的な個人ライブラリには`.syx`ファイルを**`instruments/banks/dx7/`**に既存のライブラリ横へ配置。サブフォルダーも対応。**DX7 → Bank**を開くと各ファイルが名前付きバンクとして表示され、プリセットブラウズ可能。ファイル追加・削除後はBankを再度開くこと。変換やLoad Instrument手順は不要。標準的なDX7/TX7オリジナルバンクは**32音色**。4バンクメッセージのファイルは4つのバンク（合計128音色）として表示。単一音色ファイルも受け入れ可能。選択したパッチは楽器とともに保存され、元バンクの削除で曲は変化しません。

**Load Instrument**はDX7/TX7 `.syx`単一音色や32音色バンクも受け入れ。パッチ選択で適用、キャンセルで現在の楽器を維持。永続ライブラリには上記Bankフォルダーを使用。編集済みパッチは曲または`.cni`で保存。未対応ヤマハ形式は拒否。

DX7は曲全体で**16同時発音制限**（コードボイス・リリーステール含む）あり。制限に達するとリリーステールが優先的に解放され、その後静かなホールドノートが解放され、新しいアタックの再生性を維持。曲再生中はプリセット試聴不可。

#### FMオペレーターエディター

Genesis FM、Arcade FM、OPL2、OPL3、OPLL、VRC7楽器にはFine ct右隣に**EDIT**ボタンがあります。押すとパッチパラメーターのテーブルが開きます：

- Genesis FM / Arcade FM
- OPL2 / OPL3：OPL3ではここでモード（2op、4op、dual）を変更できます。
- OPLL / VRC7：ROMプリセットを編集すると「Custom」になります。

左右キーや通常の編集キーで値を変えられ、楽器は再生を続けるので変化を聴きながら操作可能。ステータスバーはカーソル下のパラメーターを表示。OPTまたはLeft+Shiftで楽器画面に戻ります。DX7とSIDにはオペレーターエディターなし。

Genesis FM (YM2612) と Arcade FM (YM2151) は他のFMエンジンと同じBank/Presetブラウザー、試聴、微調整を使い、ネイティブエンベロープがリリースを制御。Trackerのボリュームやピッチ変更は再トリガーしません。

#### FM工場およびUSERプリセット

ネイティブチップ楽器は**Bank:**でALL、付属コレクション、USERを選択。**Preset:**でその選択内の音色を選びます。EDITを押しながら左右キーで循環、短いEDITタップで選択画面を開く。

付属コレクションは`instruments/FACTORY/`内のZIPパック。USERファイルは`instruments/USER/<engine>/`（例：`dx7`、`opll`、`vrc7`、`opl2`、`opl3`、`genesis`、`arcade`、`sid`、`sega`、`gb-pulse`、`gb-noise`）に配置。フォルダーを直接参照するか対応プリセットのZIPを置ける。ZIPはディスク上のまま。これら全てのフォルダーは互換の`.cni`ファイルも受け入れる。CNIはChooChoo/ChipNomadの携帯型楽器フォーマットで、チップメーカーの標準ではない。USERブラウザーは以下のソース形式も読み込み、ZIP内も対応：

| USERフォルダー | 追加対応形式 |
| --- | --- |
| `dx7` | Yamaha DX7/TX7 `.syx` 単一音色・32音色バンク |
| `genesis` | `.tfi`、DefleMask `.dmp`、Furnace `.fui` |
| `arcade` | VOPM `.opm`バンク、DefleMask `.dmp`、Furnace `.fui` |
| `opl2`、`opl3` | `.wopl`、`.opli`、`.woplx`、`.sbi`、Furnace `.fui` |
| `opll`、`vrc7` | Furnace `.fui`カスタムパッチと固定ROM選択 |
| `sega`、`gb-pulse`、`gb-noise` | Furnace `.fui`、DefleMask `.dmp` |
| `sid` | GoatTracker 2 `.ins` (GTI5)、Furnace `.fui` |

バンクは互換の音色を開きます。未対応ファイルや機能は理由を報告。混合バンク内の非対応音色は除外されるが、元番号は保持。ロードはトランザクショナルで、拒否されたプリセットは現在の楽器を変更しません。ソースプリセットはトラッカーテーブルを空に置き換え、DX7 SysExのみ既存テーブルを保持。CNIは保存済みテーブルを復元。ロード済みパッチは曲が所有し、元パックの移動や削除後も機能します。

WOPLバンクは明示的な空白フラグなしに未使用スロットを含む場合があります。ブラウザーは名前なしスロットで、アクティブオペレーターが完全に減衰しアタックのないものを除外。名前なしで再生可能な音色はソースのゼロベースプログラム・バンク番号を使い`Program N [Bbank]`または`Drum N [Bbank]`として残存。無名の単一OPLI楽器はファイル名を使用。命名され無音のパッチは保持。

Furnace、DefleMask、GoatTrackerファイルは曲ではなく楽器としてインポート。アニメーション付きソースマクロ、サンプル、曲固有の再生設定は転送されないこともあり。Game BoyファイルはPulseまたはNoiseの所定フォルダーに入れる。

USERプリセットの循環はファイル、フォルダー、バンク、ZIPパック間を両方向にぬけなく続き、端でループ。USERブラウザー再起動時は現在選択を保持。ALLはカテゴリ付きエンジンのUnsortedにあるUSER音色を含むが、USERは別のトップレベル選択のまま。セガPSGとゲームボーイは階層的USERブラウザーでフラットなALL/Factoryリストを持ち、Unsortedパネルはなし。古いDX7ファイルは`instruments/banks/dx7/`にありUSERでアクセス可能。

エンジンは互換の付属コレクションのみを表示。Factoryプリセットは選択エンジンのOPLL/VRC7トーンセットをまとめ、DX7はChooChooとYSEオリジナルを統合。ダウンロードした名前付きコレクションは別表示。Fat Man 2-opはOPL2、Fat Man 4-opはOPL3の下にリスト。互換OPL2のCNIはOPL3 USERフォルダーでも使用可。

#### ネイティブチップコントロール

ネイティブ楽器の波形プレビューはコントロール刷新時に再描画。FM楽器はオプションのAmp envカーブをオーバーレイ可能。SIDはFM専用オーバーレイなしで波形プレビューを保持、バンク・プリセットの参照時も同様。

7つのFMエンジン全てが**Bright**、**Feedback**、**Amp env**を提供。Brightは-63〜+63で、0はパッチを保持し、キャリアレベルを維持しつつ変調オペレーターのレベルを調整。音響効果はアルゴリズムに依存。Feedbackは初期値が**Preset**で、ネイティブのフィードバックを0〜7で上書き可能。これらのコントロールは保存されるネイティブオペレーターバイトを書き換えません。Amp envはデフォルトで**Bypass**です。**ADSR**を選択すると、ネイティブサウンドに対してアタック、ディケイ、サスティン、リリースおよび形状を追加します。A/D/Rは共通の0–5秒の2乗曲線レンジを使用し、サスティンは無音から最大レベルまで変化します。ネイティブのエンベロープは依然として動作するため、このエンベロープでサウンドのリリース時間をネイティブ以上に延長することはできません。プリセットのブラウジングでは、スロットのFMアンプおよびトーンコントロールが維持されます。

以下のフレーズFXはモジュレーションおよびモーション録音の対応先としても利用可能です。FX列の値は16進数です。設定は保存済みインストゥルメントを変更せずに再生時に適用されます。ネイティブのGBスイープとエンベロープコントロールは次のノートトリガーでラッチし、デューティ／幅およびノイズ周波数はリアルタイムで変更可能です。

#### SIDインストゥルメントとPhrase FX

**CHIP → SID**を選択します。Bankでは**ChooChoo SID Originals**と**SIDkit Effects**が利用可能です。他のネイティブチッププリセット同様にブラウズ、オーディション、保存が可能です。

インストゥルメントページでは波形／パルス幅、フィルターモード／カットオフ／レゾナンス、ネイティブADSRコントロールを表示します。プリセット名横の**EDIT**で**SID EDIT**を開けます。WaveとPWは別のラベルがあり、Filterはモード行、続いてCutoffとReso、ADSRのラベルは値の横に表示されます。各フィールドをタッチすると正確にそのコントロールを選択します。既存のパラメーター範囲や微調整・粗調整の挙動は保持されます。

SID EDITはFMエディターのコンパクト行、テーマカラー、16進数値、EDIT＋方向キーコントロールを使います。OPTまたはLeft+Shiftで戻り、EDIT+PLAYでインストゥルメントをオーディション。ページは既存の保存済みパッチを直接編集するため、変更はインストゥルメントとプロジェクトに保存されます。

#### SIDおよびネイティブチップファクトリー/USERプリセット

ネイティブチップインストゥルメントは**Bank:**でALL、付属コレクションまたはUSERを選択可能。**Preset:**でその中のサウンドを選択します。EDITをホールドし左右キーでサイクル、短いEDITタップで選択画面を開きます。

付属コレクションは`instruments/FACTORY/`内のZIPパック。USERファイルは`instruments/USER/<engine>/`内に配置：`dx7`、`opll`、`vrc7`、`opl2`、`opl3`、`genesis`、`arcade`、`sid`、`sega`、`gb-pulse`、`gb-noise`。直接フォルダをブラウズするか、これらのフォルダと互換性のある`.cni`プリセットをZIPで入れても可。DX7は対応する`.syx`単一ボイスや32ボイスバンクをZIP内でも読み込み可能。ZIPはディスク上で保持されます。直接WOPL/WOPLX読み込みは非対応。互換CNIプリセットを使うか、対応する形式にオフラインで変換してください。

USERプリセットのサイクリングはファイル、フォルダ、バンク、ZIPパック全体で双方向に続き、端でループします。USERブラウザーを再度開くと現在の選択に従います。ALLは無分類のUSERサウンドを含み、カテゴリ別エンジンを表示。USERは独立したトップレベル選択肢です。Sega PSGとGame BoyはフラットなALL/Factoryリストと階層的なUSERブラウザーを使用し、無分類パネルはありません。古いDX7ファイルは`instruments/banks/dx7/`でUSER内に残っています。

各エンジンは対応する付属コレクションのみ表示。Factory Presetsは選択されたエンジンのOPLL/VRC7トーンセットをまとめ、DX7はChooChooとYSEオリジナルをまとめます。DLした名前付きコレクションは分離。Fat Man 2-opはOPL2、Fat Man 4-opはOPL3に表示。互換OPL2 CNIファイルはOPL3 USERフォルダーでも使用可能。

## 6. モジュレーションとモーション録音

各インストゥルメントは最大4つのモジュレーションスロットを持てます。オーディオインストゥルメントは**Instrument Pan**か**Track Pan**を対象にでき、いずれも`00`が左、`80`が中央、`FF`が右です。

利用可能なモジュレーションタイプ：

- ADSR：古典的なアタック・ディケイ・サスティン・リリースエンベロープ
- AHD：アタック・ホールド・ディケイエンベロープ
- LFO：いくつかの波形を持つ低周波オシレーター
- syncLFO（旧SLFO）：1単位あたりのティック設定と周期乗数を持つLFO
- slowLFO：通常のLFO範囲のすぐ先から始まる、比例的な周期コントロールを持つ長周期LFO
- FLFO：kHz帯に達するオーディオレートLFO。CPU負荷が高い
- SLIN：線形ジョイスティックコントロール
- SRAT：速度ベースのジョイスティックコントロール
- Sequence：トラッカーのシーケンスをモジュレーション信号として読み取ります。**PITCH** は最終的にシーケンスされたピッチ、**VOL** は最終的にシーケンスされたボリューム、**TRANCE GATE** は独立したリズミックモジュレーターです。Motif、Rate、Length がゲートパターンを選び、Trigger はフリーラン、ノートごとの再トリガー、フレーズまたはチェーン境界でのリセットを選びます。閉じたゲートはゼロ、開いたゲートは半分のレベルで、Accents は有効なゲートの中にユークリッド分配でフルレベルのゲートを配置します。トラックのインサートは使用も変更もしません。

モジュレーションの出力先はインストゥルメント種類によって異なります。

ADSRまたはAHDエンベロープがボリュームを対象にすると、そのインストゥルメントのボリュームエンベロープになります。LFOがボリュームを対象にすると現在の出力ボリュームをオフセットします。

モジュレーション量は正または負の値になり得ます。範囲は対象に依存します。多くのパラメーターのように対象のフルレンジが127以下の場合、量は絶対レンジを定義。ピッチなどレンジの広い対象はスケーリングされた量が使われます。

Sequence の PITCH と VOL ソースには **Mode** があります。**Normal** はトラッカーの値を聞こえる状態に保ちつつ、モジュレーションにも使います。**Bypass** はソース専用にします：PITCH は最後のピッチ（最初のノートでは C-4）で再トリガーし、VOL は最後に聞こえたレベルを保持します。Trance Gate は元からソース専用です。アクティブな Sequence スロットのいずれかが PITCH または VOL を bypass にした場合、bypass が優先されます。フィードバックを避けるため、PITCH と VOL は Pitch や Volume を対象にできません。

すべての持続時間パラメータ（アタック、ホールド、ディケイ、周期を含む）はティック単位です。

**syncLFO** は旧SLFOです。ティックと乗数を設定して、テンポ同期した動きを作ります。既存のSLFO設定と曲は同じタイミングを保ちます。

通常のLFOより長いスイープには **slowLFO** を使います。Period コントロールは 256〜131,072 ティックです。ティックベースのLFOはすべて曲のテンポに従い、同じ波形、ウェーブテーブル選択、トリガーモードを共有します。ノートをまたいで続くスイープには Free を、Retrig、Phrase、Chain はそれぞれの境界で再起動します。

LFO 波形：

- Tri - 双極三角波
- Sin - 双極正弦波
- UniTri - 単極三角波
- UniSin - 単極正弦波
- RampDn - 線形ランプダウン（鋸波）
- RampUp - 線形ランプアップ（鋸波）
- ExpDn - 指数ランプダウン（指数的鋸波）
- ExpUp - 指数ランプアップ（指数的鋸波）
- Square - 方形波
- Random - サンプルアンドホールドのランダム波
- Wavetable - プロジェクトの32ステップAYウェーブテーブルのいずれかを読む。値は`00`から`0F`まで、`-100%`から`+100%`に補間なしでマッピング。

LFOトリガータイプ：

- Free - インストゥルメント変更時のみLFO再起動
- Retrig - 各ノートでLFO再起動
- Phrase - 再生が新しいフレーズに入るとLFO、syncLFO、slowLFOを再起動
- Chain - 再生が新しいチェインに入るとLFO、syncLFO、slowLFOを再起動
- Hold - 1周期後に停止し最後の値を保持
- Once - 1周期後に停止しゼロに戻る

### モーション録音

- **STICK LIVE** （デフォルト`L1`）はフレーズを変えずにスティックモジュレーションを適用します。**Settings > Stick live mode**で`HOLD`（デフォルト）はボタン押下中のみ有効、`TOGGLE`は一押しで有効／次の押しで無効、`FREE`は常に有効。`TOGGLE`中にリリースしても有効のままです。
- 再生中に**MOTION RECORD**（`L2`）を押し続けるとスティックモジュレーションを適用し、変更先のFXを絶対値として録音します。
- **MOTION ERASE**（`R2`）を押し続けると現在の行の対応するFXを削除します。

右下の`~`はアクティブなStick liveを示します。Record（`*`、オーバーフロー時は`!`）、Erase（`x`）は指標優先で一時的に表示されます。両者とも押下中はライブスティック処理を有効にし、離すとライブトグルは保持されます。

モードはアプリ設定と共に保存されますが、起動時はライブトグルオフから開始。モード切り替えでトグルは消去：`HOLD`は押されているスティックライブに従い、`TOGGLE`は新しい押下を待ち、`FREE`は即時有効。

モーション録音は現在再生中のフレーズにトラックFXを書き込みます。まず対応するFXを更新し、空スロットは右から左へ埋めます。異なるFXを上書きしません。3スロットが全て埋まっているときはそのステップにモーションは録られません。右下の`!`は3つのFX列に収まりきらない変更先があったことを示します。

モーション録音はBraids、Plaits、Sampler、2xSCWF、BYOWTBL、Bogieの対応先をサポートし、適用可能ならBogieマクロやフィルターコントロールも含みます。

| Trance Gate | Pattern, Rate, Length, Gate, Phase, Mode, Smooth, Mix |
| Beads (Mutable Instruments) | Time, Size, Density, Pitch, Scatter, Feedback, Shape/Freeze, Mix |

連続コントロールは 00–FF を使用し、有効なゼロ値と最大 FF を含みます（FORMANT VOW は 00–7F）。バイポーラコントロールは正確なニュートラルが 80 にあります。ディストーションモードは 00 Density、01 Drive、02 Spiral、03 Mojo、04 Dyno です。コンプレッサーのレシオは 00–07 が 1.5、2、3、4、6、8、16、20:1、Compressor Detect 00–02 は自身のステレオ入力、左、右を監視し、03–0A は代わりにトラック1–8を監視します。ディテクターフィルター 80 がニュートラルで、それ以下はローパス、以上はハイパスです。トラックソースはそのボリューム、パン、Tilt EQ の後、インサートの前で取得され、ミュートまたは存在しないソースは無音になります。任意のスロットに任意のモジュールを入れられ、重複したモジュールは独立しています。

Chorus と Phaser は可聴ながらコントロールされたモジュレーションから始まります。Mix、Depth、Feedback を減らすとほぼ透明な効果です。Depth、Feedback、Mix を高く設定すると意図的に極端な効果になります。Flanger と Rotary は穏やかなモジュレーションのデフォルト設定です。Rotary Speed は全範囲 **00-FF** を使用し、**00 = 0.01 Hz**（100秒で1回転）、**FF = 25 Hz**（旧 Chaos の最大）です。指数関数的な間隔で、遅いLFO動作の調整が細かくなっています。新しく挿入された Rotary のデフォルトは **8F**（約0.8 Hz）で、4つの離散速度値に代わります。既存の Rotary 設定および F11/F21 の速度オートメーションは新しいスケールに合わせて調整が必要です（旧・Slow/Fast/Hyper/Chaos は概ね **8F/CB/E7/FF** に相当）。他のパラメータは変更ありません。

Bitcrusher のビット深度は4～16ビット、レートリダクションは1倍～32倍です。Destruction のモードは Fold、Clip、Crush です。Saturation と Distortion は未処理信号とのバランスを取るための出力レベルまたはミックスコントロールを備えています。

Trance Gate はパッド、リード、スタブ用のテンポ同期アンプリチュードシーケンサーです。パターン値 00–3F は名前付きの音楽的モチーフを選択し、00–1F は基本的なグルーヴ、20–3F は実験的なバリエーションです。レートは 1/2 から 1/32 までのストレート、トリプレット、ドット付きの値を持ちます。レングスは独立回転する16ステップのモチーフを1～16ステップに短縮します。各トラックのノートオンでシーケンスを再開し、ノートオフはリリースを通じて継続します。Forward、Reverse、Ping-Pong が再生方向を定義し、Chaos は4ループごとに密度を保った変異を繰り返します。マスターインサートではノートリトリガーせずトランスポート時間を追従します。Gate は開いたステップの幅、Smooth は端を丸めクリック音を抑え、Mix はドライとゲート処理済み音声のクロスフェードをします。

**Beads** は Mutable Instruments のオリジナルグラニュラーDSPをステレオインサートとして使用します。トラックのインサートスロットで Beads を選択します。8つのコントロールは既存の F11–F18 / F21–F28 コマンドとインサート MOD 宛先を利用し、新たな FX ID やプロジェクトフォーマットは不要です。グレインは追加イベントなしに連続再生されます。

- **Time:** 4秒録音バッファ内の位置
- **Size:** 00 で長い逆再生グレイン、約55付近で最短グレイン、その後順に長い正再生グレイン。FF は変移後に元のディレイモードに入ります。
- **Density:** センター以下は規則的なグレイン、以上はランダムタイミング。センターのデッドゾーンは新規グレインを停止。中心から離れるほどレートが上昇します。
- **Pitch:** −24～+24セミトーン。80 は正確なユニゾン。
- **Scatter:** 00 はパラメーターのランダムネスなし。増やすと Beads 内部の均一な Time ランダムネスを全量、Size ランダムネスを半量かつグレインごとに独立して適用。Pitch と Shape は設定値のまま維持されます。
- **Feedback:** 処理済みグレインを録音パスに戻します。
- **Shape/Freeze:** 00–7F は録音、80–FF はフリーズ。どちらの範囲内でも下位7ビットは矩形からディケイ、ベル、逆音まで同じエンベロープをスイープ。80 を加減算でフリーズを切り替え（Shapeは変わらず）。40 と C0 は同じエンベロープ。値のヒントはエンベロープの位置と録音／フリーズ状態を示します。EDIT を押しながら上下で16進数10（16）ずつ、左右で1ずつ変更可能。このパックドコントロールは離散値なのでスルーでフリーズビットを跨ぎませんが、バイト丸ごとのモジュレーションで意図的に2状態を行き来可能です。
- **Mix:** 00 は完全ドライ、FF は完全処理済み。変化はスムーズです。

フリーズは現在エフェクトでキャプチャされているオーディオを保持します。別のモジュール選択や Beads リセットで解除されます。トラックのリバーブセンドは利用可能です。

### キックでミックスや他のトラックをポンピングさせる

ポンピングするマスターにするには、キックをトラック1に置き、MASTER FX で Compressor を選び、Detect を 03（Track 1）、Ratio を 04（6:1）、Attack を 60 付近（約1.6 ms）、Release を C0 付近（約115 ms）、Makeup を 00、Mix を FF にします。キックのたびに他の音が沈むまで Threshold を下げ、次のキックの前に戻るよう Release を調整します。キックの直接音は自身のトラックインサートを保ちますが、2つのマスターインサートスロットはバイパスします。リバーブとディレイの返しはそれでもポンピングします。

ベース、パッド、シンセだけを下げたい場合は、そのトラックに Compressor を置き、Detect でキックのトラックを選びます。元のキックは聞こえたままで、そのトラックのコンプレッサーによってボリュームが変わることはありません。同じトラックに合成されたキックとベースは、このルーティングでは分離できません。

### FORMANT

TF1 または TF2 で **FORMANT** を選ぶと、音を母音のような音色に整形できます。鋸波のような、持続する倍音豊かなソースで最も効果的です。

MODE を `00` VOW にして、**VOW** で A（`00`）から E、I、O を経て U（`7F`）までスイープします。MODE を `01` CUSTOM にすると **F1** と **F2** を自分で調整できます。**RES** は母音の性格を狭めたり広げたりし、**MIX** は効果を元の信号と混ぜます。MOD → INSERT FX でアクティブなコントロールを動かせます。MODE は MOD の対象ではありません。

### インサート用レーンFX

インサートコマンドは **F11–F18** が TF1、**F21–F28** が TF2 です。ロールの FX 選択と Phrase/Table ポップアップは選択したトラックの設定済みインサートで使われるパラメーターだけを表示します。ポップアップは **TF1: エフェクト名** と **TF2: エフェクト名** にグループ化され、OFF のスロットは非表示です。バイパス中のインサートも編集可能です。Phrase と Table の FX ポップアップは選択したトラックのインサートスロットに従い、モジュール、パラメーター名、デコード後の範囲端点、保存済みの基本値を表示。モジュール変更で使われなくなった既存のソングコマンドは保持され、ピッカーを開くと利用可能なコントロールから始まります。

値を編集中、下部のヒントはデコードされた値と単位を表示します。どの Phrase または Table FX カラムもどちらかのスロットを指定可能で、Phrase グリッドは3カラムを維持。これらの絶対ランタイム値はノート、インストゥルメント、フレーズ、チェイン、通常ループ間で持続します。新規再生やハードストップでリセット。F ページで基本値を編集するとそのパラメーターのオーバーライドのみ解除。MOD は基本値／オートメーションの実効値に作用し、オフセットは保存しません。新モジュール選択はデフォルトを読み込み、スロットのオーバーライドをクリア。バイパスは短いフェード後に処理を停止し、既存のオートメーションは保持します。

**アドレスはトラックスロット／パラメータ位置を指し、名前付きエフェクトではありません。** 他トラックでの再利用 Phrase はそのトラックのモジュールを使用。モジュール変更はコマンドの意味に影響しますが、書き換えはされません。OFF／未使用アドレスは安全な無操作で、保存された Phrase/Table データに残ります。

インストゥルメント MOD チューザーに Insert FX カテゴリ追加。各インストゥルメントのソースは、そのインストゥルメントが鳴っているトラックの挿入に作用（コードシグナル含む）。同じインストゥルメントが2トラックにあっても独立チェインに影響。既存のソースタイミング、有効値（符号付き）、ソース組み合わせルール、スティックモード、モーション記録が適用。離散コントロールは量子化され有効範囲に制限。新たなトラック所有のモジュレーションバンクはありません。

最初は数個のインサートから始め、オーバーロードやノイズに注意し、曲に不要なエフェクトはバイパスしてください。ドライブやゲイン設定はミックスをクリップさせることがあるので、Mixer のクリップインジケーターを確認しながら調整しましょう。


## 8. テーブル

テーブルはトラッカーのコアなサウンドデザインツールです。Vortex Tracker ではインストゥルメントとオーナメントを組み合わせたものですが、もっと多用途に使えます。LSDj や NerdSEQ を知っていればイメージしやすいでしょう。

Pitch カラムは相対値（`~`）または絶対値（`=`）のセミトーンを受け入れます。Volume カラムは `00`-`0F` で、各エンジンのエンベロープ上に適用され、ゲートとしても使えます：`0F` と `00` を交互に置いて `HOP 00` でループさせるなど。4つの FX レーンは主にフレーズのレーンに準じますが、一部 FX はテーブルで動作が異なります。

テーブルの最終行に `TIC` FX を置くと、そのカラムの速度が設定され、インストゥルメントのデフォルトテーブル速度を上書きします。各 FX カラムは異なるティック速度で動作可能。Pitch と Volume は1番目の FX カラムの速度に従います。

16行テーブルは長大な Vortex Tracker インストゥルメントに比べると短く見えますが、`HOP` FX による条件付きループ（「これらの行を5回繰り返す」など）や入れ子ループにより、16行でも十分な長さを実現します。

Phrase と Table 間でレーン FX のコピー／ペーストも可能です ;)

### リトリガーモード

テーブル画面上部の `Retrig` フィールドで、既にアクティブなテーブルの再スタート条件を選べます。`Inst` はデフォルトの互換モードで、インストゥルメントを含むフレーズ行がそのインストゥルメントのデフォルトテーブルを選択し、行 `00` から開始します。`Phrase` はフレーズ再生開始時にテーブルを再スタート、`Chain` はチェイン開始時、`Free` はトラック停止または明示的コマンドで置き換わるまで継続します。

構造的モードは時間を遡りません。トラックにアクティブなインストゥルメントテーブルがなければ、最初にインストゥルメントが出現したフレーズ行で正確にその行からテーブルが有効化されます（`4`、`8`、`F` などの行でも同様）。後のインストゥルメント番号はアクティブな `Phrase`、`Chain`、`Free` テーブルを置き換えません。これにより、フレーズの以前のステップを無音でシミュレートせずに、LFOのようなオートメーションとしてテーブルが使えます。

`TBL`、`TBX`、`RET` は常に即時アクション：モードに関わらず即選択／再スタートします。Phrase または Chain の境界上では、新行読み込み前に再スタートが行われ、該当行の `TBL` や `TBX` が最終決定権を持ちます。テーブルの行 `00` FX は通常通り再生され、累積 FX は通常通り蓄積されます。

テーブル `00-7F` はデフォルトインストゥルメントテーブル用に予約。`80-FE` は `TBX` 効果で起動する補助テーブル用の想定です。下位範囲も補助用に使えますが、予期せぬ競合や混乱の原因になります。

### 操作方法

- **EDIT + [UP/DOWN]**: FX 名前カラムで FX 選択画面を開く
- **OPT + [方向キー]**: テーブル間を移動

## 9. インストゥルメントプールと AY ウェーブテーブル

### インストゥルメントプール

プロジェクト内の全インストゥルメントを一覧表示し、並べ替え可能。再生中は現在アクティブなインストゥルメントも表示されます。

#### 操作

- **EDIT**: インストゥルメント編集画面へ移動
- **SHIFT + OPT**: インストゥルメントをコピー
- **SHIFT + EDIT**: インストゥルメントをペースト
- **EDIT + [UP/DOWN]**: インストゥルメント順序を変更
- **EDIT + PLAY**: インストゥルメントをプレビュー

### AY ウェーブテーブル

Wavetable は AY Plus ソフトウェアOSCタイプ。プロジェクトは最大256個のウェーブテーブルを含み、各テーブルは32ステップ。すべてのウェーブテーブルインストゥルメントは同一セットの波形を共有します。この画面で編集します。

AY ボリュームレベルは非線形なため、Standard ビューの波形は実際の出力レベルに合わせて描画されます。**OPT** をダブルタップすると、Standard ビューと記憶されている **LFO ビュー** を切り替えられます（Song/Live Mode と同じショートカット）。LFO ビューは原始 `0`–`15` ステップを線形に描画し、中心線は `7` と `8` の間でモジュレーションのゼロ点になります。

画面は論理的に2行に分かれます。上段に **Load** と **Save** ボタン、2行目にウェーブテーブルエディターがあります。

#### 操作

- **OPT + [LEFT/RIGHT]**: ウェーブテーブルリストを横移動
- **OPT + [UP/DOWN]**: 16波ずつリスト移動
- **SHIFT + OPT**: ウェーブテーブルをコピー
- **SHIFT + EDIT**: ウェーブテーブルをペースト
- **OPT + PLAY**: Standard ビューと LFO ビューを切り替え

#### 条件

スウェーデンの"trig conditions"に触発され、トリガー確率とモジュロ条件をサポート。

| FX | 値 | 意味 |
|---|---|---|
| `PRO` | `00-64` | `0%`から`100%`までの絶対トリガー確率 |
| `MOD` | `AB` | `B`回目のうち`A`回目でトリガー；例：`12`, `22`, `14`, `34` |

`MOD`カウンターはトラックとフレーズ単位でローカル。`A > B`のような無効組み合わせはトリガーされない。

`MOD34`は4サイクルの3回目でトリガー。`MOD1F`は16サイクルの1回目でトリガー。

#### 再生速度

NerdSEQ同様、ChooChooTrackerはトラックごとに独立した再生速度を持つ。

`SPD`は符号付きバイトとして読み取る。`00`が標準速度、正値は速く、負値は遅くなる。設定は別の`SPD`が来るまで有効。

| 値 | 速度 |
|---|---:|
| `00` | `x1` |
| `01` | `x2` |
| `02` | `x3` |
| `7F` | `x128` |
| `FF` | `/2` |
| `FE` | `/3` |
| `80` | `/129` |

古いプロジェクトは符号付き`SPD`対応前の`00-10`マッピングを保持し、そのまま再生。

非常に高倍率はトラッカーのティックスケジューラーの分解能を超える可能性があり、ハードウェアでのテストはされていない。

### スケール & コードFX

#### スケール自動化

`SCL XY`はフレーズ内のノートを変更せず、グローバルな再生スケールとルートを変更。`X`はスケール選択（`0`クロマティック、`1`メジャー、`2`マイナー、`C`カスタムまで）；`Y`はルート選択（`0`Cから`B`Bまで）。このコマンドはフレーズFXにのみ適用され、テーブルには適用されない。同じティックで複数トラックが`SCL`を発行した場合は、番号が最も小さいトラックが優先。

`SCL`はクオンタイザーモードに属する。**Note Lock**が有効の場合、FXリストに表示されず、書き込まれた`SCL`も無視される。

#### コード

`CRD XY`はそのフレーズ行のノートをコードに変換。`Y`はコード種別選択：`0`メジャー、`1`マイナー、`2`ディミニッシュ、`3`オーグメント、`4`Sus2、`5`Sus4、`6`パワー、`7`メジャー7、`8`マイナー7、`9`ドミナント7、`A`マイナー7b5、`B`ディミニッシュ7、`C`Add9、`D`MinAdd9、`E`Maj9、`F`Min9。`X`は16種類のボイシングから選択：`0-3`は上昇するクローズドインバージョンサイクル、`4-7`はドロップ2追加、`8-B`はドロップ3追加、`C-F`は両方のドロップを組み合わせ。トライアドとパワーコードは1オクターブ余分にサイクルし、全ての値は区別可能。値が大きいほど広く、非典型的。例：`CRD 4Y`はドロップ2のルートポジション。`CRD DY`は両ドロップの第一転回形。ピッチテーブルの上下端ではボイスが範囲内に制限される。このコマンドは持続しないため、コード化する行すべてに書く必要あり。スケールが有効時は個々の生成ノートが独立してクオンタイズされる（クオンタイザーとNote Lock両対応）。ソフトウェアエンジンのみ対応。AYインストゥルメントは無視し、モノフォニックのまま。

## 11. ミキサー、リバーブ、ディレイ

ミキサーはメイン画面の最左部にあり、CPU負荷とクリッピング警告を表示します。**CLIP**列に赤い`!`があるトラックは、ドライ信号がミックスの安全範囲を超えたことを示します。

8トラックのバランス調整、各トラックのTilt EQによる音作り、リバーブやディレイへの送出に使用します。

| フィールド | 意味 |
|---|---|
| LVL | エンジン後のトラックレベル、`000-100` |
| REV | 共通リバーブへの送信量、`000-100` |
| DLY | 共通パンピングディレイへの送信量、`000-100` |
| PAN | 音声を左または右に振る |
| TLT | トラック別Tilt EQ、`00-FF`；`80`がニュートラル、低い値は低域寄り、高い値は高域寄り。低値は柔らかなオーバードライブを導入します。 |
| M | `*` が付くとこのトラックをミュート |
| S | `*` が付くとこのトラックをソロ |

ミキサーはトラックベースであり、楽器ベースではありません。トラックが楽器を変更しても、レベル、PAN、Tilt、送信設定はトラックに保持されます。楽器側にもInstrument画面の上段に`00-FF`の**Vol**と**Pan**があります。楽器PANが先に適用され、その後にトラックPANが適用されます。両方ともセンターで既存のステレオイメージを維持し、左右どちらかに振ると逆側を徐々に減衰させます。

### Auto Mix

Mixer には **AUTO MIX** ボタンがあります。`6秒` をオフラインでレンダリングし、トラックのボリュームをバランスさせ、8つのオクターブ帯域をピンクノイズのプロファイルと比較して、それらの帯域を過負荷にするトラックを穏やかに下げます。控えめなレベル変更を提案し、ピークの余裕を残し、一時的なプレビューを開始します。**Apply** は提案されたレベルを保持し、**Cancel** は以前の8つのレベルに戻します。良い出発点ですが、結果は自分で微調整したくなるでしょう。

### リバーブ

ミキサー画面から**SELECT + [UP]**でリバーブ設定画面を開きます。

- **Algorithm**：CloudsかBeadsを選択。各アルゴリズムは独自のコントロールを持ちます。
- **Return**：マスターミックス内のウェットリバーブレベル。
- **Clouds**：**Time**、**Damping**、およびリバーブ前の**LP**と**HP**フィルター。
- **Beads**：**Time**、ネイティブフィードバックフィルターの**Tone**、リバーブ前の**HP**フィルター。

これはCloudsまたはBeadsのSendリバーブ部のみで、グラニュラー処理部ではありません。

### パンピングディレイ

ミキサー画面から**SELECT + [DOWN]**でディレイ画面を開き、**SELECT + [UP]**で戻ります。リバーブは逆方向で操作します：**SELECT + [UP]**で開き、**SELECT + [DOWN]**でミキサーに戻る。

- **Return**：ウェットディレイレベル。
- **To Reverb**：ウェットディレイ信号を共通リバーブに送る量、`0-100%`。
- **Ticks**：トラッカーのティック単位のディレイ時間（デフォルト`9 ticks`＝`1 beat`）。
- **Feedback**：クロスフィードバック量、最大`95%`。
- **Filter**：ディレイ信号経路のローパスフィルター。

1回目のリピートはステレオ入力に従い、以降のフィードバックは左右チャンネル間をクロスします。

## 12. プロジェクト画面

プロジェクト画面は**Load**、**Save**、**New**、**Export**、**Manage**、**Scale**コマンドと、ファイル名、タイトル、作者メタデータを提供します。

### エクスポート場所

エクスポート、ステム、バウンスはアプリの既存サンプルディレクトリ内のプロジェクトフォルダーに書き込まれます：

- **デフォルト**：`<app folder>/samples/Exports/<project name>/`。プロジェクトが未命名の場合は`current-project`フォルダー。
- Web版ではデフォルトは`/user/samples/Exports/<project name>/`。
- Androidではサンプルフォルダーはアプリのワークスペース内：Playストアビルドではアプリ専用のプライベートフォルダー、直接APKビルドでは選択したフォルダー内の`samples`。

**EXPORT**画面の**Folder**行は現在の出力先を表示します：

- **EDIT**をタップしてフォルダーブラウザーでカスタムフォルダーを選択。選んだフォルダーはそのまま使われ（プロジェクトのサブフォルダーは追加されない）、設定に記憶されます。
- **EDIT + OPT**（クリア）でデフォルトの場所にリセット。

名前付きプロジェクトを新しい名前で保存すると、デフォルトエクスポートフォルダーも名前が変更され、以前のエクスポート済みファイルは保持されます。カスタムフォルダーには名前変更が適用されず、オートセーブでもフォルダー名は変わりません。ターゲット名のフォルダーがすでに存在する場合、両方のフォルダーが残ります。トラッカーがフォルダーの所在を見失った場合（例：再起動後）、名前付きプロジェクトの保存時に既存の`current-project`フォルダーが名前変更されます。インストゥルメントは名前変更後も動作を継続し、リネームされたフォルダーを指すロード済みサンプルパスは自動更新されます。

**Load**は`.mid`/`.midi`ファイルを受け付け、新規プロジェクトとしてインポートします：ノートはMIDIチャンネルごとにグループ化され（トラック数分まで）、4行／ビートにクオンタイズされ、デフォルトのAY楽器に配置されます。MIDIプログラム番号はチップチューンに対応しないため、あとで実際の楽器を選んでください。ファイルの最初のテンポのみが使われます（グローバルなティックレートのみで、セクションごとのテンポ変更は不可）。**Export**画面の**MIDI**行は逆に現在のアレンジのノート、ボリューム、テンポ/グルーブをスタンダードMIDIファイルとして書き出します（トラッカートラックごとに1MIDIトラック）。[MIDI Out](#midi-out)楽器や音量やグローブ以外の行単位FXにはMIDIでの対応がなく変換されません。

**Load**はDirtywave M8ソング（`.m8s`、ファームウェア2.x〜4.x）を受け付け、新規プロジェクトとしてインポートします。構造とノートのみが引き継がれます（ソング行、トランスポーズ付きチェーン、ノート・ベロシティ・楽器番号付きフレーズ、ノートオフ、テンポ、ソング名）。ノートは実際のピッチを維持します（M8はオクターブ表記が2つ高い：M8の`C-6`は本アプリの`C-4`）。フレーズで使われる各インストゥルメントはM8の楽器名のままインポートされます。M8の**MACROSYN**楽器はBraids楽器に変換され（47の波形はBraidsモデル番号と対応、音色、カラー、フィルタータイプ、カットオフ、レゾナンス、PANも引き継ぎ、カットオフカーブは近似）、**SAMPLER**楽器はSample楽器に変換されます：`.m8s`はM8カード上のWAVパスのみを記録しているため、`.m8s`フォルダーと親フォルダー（カード配置のコピーでも可）、現在のサンプルフォルダー（`Samples`または`samples`）を順に検索し、見つからなければM8パスのまま無音に。読み込まれたサンプルはPitch設定に+24半音が加えられます（M8は本アプリより2オクターブ低い元ピッチで再生）。**FMSYNTH**はGenesis FM楽器（大まかな近似）、**WAVSYNTH**と**HYPERSYNTH**はaChChidに変換、**MIDI OUT**はMIDI Out楽器（チャンネル、バンク、プログラム、最初の4つのCC番号）。その他（外部）のタイプはデフォルトのAY楽器となり、あとで実音を選んでください。FXとテーブルは無視されます。

**Load**はLittle Sound Djソング（`.lsdsng`、ファイルごとに1曲）を受け付け、新規プロジェクトとしてインポートします。全LSDjセーブファイル（`.sav`、最大32曲）を選ぶと曲リスト（スロット、名前、バージョン、サイズ）を表示。1曲選びインポートします（セーブ時に編集中だった曲はリストにありません）。構造とノートのみが引き継がれます（ソング行、トランスポーズ付きチェーン、ノート・楽器番号付きフレーズ、テンポ、ソング名）。LSDjはノートボリュームがないため全て最大ボリュームになります。4つのLSDjチャンネルPU1, PU2, WAV, NOIはそれぞれトラック1-4になります。パルス楽器はGB Pulse（デューティ、エンベロープ、パンを引き継ぐ。パルススイープは非対応）、ノイズ楽器はGB Noise（エンベロープ、安定度、パン）、ウェーブ楽器はGB Pulse Hollow Leadプリセット、キットはデフォルトGB Noise。グルーブもインポートされ、フレーズコマンド`C`（コード）、`D`（ディレイ）、`E`（パルス・ノイズエンベロープ、ウェーブチャンネル除く）、`G`（グルーブ）、`K`（キル）、`V`（ビブラート）はそれぞれ`ARP`、`DEL`、`CEI`/`CEP`/`CED`、`GGR`、`KIL`、`PVB`に変換。その他のコマンド（`A`, `F`, `H`, `L`, `M`, `O`, `P`, `R`, `S`, `T`, `W`, `Z`）、テーブル、ウェーブフレーム、キットサンプル、シンセ設定は無視。依存曲は音が変わることがあります。テンポは6ティックグルーブ向けに変換されます。

デスクトップとAndroidでは、**Export**画面の**LSDJ**行は逆方向の限定的な変換を提供：タップして既存の`.lsdsng`を**テンプレート**として選ぶ（終了まで記憶、**EDIT + OPT**で解除）。曲行、チェーン、フレーズ、テンポ、タイトルを置換し、それ以外（テーブル、グルーブ、ウェーブ、キット、シンセ設定）はそのまま。トラック1-4はPU1、PU2、WAV、NOIに。GB PulseとGB Noise楽器はLSDjのパルス、ノイズ楽器として書き戻され、それ以外はデフォルトパルス楽器。FX、ノートボリューム、ノートオフはエクスポートされず、チェーン`80`以上やフレーズ`FF`以上を使っている曲はエクスポート不可（LSDjはチェーン128個、フレーズ255個制限）。エクスポートしたファイルはLSDj本体での動作確認済みでありません。

デスクトップでは**Export**画面の**M8S**行も逆方向の限定的な変換を提供：タップして既存の`.m8s`を**テンプレート**として選択（終了まで記憶、**EDIT + OPT**で解除）。ソング、チェーン、フレーズ、テンポ、タイトルが置換され、それ以外はそのまま。Braids楽器はMacroSynth、Sampler楽器はSamplerとして書き戻される（パスは`/Samples/<ファイル名>`：WAVは自身でM8にコピーしてください）。テンプレートに対象の楽器が存在しない場合、そのパラメーターのコピーはなし。FXはエクスポートされず、フレーズ`FF`以上を使う曲はエクスポート不可（M8は255フレーズ制限）。エクスポートしたファイルはリアルM8での動作確認済みではありません。詳細は[M8 songs](m8s-format.md)参照。

デスクトップではkey jazzで、画面上の仮想キーボードを使わずにファイル名、タイトル、作者名を直接タイピング可能です — [Key jazz](#key-jazz-desktop-only)参照。

### Scale / Quantize

Scale画面はグローバルな12平均律スケールエンジンを制御します。**Mode**行で2つのモードを切り替えます：

- **Quantizer**（デフォルト）：フレーズ入力はクロマチックのままです。有効にすると、ノートはサウンドエンジンに届く直前に下方向へ丸められます。これにより、ルートやスケールを変えてもフレーズ編集なしに曲のリアレンジが可能です。
- **Note Lock**：フレーズに入力されたノートは、入力時にスケールの最も近いノートにスナップされるため、スケールノートだけが書き込めます。新規入力や音の下げは下方向へスナップし、`EDIT + RIGHT` / `EDIT + UP`で次のスケールノートへ上げられます。この画面での入力は常にプロジェクトのスケールに従います。ルートやスケールの変更は有効トラックの新規入力に即反映され、既に保存されたノートは変更されません。`SCL` FXはこのモードで使用できず、既存の`SCL`も無視されます。プレーンノートの再生時クオンタイズは無効（入力時にロック済み）ですが、`CRD`によるコードクオンタイズは有効です。

- **Clock source** は **Internal**（プロジェクト自身のテンポ）、**Midi Clock**（シーケンサーが入力MIDIクロックに追従）、**Ableton Link**（シーケンサーがローカルネットワーク上のLinkセッションのテンポに追従）から選びます。**Midi Clock** のとき **Tempo** 行は暗くなり、入力クロックの計測テンポを表示します。トランスポート（play/stop）は送信側の Start/Continue/Stop メッセージで制御されるため、アプリの PLAY は不要です。**Ableton Link** のときは行が **Link** 行になり、テンポ欄の代わりにセッションへの接続/切断スイッチが入ります（下記参照）。クロックソースは settings.txt に保存され、すべてのプロジェクトに適用されます。
- **Tempo** はプロジェクトのテンポを整数BPM（`3-500`）で設定します。内部的にはトラッカーは tick rate を Hz で保存し続けるので（`tick rate = BPM x 0.4`）、既存のプロジェクトは変更なく読み書きできます。小数テンポのプロジェクトは丸めて表示され、最初のテンポ編集で整数BPMにスナップします。粗調整は5 BPM刻み、微調整は1 BPM刻みで、クリアするとデフォルトの125 BPMに戻ります。

ChooChooTrackerはプロジェクトを`.cct`形式で保存します。これは人間にも読みやすい独自形式です。

楽器タイプを変更したり別のプロジェクトを開く前に、**Save**を使ってください。

### Ableton Link

Ableton Link を使うと、ChooChooTracker は同じローカルネットワーク（Wi-Fi または Ethernet）上の Link 対応アプリ（Ableton Live、LinkHut など）のテンポに追従できます。受信専用で、トラッカーは自身のテンポをセッションに合わせ、他の参加者にテンポやトランスポートを送ることはありません。

**同期されるもの：**

- セッションテンポ - トラッカーは Link セッションのテンポに継続的に追従します（トラッカーの 3-500 BPM の範囲内）。
- ビート位相 - PLAY を押すと再生がセッションのビートグリッドに揃います：曲は次の小節（4拍クォンタム）から始まります。

**同期されないもの：**

Link での再生中、ChooChooTracker は4/4の1小節ごとに共有ビート位相を確認し、必要に応じて自身の tick rate を穏やかに調整します。これによりトラッカーのティックを飛ばしたり繰り返したりせずにデバイス間の小さなクロック差を補正し、他の参加者の Link セッションを変更することはありません。

- グルーヴと `SPD`、`DELAY` の値は影響を受けません - 追従したテンポに対して相対のままです。
- song/chain/phrase のカーソル位置とミキサー設定は共有されません。

**使い方：**

1. Project 画面を開き、**Clock source** を **Ableton Link** にします。下の行が **Link** 行になります。
2. **[Connect]** で EDIT を押してセッションに参加します。右のステータスメッセージが進行状況を示します：接続中は `Wait...`、ネットワークがなければ `No net`、セッションが見つからなければ `No sess`、内部エラーなら `Err`。接続中はボタンが **[Disconnect]** になり、ステータスは約1秒ごとに `connected` と `Peers: N`（N = ピア数）を交互に表示します。
3. `connected` を待って PLAY を押すと、再生はセッションの次の小節に揃って始まります。
4. セッションから抜けるには **[Disconnect]** で EDIT を押します（またはクロックソースを Internal に戻します）。

Link モードではセッションがテンポを管理します：行には BPM 欄がなく、セッションのテンポが自動的にプロジェクトに適用されます（トラッカーの 3-500 BPM の範囲内）。

**プラットフォーム対応：** PortMaster（主対象）、Windows、Linux、macOS、Android に対応しています。Web 版と Miyoo 版には Link は含まれません。

**PortMaster の注意：** PortMaster デバイスではオーディオバッファが大きい（48 kHz で512フレーム）ため、ビートの整列は約10-15 ms 以内の近似で、サンプル単位の正確さではありません。テンポ同期自体には影響しません。

## 13. Settings

Settingsはアプリ全体に適用される設定用で、現在のプロジェクトには依存しません。テンポ、グルーブ、ミキサーレベルなどプロジェクト全体の制御はそれぞれ別画面にあります。

### Controls

- **Repeat delay**と**Repeat speed**は、ナビゲーションや編集ボタンを押し続けた時の繰り返しの開始までの遅延と速度を設定します。押し続けて意図せず進みすぎる場合は遅延を長く、素早く入力したい時は短くしてください。
- **Stick live mode**は割り当てた**STICK LIVE**ボタンの動作モードを選びます：`HOLD`は押している間だけ有効、`TOGGLE`は押すたびにオンオフ切り替え、`FREE`は常に有効。詳しくは[Motion recording](#motion-recording)を参照。
- **Key mapping**ではキーボードやコントローラの割り当てを変更できます。コマンドを選択し、新しい操作を押し、**Done**で保存します。

### Audio

**Sample rate** は `32 kHz` または `48 kHz`（デフォルト）を選べます。変更は即座に適用され、保存されます。サンプルレートを変更すると、サウンドエンジンとアーム済みのオーディオ入力が新しいレートで開き直される間、再生とサンプルプレビューが停止します。デバイスが新しいレートを拒否した場合、以前の設定が有効なままです。`32 kHz` は処理負荷を減らし、再生できる最高周波数を 16 kHz に制限します。CPU負荷インジケーターはオーディオレンダリングのコストを示します。

**Buffer size**は応答性と安定性のトレードオフです。ライブ演奏時に反応を良くしたければ小さく、ノイズやCPU負荷が高い時は大きく設定してください。`32`、`64`、`128`、`256`、`512`、`1024`サンプルの中から選べます。CPU負荷表示を参考に安定した値を見つけてください。

### MIDI

入力・出力デバイスを選び、MIDIチャンネルを楽器に割り当て、MIDI CCをマップします。キーボード接続やミキサー操作、外部機器へのノート送信は[15. MIDI](#15-midi)を参照。

### Synths

- **AY Quality**はAY/YM楽器の音質を設定します。**AY Sample dithering**はAYサンプルの再生を滑らかにできますが、オリジナル機器向けやローファイサウンドを狙う場合はオフのままにします。
- **Braids BITS**、**DRFT**、**SIGN**はすべてのBraids楽器に適用されるグローバル設定です。全体の解像度、ドリフト、キャラクターを調整してから個別の音色を微調整してください。詳しくは[Braids](#braids)へ。

### Mixer

- **Mix volume**はアプリ全体のマスター出力レベルです。外部ミキサーや録音機に送る際は控えめに設定してください。曲内のトラックミックスには影響しません。
- **Tilt pivot**はこのプロジェクトのすべてのMixerの**Tilt**コントロールの中心周波数を`250 Hz`～`4000 Hz`（デフォルト `1 kHz`）の間で設定します。

### Graphics

- **Edit color theme**はインターフェイスの配色を変更します。**Load font**は`.cnfont`形式のフォントを読み込みます。
- **Song waveform**はSongページのミックス波形表示のON/OFF。詳細は[Song waveform](#song-waveform)。
- **Track visuals**は各トラックで**Detailed**（楽器の波形とオーバーレイ）または**Audio waveform**（そのトラックの出力波形）を選べます。全部のトラックを一括で**All detailed**または**All audio**に切り替え可能。
- **Waveform FPS**は楽器スコープやミキサービジュアライザの再描画頻度（1～60fps）を設定。静かな表示やCPU余裕のために下げられます。
- **Renderer**は`GPU`か`Software`レンダリングの使用状況を表示。

### Support report and quit

**Support report**はバグ報告用の簡易診断ファイルを作成します。問題が特定曲に関連している場合は、その`.cct`ファイルと共に添付してください。**Quit ChooChooTracker**でアプリを正常終了します。

### Song waveform

Graphics → Song waveformは初期状態OFFです。EDITをタップするか、EDIT + 方向キーで切り替えます。設定はアプリのプリファレンスとして保存されます。有効時はSONG画面上部に全体モノラルミックスの2段波形が表示されます。他のページは影響を受けず、フルサイズレイアウト、通常の間隔、楽器プレビューが維持されます。設定は過去バージョンとの互換性あり。SONGのタッチ操作範囲は両モードの波形行に連動します。

## 14. トラブルシューティング

### CPU

CPU負荷は起動中のエンジンとエフェクトによります。Plaitsの物理モデルやCloudsリバーブは基本AYボイスより重いです。特に8声Plaitsと両方のセンドを同時使用時にターゲット機器で性能を確認してください。CPU読み値が`100%`近くになるとノイズや音欠落が発生します。
ポップ音やクラッシュ、遅延が起きた場合は**Settings > Support report**を使い`support-report.txt`を作成し、バグ報告に添付してください。特定曲が原因なら、その`.cct`も添付してください。

### 無音

楽器番号、トラックのミュート・ソロ状態、トラックLVL、アプリのMix volume、楽器エンベロープを確認してください。サンプルの場合は元のWAVファイルが保存先に存在しているかも確認。
ArkOSでは**MENU + L3**でOSミュートが切り替わります。効果がなければハードの再起動やオーディオインターフェースの再接続を試してください。ArkOSの「repair audio」オプションも役立つことがあります。

### 入力が変

SettingsでRepeat delayとRepeat speedを調整してください。1回押しで2回進む場合は、その方向に物理コントロールが1つのみ割り当てられているか確認し、問題の画面とショートカットを報告してください。

## 15. MIDI

Settings > **MIDI** は以下のサブメニューを開きます：**MIDI In** / **MIDI Out** で接続済みデバイスを選択。`OFF`は両端にあり、検出されたポートを順に切り替えます。入力・出力両方にデバイスが必要です。

- **MIDIキーボードからのサウンドプレビュー**：MIDI Inにデバイスを選択すると、接続キーボードでどの画面からでも入力可能で、[Instrument](#5-instruments)画面の画面上の**EDIT + PLAY**ショートカットと同じ動作をします。プレビュー専用で曲には記録されません。
- **チャンネルマッピング**：16チャンネルのリストが開きます。各チャンネルに楽器（初期は`OFF`）を割り当てると、そのチャンネルから受信したノートはInstrument画面の選択に関わらず割り当てた楽器でプレビューされます。例：チャンネル`01`→楽器`05`。`OFF`にしたチャンネルは選択中の楽器で鳴ります（従来の動作）。割当情報はsettings.txtに保存。
- **MIDI CCマッピング**：受信したコントローラを楽器パラメータ（**Volume**含む）やグローバル制御へ割り当てます。グローバル行は楽器名の代わりに`TRK 1`～`TRK 8`が表示され、トラックの**Mute**、**Solo**、**Volume**、**Reverb send**、**Delay send**を操作可能。**Song play/stop**はターゲットなし。新規割当は設定されたCCの最後の値を無視し、次の物理的操作で有効になるため、再生中の割当変更でパッチ値は自動リセットされません。ミュート・ソロは`0-63`がオフ、`64-127`がオンです。
- **MIDIクロック同期**：MIDI In デバイスを選んだ状態で、Project 画面の **Clock source** を **Midi Clock** にすると外部シーケンサーに追従します。トラッカーは入力クロックのテンポ（4分音符あたり24パルス）を計測し、暗くなった **Tempo** 行に表示します。**Start**、**Continue**、**Stop** メッセージが再生を制御します。クロックソースは settings.txt に記憶されます。
- **外部MIDI機器の駆動**：トラックに[MIDI Out](#midi-out)楽器タイプを割り当てチャンネルを設定すると、そのトラックのノート入力はChooChooTracker内で音を鳴らさず指定されたMIDI Outデバイスへ送信されます。
