# PortMaster startup diagnostics

This support tool is not included in the standard package.

1. Copy `ChooChooTracker-debug.sh` into the Ports folder, next to
   `ChooChooTracker.sh`, without replacing it.
2. Make it executable if needed: `chmod +x ChooChooTracker-debug.sh`.
3. Run the debug script. It writes `cct-startup.txt` in the same folder.
4. Review the log for personal information before sharing it with support.
